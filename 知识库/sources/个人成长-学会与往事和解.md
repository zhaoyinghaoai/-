# 学会与往事和解（每日阅读）

> 网络文摘·个人成长（和解）。和解是一种胸怀，能包容曾经的伤害，让心灵重归宁静；与世界和解、与过去的挫折和解、与自己和解、与时间和解，放下执念，发现生活美好。

## 核心观点

1. **和解是包容伤害的胸怀**：能包容曾经的伤害，让心灵重归宁静——学会与不如意和解，是成熟的标志，也是幸福的开端
2. **与世界和解、与过去和解**：不抱怨、不执拗，用平和心态迎接挑战；在岁月长河里与过去的挫折和解，为未来积攒前行的力量
3. **和解不是妥协**：而是以更豁达的姿态面对人生起伏；放下心中的执念，与自己和解，便能发现生活的美好无处不在
4. **与时间和解**：不匆忙、不焦虑，稳稳地走好人生每一步
