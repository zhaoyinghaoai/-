# 行动（每日阅读）

> 网络文摘·个人成长（行动·实干）。行动是打败焦虑的最好办法；不知道该做什么就把手头每件小事做好，不知道怎么开始就从离你最近的那件事做起；喊破嗓子不如甩开膀子，行动不一定成功，但不行动一定不会成功。

## 核心观点

1. **行动是打败焦虑的最好办法**：不知道该做什么时，把手头的每件小事做好；不知道怎么开始时，把离你最近的那件事做好
2. **实干胜过空喊**：喊破嗓子不如甩开膀子，行动是最富有力量的宣言
3. **不行动一定不会成功**：行动不一定会成功，但不行动则一定不会成功
4. **报酬来自做了什么**：生活不会因为你想做什么而给你报酬，而是因为你做了什么才给你报酬
