# 初心易得，始终难守（每日阅读）

## 核心观点

1. **初心易得，始终难守**：每个人都听过「不忘初心，方得始终」，却少有人知道下一句「初心易得，始终难守」——开始容易，坚持到底才是真考验
2. **重复的力量**：水滴石穿不是水的力量，而是重复的力量；再远的路走着走着就近了，再难的事做着做着就成了
3. **坚强是底线**：现实有多残酷，你就该有多坚强
4. **活成自己想要的模样**：每天醒来面朝阳光、嘴角上扬，不羡慕谁、不讨好谁，默默努力
