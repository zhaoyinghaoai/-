# 复盘是一种向自己学习的方式（每日阅读）

> 网络文摘·个人成长（复盘）。听过那么多大道理却依然过不好这一生，因为你没有及时复盘；学习有三种方式——向书本学、向他人学、向自己学，而最深刻的方式就是向自己学习，复盘就是这种学习。

## 核心观点

1. **听过道理却过不好，因为没复盘**：大道理都懂，但没有对自己的经历做过回顾反思，道理就落不了地
2. **复盘 = 回看每一步**：像棋手下完棋回看每一步决策——回顾做过的事、分析预期与结果的差距、提炼经验教训
3. **三种学习方式，最深刻的是向自己学习**：向书本学、向他人学、向自己学；前两者是输入，向自己学是从自己的实践里长出来的经验
4. **复盘是向自己学习的动作**：把复盘做起来，就是给自己搭了一条「从经历到成长」的闭环

## 金句

- 「听过那么多大道理，却依然过不好这一生——因为你没有及时复盘。」

- 「复盘，就是一种向自己学习的方式。」
