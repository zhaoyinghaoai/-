# 合抱之木，生于毫末（每日阅读）

> 老子《道德经》第六十四章——大事从小事起，量变积累，行动从第一步开始。

## 核心观点

1. **大事起于微末**：合抱的大树从一粒种子长起，九层高台从一筐土垒起
2. **量变积累产生质变**：所有「大」都是「小」的复利，没有捷径
3. **行动从第一步开始**：千里之行，始于足下——再远的路也要迈出第一步

## 金句

- 「合抱之木，生于毫末；九层之台，起于累土；千里之行，始于足下。」
