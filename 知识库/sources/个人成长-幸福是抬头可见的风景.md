# 幸福是抬头可见的风景（每日阅读）

> 网络文摘·个人成长（幸福·快乐）。没有信手拈来的幸福也没有不劳而获的成功；把简单的小事做好就是不简单，用心过好当下每一天；快乐需要学习，快乐本由心生，只要愿意感知小小的快乐无处不在；幸福不是高峰而是抬头可见的风景。

## 核心观点

1. **没有信手拈来的幸福**：幸福和成功都不是不劳而获的
2. **小事做好就是不简单**：把每一件简单的小事做好就是不简单，把平凡的事做好就是不平凡
3. **用心过好当下**：用心过好当下每一天，离理想生活越来越近
4. **快乐需要学习**：不快乐时靠近正能量的人、换个角度看问题、培养感知幸福的能力
5. **快乐本由心生**：只要愿意感知，小小的快乐无处不在
6. **幸福是抬头可见的风景**：幸福不是高不可攀的高峰，寻找幸福的过程就是人生最好的状态

## 金句

- 「没有信手拈来的幸福，也没有不劳而获的成功。」

- 「用心过好当下的每一天，你就会离理想的生活越来越近。」
- 「快乐是需要学习的。」

- 「你不断寻找幸福的过程，正是人生最好的状态。」
