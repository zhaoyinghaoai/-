# 自律者，方能掌控自己的人生（每日阅读）

> 网络文摘·个人成长（自律）。天才之所以卓越，靠的是持续不断的努力；别只羡慕别人出彩自由，他们靠日复一日的自律与坚持；自律是开启渴望世界的钥匙，越自律越能掌控人生、拥有选择的自由。

## 核心观点

1. **天才靠持续努力**：人们眼中的天才之所以卓越非凡，并非天资超人一等，而是付出了持续不断的努力
2. **别只羡慕别人**：与其盯着手机羡慕别人活得精彩自由，不如明白一件事——他们能掌控人生，靠的是日复一日的自律与坚持
3. **自律是开启渴望世界的钥匙**：每个人心中都有渴望的世界，自律就是那把可以开启的钥匙
4. **越自律越自由**：越自律的人，越有能力掌控自己的人生，也越能拥有选择人生的自由
