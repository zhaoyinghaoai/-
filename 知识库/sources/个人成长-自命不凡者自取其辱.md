# 自命不凡者 往往是自取其辱（每日阅读）

> 网络文摘·个人成长（处世）。自命不凡者往往是自取其辱、不值得信任——他们总觉得只有自己最重要，以为自己能掌控一切，反而在交往中处处受阻；心比天高，最后把机会让给了懂得珍惜的人。

## 核心观点

1. **自命不凡→自取其辱**：总觉得自己最重要、别人都该把自己放第一位的人，往往自取其辱、不值得信任
2. **掌控一切却处处受阻**：自以为能掌控一切、无所不能，反而在与人交往中处处受限制
3. **心比天高**：总抱着「我的成功、我的荣耀」的心态，眼里只有自己，遇贵人也会把机会让给懂珍惜的人
4. **机会留给懂珍惜的人**：那些有能力、有梦想又懂得珍惜机会的人，最终接住了机会

## 金句

- 「自命不凡者，往往是自取其辱，不值得信任。」
- 「他们心比天高，总是抱着『我的成功，我的荣耀』的心态。」
- 「他们总会把机会让给那些有能力、有梦想而又懂得珍惜机会的人。」
