# 基础不牢 地动山摇（每日阅读）

> 网络文摘·个人成长（踏实）。生活中总有人想走近道抄近路，但重要环节松松垮垮，根基必不稳；每一条投机取巧走过的捷径，到头来往往是绕了弯路。卓越不属于投机取巧的人，它属于愿意默默耕耘的人。

## 核心观点

1. **基础不牢，地动山摇**：就像建一座大厦，重要环节松松垮垮，必然根基不稳，日后有坍塌的风险
2. **走捷径终绕弯路**：每一条投机取巧走过的捷径，往往到后来才发现是绕了远路
3. **一砖一瓦建高楼**：唯有一砖一瓦去建造，万丈高楼才能拔地而起
4. **卓越属于默默耕耘的人**：卓越不属于投机取巧的人，它属于愿意默默耕耘的人
