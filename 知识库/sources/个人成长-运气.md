# 运气（每日阅读）

> 网络文摘·个人成长（励志）。以大多数人的努力程度，还没有资格谈运气；不劳而获、运气好只是成功者的自谦，不努力的人却当了真——最大的运气，是你从未停止过的努力。

## 核心观点

1. **实力不够，别谈运气**：以大多数人的努力程度还没资格谈运气，还没轮到拼运气，薄弱的实力就先让你败下阵来
2. **「运气好」是成功者的自谦**：不劳而获、运气好只是成功者的客套话，不努力的人却当了真
3. **最大的运气是努力**：别总想着走捷径，这世上最大的运气，是你从未停止过的努力
4. **自律才会遇到好运**：坚定梦想、保持自律，你才会遇到属于你的好运
