# 没有人能回到过去，但我们能创造未来（每日阅读）

> 网络文摘·个人成长（放下·成长蜕变）。放不下的是付出没得到回报、事与愿违的遗憾；可真正的回报并非一时的成败得失，而是生命中的成长与蜕变；不能回到过去重新开始，但能从现在开始创造崭新未来；向阳而生，每个努力的当下都是美好年华。

## 核心观点

1. **放下「付出未得回报」的遗憾**：很多事与愿违的遗憾，源于执念于付出没有回报
2. **真正的回报是成长与蜕变**：回报并非一时的成败得失，而是生命中的成长与蜕变
3. **不能回到过去，但能创造未来**：没人能回到过去重新开始，但都能从现在开始创造崭新的未来
4. **向阳而生，珍惜当下**：从今天起健康快乐、乐观向上；别怕来不及，你努力的每一个当下都是最美好的年华
