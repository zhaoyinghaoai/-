# 爱自己才能活成一束光（每日阅读）

> 网络文摘·个人成长（自爱·生活态度）。不必成为玫瑰，也可以做岁岁枯荣、生生不息的野草；想发照片就发、想分享就分享，何必在意别人的眼光；面对批评指责置之不理是最好的回应；好好爱自己才能把自己活成一束光，照亮自己也照亮别人；人生只有一次，好好爱自己才是对生命最大的尊重。

## 核心观点

1. **不必成为玫瑰，可做野草**：风华正茂的年纪不必一定要成为玫瑰，也可以做岁岁枯荣、生生不息的野草——不必迎合单一标准
2. **何必在意别人的眼光**：想发照片就发、想分享就分享，过自己的日子
3. **面对批评指责置之不理**：置之不理是最好的回应，不被外界噪音消耗
4. **爱自己才能活成一束光**：先照亮自己，才能照亮别人
5. **人生只有一次，好好爱自己**：自爱是对生命最大的尊重
