# 接纳自己（每日阅读）

> 网络文摘·个人成长（励志）。人生有起有伏，无法逃避坎坷，却可以选择面对坎坷的态度；稳住心、沉住气，握好自己的人生节奏。

## 核心观点

1. **面对坎坷的态度**：人生有起有伏，无法逃避坎坷，却可以选择面对坎坷时的态度——接纳是主动的
2. **低谷不可怕，怕的是认输**：成就并不难得，难的是保持本心——稳住心、沉住气，集中精力做好自己的事，没有翻不过去的山、跨不过去的栏
3. **沉着冷静，从容做事**：遇上麻烦自乱阵脚只会迷失航向、满盘皆输；唯有沉着冷静，才能逐浪而行、挺立潮头
4. **握好人生节奏**：人生就是不断成就自己的过程，愿我们都能握好自己的人生节奏，活出精彩人生

## 金句

- 「低谷不可怕，怕的是你就此认输；成就并不难得，难的是你保持本心。」
