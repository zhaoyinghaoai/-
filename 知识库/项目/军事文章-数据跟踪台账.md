3. **发布三查清单**：①3个标签都蓝色可点击 ②每个标签都是硬词不是问句 ③标签和文章核心严丝合缝 ④封面图选好 ⑤自评话术准备好

### 🔴 9-11 判定根因复核（9-17 12:16 浩总问「9-11 是什么原因触发的」）

**平台原话**：`作品不适宜持续推荐，存在低质创作内容`（**质量评级，非违规**）。

**根因＝完读率 12% + 真实评论 0。** 平台看到的是：**推了 9.4 万人，只有 12% 读完** → 判"留不住人"；**真实评论 0** → 判"没有讨论价值"。两条一起触发"低质"评级。

**关键数据对照（本篇是"机器和读者打架"的标本）**：

| 指标 | 数值 | 判读 |
|---|---|---|
| 展现 / 阅读 | **94,158 / 8,006** | 🚀 4 年历史最高 |
| 点击率 | **8.5%（超 68% 同类）** | ✅ 优秀档 |
| **平均阅读完成率** | **12.0%（超 30% 同类）** | 🔴 **极低，低于平台低质线 40%** |
| **真实评论** | **0** | 🔴 **没有讨论价值** |
| 平均阅读时长 | **3 分 3 秒** | ✅ 不短 |
| 点赞 / 收藏 / 涨粉 / 收益 | **118 / 27 / +4 / 3.44 元** | ✅ 读者侧投了相反票 |

→ **模型**：读完的人不多（12%），但读进去的人几乎全被转化（960 个读完的人里出 118 赞 = **转化率 12%**）＝典型"**长文深读型**"。**机器看的是"多少人没读完"，读者看的是"读完的人多喜欢"——两边算的不是同一笔账。**

**⚠️ 一个必须纳入考察的嫌疑：正文 2,185 字，是标准篇幅的 2.2 倍**
本篇**实际发布正文 2,185 字 / 50 段 / 平均 43.7 字/段 / 最长段 117 字 / 超 60 字的段有 16 个 / 6 个段落超 80 字 / 6 个小标题**。
