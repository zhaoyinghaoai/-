## 一、一句话故事（Logline）

方士韩终随徐福跨海寻仙，却因一念之仁放过一名海东扶桑少女；他更阴差阳错误服不老药，长生不老。千年里，他亲见自己当年那点仁慈在时光中长成的因果——那支被放过的血脉将"隐忍"刻入骨血，长成了他再也挽回不了的模样。长生不是恩赐，是罚：让他独自吞下这份额外的债，最终以死谢罪。

## 二、主题陈述

**仁慈的代价，与长生者的债。** 一个人的一念之仁，在千年尺度上发酵成他始料未及的因果；而不死，让行善者独自吞下这份额外的刑罚——直到以死谢罪，才把债还清。

## 五、人物小传与弧光

### 韩终（主角·方士/心腹副将）
- **身份**：秦代齐地方士，本求不死药，被始皇选为徐福副手。
- **弧光**：求药方士 → 平服令下的犹疑者 → 放少女的道德行动者 → 误服不死的不老囚徒 → 千年见证者 → 悔恨谢罪。
- **看点**：全书道德心脏；他的"仁"不是弱点，是人性未被帝王意志抹掉的光；而不老让他独吞这份罪的利息。

### 徐福（副线核心）
- **身份**：齐地琅琊方士，东渡主帅，冷峻执行者。
- **弧光**：政治算计者 → 平海东主帅 → "止王不来"立邦者 → **隐约知晓韩终纵走少女、因己为灭国令主使而压下追问、暗中追查至死未得 → 抱憾客死海东、灵柩未归故土**（与韩终"长生亲历"构成双线忏悔）。
- **与韩终关系**：同乡+主副；冷与温的对照，结局一"长生亲历"、一"死不瞑目未还乡"。

### 扶桑少女（被放过者·代际象征）
- **身份**：卷三被韩终放过的扶桑部族少女。
- **弧光**：被赦遗民 → 隐忍血脉之母（创伤生存术：非天生狡诈，是灭族逼出的活命之道）。她的血脉将"隐忍"刻入族群记忆。

### 秦始皇（开场钩子源）
- **身份**：一统帝王，梦魇驱动的控制狂。
- **作用**：梦魇设定全局动机（预见一场跨越千年的因果劫→先发制人）；与韩终构成"预见者"双镜——始皇梦见，韩终活见。

## 七、史料锚点表（保底七分实三分虚）

- **实（正史明载）**：徐福齐地琅琊人；前219上书三神山、带童男女数千；前210射巨鱼再出海；"得平原广泽，止王不来"；始皇求仙潮与坑儒；韩终史载入海不归（《史记》《汉书》）。
- **轻奇幻（可真实）**：方术氛围；巨鱼/海神托辞叙事层；仙药（佐贺古记"弗志弗死"不老草可作不死药原型）。
- **虚（小说虚构）**：始皇梦魇预见千年因果；平海东扶桑真实使命；韩终为徐福心腹同行；韩终误服不死药长生；被赦少女血脉世代隐忍；以死谢罪结局。
- **来源**：《史记·秦始皇本纪》《史记·淮南衡山列传》《汉书·郊祀志》《三国志·吴书》《后汉书·东夷传》、五代《义楚六帖》。

## 八、创作护栏（让小说稳且狠）

1. "隐忍"写成**灭族创伤逼出的生存术**，不写成"天生狡诈"——避免脸谱化，升格为"暴力的代际回响"。
2. 韩终的"妇人之仁"是**道德心脏**，写成人性未被帝王意志抹掉的光，非"蠢/误事"。
3. 结局不走宿命反讽，走**直给因果 + 长生者赎罪**：清晰、有力、契合网文向情绪拉满。
4. **合规护栏（发布版必守）**：全书不出现"倭 / 红圆旗 / 甲午 / 侵华"等指向现实民族与战争的字眼；始皇之梦以"跨越千年的因果劫"意象承载，不坐实为任一真实历史事件；详见 `产出/小说/徐福东渡_平台发布大纲_合规.md`。
