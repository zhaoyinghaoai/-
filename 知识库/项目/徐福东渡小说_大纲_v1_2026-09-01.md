## 一、一句话故事（Logline）

秦始皇一统后梦见千年近代屈辱，借求仙之名遣徐福跨海、实为灭海东扶桑于萌芽；方士韩终与徐福同心征讨、势如破竹，却因一念之仁放过一名扶桑少女——那支血脉将"隐忍"刻入骨血，终成后世倭寇之患；而韩终误服不老药长生不老，偏偏活到近代、亲见自己当年那点仁慈酿出的千年之祸，悔恨以死谢罪。

## 二、主题陈述

**仁慈的代价，与长生者的罪。** 一个人的妇人之仁，在代际尺度上发酵成国族之患；而不死，让行善者独自吞下这份额外的刑罚。

## 四、四卷总纲（起承转合）

字数预算（网文向，均章 ~2200–2500 字，全书约 40–46 章，章末必留钩子）：
**卷一 2.5w / 卷二 2.5w / 卷三 3w / 卷四 2w**

### 卷一 · 梦魇与启航（起 / 出海前）~2.5万字 · 10章
- **目标**：立住"始皇梦魇→灭扶桑真实使命"，完成徐福韩终结义与出海。
- **核心冲突**：帝王意志 vs 方士之仁（韩终初现犹疑）；明面求仙 vs 暗面出征。
- **转折**：韩终被选为心腹、得知真实使命、随船启航。
- **情感弧**：韩终从求药方士 → 背负屠族之令的犹疑者。
- 见下方"卷一章级细纲"。

### 卷二 · 沧海征途（承 / 航海）~2.5万字 · 10章
- **目标**：航行奇观 + 初接触扶桑诸部 + 埋仙药伏线。
- **核心冲突**：自然之险（风暴/巨鱼，轻奇幻叙事层）vs 内心之险（韩终对"夷狄非兽"的觉醒）。
- **转折**：韩终意外触及/获得"不死药"线索（徐福所得"平原广泽"之药 / 扶桑部族守护灵药）。
- **情感弧**：韩终动摇加深，与徐福出现第一道裂痕。
- **章级细纲**：待续。

### 卷三 · 焚与赦（转 / 登陆与征服）~3万字 · 12章 ★重头戏
- **目标**：灭扶桑前期高歌、遇少女、韩终放人、误服不死。
- **核心冲突**：征服号令 vs 韩终之仁（全书爆点）。
- **转折（hinge）**：韩终放少女 → 误服不老药 → 开始不老而不自知。
- **情感弧**：韩终从犹疑者 → 道德行动者 → 不老囚徒（起点）。
- **章级细纲**：待续。

### 卷四 · 长生的债（合 / 立邦与回响）~2万字 · 8–10章
- **目标**：东土立邦 + 千年回响 + 韩终亲历屈辱 + 谢罪。
- **核心冲突**：韩终长生之身 vs 亲眼见证自己仁慈的恶果。
- **转折**：韩终活到近代，亲见始皇当年所梦的同一段屈辱史。
- **情感弧**：长生见证者 → 悔恨 → 以死谢罪（闭环：始皇梦见，韩终活见）。
- **章级细纲**：待续。

## 五、人物小传与弧光

### 韩终（主角·方士/心腹副将）
- **身份**：秦代齐地方士，本求不死药，被始皇选为徐福副手。
- **弧光**：求药方士 → 屠族令下的犹疑者 → 放少女的道德行动者 → 误服不死的不老囚徒 → 千年见证者 → 悔恨谢罪。
- **看点**：全书道德心脏；他的"仁"不是弱点，是人性未被帝王意志抹掉的光；而不老让他独吞这份罪的利息。

### 徐福（副线核心）
- **身份**：齐地琅琊方士，东渡主帅，冷峻执行者。
- **弧光**：政治算计者 → 灭扶桑主帅 → "止王不来"立邦者。与韩终的"冷"对照韩终的"温"。

### 扶桑少女（被放过者·代际象征）
- **身份**：卷三被韩终放过的扶桑部族少女。
- **弧光**：被赦遗民 → 隐忍血脉之母（创伤生存术：非天生狡诈，是灭族逼出的活命之道）。她的血脉将"隐忍"刻入族群记忆。

### 秦始皇（开场钩子源）
- **身份**：一统帝王，梦魇驱动的控制狂。
- **作用**：梦魇设定全局动机（梦见近代屈辱→先发制人）；与韩终构成"预见者"双镜——始皇梦见，韩终活见。

## 七、史料锚点表（保底七分实三分虚）

- **实（正史明载）**：徐福齐地琅琊人；前219上书三神山、带童男女数千；前210射巨鱼再出海；"得平原广泽，止王不来"；始皇求仙潮与坑儒；韩终史载入海不归（《史记》《汉书》）。
- **轻奇幻（可真实）**：方术氛围；巨鱼/海神托辞叙事层；仙药（佐贺古记"弗志弗死"不老草可作不死药原型）。
- **虚（小说虚构）**：始皇梦魇预见近代；灭扶桑真实使命；韩终为徐福心腹同行；韩终误服不死药长生；被赦少女血脉世代隐忍；以死谢罪结局。
- **来源**：《史记·秦始皇本纪》《史记·淮南衡山列传》《汉书·郊祀志》《三国志·吴书》《后汉书·倭传》、五代《义楚六帖》、学界"徐福集团推动日本弥生时代"共识。

## 八、创作护栏（让小说稳且狠）

1. "隐忍"写成**灭族创伤逼出的生存术**，不写成"天生狡诈"——避免脸谱化，升格为"暴力的代际回响"。
2. 韩终的"妇人之仁"是**道德心脏**，写成人性未被帝王意志抹掉的光，非"蠢/误事"。
3. 结局不走宿命反讽，走**直给因果 + 长生者赎罪**：清晰、有力、契合网文向情绪拉满。
