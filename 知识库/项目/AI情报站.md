# AI情报站

> 全网AI资讯 → 每周四格简报 → 服务军事文章选题 + 创业机会侦察 + 认知跟上时代 + 写作提效
>
> 运转机制：浩总每日碎片15分钟丢钩子 → 每周一自动生成简报 → 浩总5分钟确认 → 每月回看砍无用源

## 一、四个方向（情报往哪归档）

| ④ 写作相关 | 写作提效 + skill情报 | 新写作skill、写作工具升级、写作方法 |

## 四、筛情报口诀（每天过眼时问）

- 军事角度：**"这有没有文章钩子？"**
- 创业角度：**"这有没有我能抄的玩法？"**
- 通用三问：跟我有关吗？能行动吗？值得留吗？——90%的信息看完就过，只有10%值得丢进收件箱。

## 五、每月回看（防垃圾场化）

- 这月情报真用上了吗？（写成文章 / 试了工具 / 改变了一个决策）
- 没用的全删，源头也砍
- 情报是输入，文章和行动才是产出
