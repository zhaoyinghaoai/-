# 我的写作风格

> 从两篇军事文章成品中提取，用于指导公众号/头条文章的写作。

## 标题

- 长标题、信息量大，用冒号或问号分隔
- 典型：[具体事件] + [数字/细节] + [设问/悬念]
- 例："日本防卫省一天发5条通报手忙脚乱，中国7舰横穿4要道，在破什么局？"

## 开头：2-3句抓人

- 用具体事件 + 具体数字直接把人拉进现场
- 不铺垫、不介绍背景，一上来就是画面
- 例："6月29号这天，日本防卫省统合幕僚监部的官网有点忙不过来。一天之内连发5条..."

## 节奏

| 特征 | 说明 |
|------|------|
| **短句为王** | 能断就断，不让读者喘不过气的地方故意不停 |
| **口语但不口水** | 用老百姓说话的方式写——"什么叫霸屏？这就叫霸屏" |
| **设问推进** | 先问一个问题，"问题是，亮给谁看？"然后给出答案 |
| **--- 分段** | 大段落之间用分隔线，给读者视觉休息 |

## 内容手法

### 数字说话
每段必有具体数字。不是"很多军舰"，是"7艘军舰"。不是"经常来"，是"357天"。

### 专家引用 + 大白话翻译
引用权威后，必跟一句"翻译一下就是..."或"用大白话说..."。把专业术语拆成老百姓听得懂的话。

### 对比
用时间对比（"89年前的今天...89年后的今天..."）或用实物对比（"枪炮换成了舰炮，刺刀换成了星链"）。

### 反问
不直接下结论，用反问引读者自己得出——"你是来巡逻的，把炮越换越大干什么？"

## 立场

- 不中立。有明确立场和态度。
- 敢于下判断："对面还是那个喜欢在别人家门口搞事情的老毛病"
- 但这种判断建立在事实之上，不是空喊口号

## 结尾

- 一句话收尾，有力量，有余味
- 不总结全文，不给"建议"或"展望"
- 例："规矩自己定的，道我们合法走。这种'霸屏'往后只会更频繁。"

## 禁忌

- 不写"值得注意的是""总而言之""不言而喻"这种 AI 腔
- 不用"赋能""抓手""闭环""底层逻辑"这种互联网黑话（除非语境确实需要）
- 不写空话——每句话必须有信息量
- 不写"给 XX 三个建议"这种说教感结尾
- 不写超过三行的长句

## 适用场景

| 平台 | 风格适配 |
|------|---------|
| 今日头条（军事） | 原生的风格，最匹配 |
| 公众号（商业/成长） | 去掉记者视角，保留其余所有特征 |
| 小红书 | 需调整为更轻量，但短句和数字说话保留 |
