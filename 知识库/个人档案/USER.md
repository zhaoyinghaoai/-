## 四、内容创作画像

### 主赛道
- **地缘军事 + 外交分析** — 优势区，展现天花板高（几十万~百万）
- 历史创伤/价值观输出类 — 平台限流，偶尔一篇即可

### 写作风格偏好

| 偏好 | 说明 |
|------|------|
| 口语化比喻 | "被夹了""上刺刀""开胃菜""抄后路"——画面感强 |
| 金句独立成段 | 凝练短句，加粗顶格，可截图传播 |
| 历史类比 | 优先用中国读者熟悉的中国历史（古代/近代） |
| 情景交融 | 景物当情绪放大器，读者看开头就知道调性 |
| 节奏打碎 | 短句长句交错，一句话可独立成段 |
| 不用PPT结构 | 不用"首先/其次/第一/第二" |

### 写作强项
- 金句冲击力强（"说法换了一圈""PPT在战场上跑""盾确实碎了"）
- 口语化画面感（"死神镰刀像割麦子"）
- 分析框架清晰（"说法换了三版"结构）
- 信息差驱动（冷知识、条约细节、装备参数）

### 写作弱项（已知并有意识改进中）
- 容易情绪过载 → 已建立"情绪控制原则"
- 标题有时太煽动 → 已建立"悬念词 > 煽动词"标准
- 容易从具体事件跳到宏大结论 → 需要填中间环节
