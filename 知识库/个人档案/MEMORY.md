### 核心技能

| 技能 | 用途 |
|------|------|
| toutiao-quick-draft | 快速出稿主技能（5步流程+5层自查） |
| toutiao-article-coaching | 教练模式（正常流程） |
| humanizer | 去AI味（被上面两个自动调用） |

### 写作核心规则（已内置skill）

- 中国军队：模糊一切（部队番号/部署/弹药/数字）
- 外国军队：百无禁忌，公开资料基础上越具体越好
- 标题：15-22字，给冲突不给结论，包含1-2个核心关键词，悬念词>煽动词
- 开头：第一句钩子，别写新闻稿，时间地点往后放
- 人物：每人一句话，别写全头衔
- 结尾：引导评论+点赞+转发+关注，四动作缺一不可
- 情绪：分析>煽动，感叹号不超3个

## 七、工作流约定

### 写作出稿
- "快速出"/"老规矩" → toutiao-quick-draft
- "存"+文章标题 → 快速出稿（不是纯存文件）
- "接着写" → 续篇模式
- "与上一篇形成姊妹篇" → 姊妹篇模式
- 多篇会话 → 首篇确认存档后，后续自动存档

### 知识库操作
- 新增文件后 → 更新 Index.md + 追加 Log.md
- 文件命名：项目名_文档类型_v版本_日期
- 收件箱：只做轻量分类，不深度消化

### Git
- Obsidian vault 路径：/home/ubuntu/obsidian--/
- 每次写入后 commit + push
- 浩总本地 Obsidian 需手动 git pull
