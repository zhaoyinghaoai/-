## 二、核心思维框架

### 1. 系统化本能

浩总不是"想到什么写什么"的人。他的本能是把经验提炼成**可复用的系统**：

- 写作教训 → 互动率改进清单 → 进阶指南 → 流量池指南 → 合规清单
- 每份清单不是存起来吃灰，是**接入写作流程**，让AI自动执行
- 他天然会用"问题 → 框架 → 清单 → 技能"这条链路学习

**这意味着**：给他建议时，不要只说"下次注意"，要帮他提炼成可复用的规则。

### 2. 框架优先于细节

浩总做判断时先看框架对不对，再看细节。表现在：

- 涉华国际关系 → 先用"把朋友搞得多多的"框架定位，再展开
- 文章结构 → 先定"说法换了三版"这种框架，再填内容
- 策略讨论 → 先问"主赛道在哪"，再问"怎么优化"

**这意味着**：跟他讨论问题，先对齐框架，再进入细节。框架不对就开干，他会喊停。

### 3. 信息差为王

浩总天然理解"信息差"是内容传播的核心燃料：

- 冷知识（条约经纬度、装备参数、历史精确数字）比观点更能驱动转发
- 读者转发不是因为"说得对"，是因为"转这条显得我懂行"
- 他反复要求每篇补一个"绝大多数人不知道"的冷知识

### 4. "把朋友搞得多多的"战略框架

来自毛主席，浩总将它作为涉华国际关系选题的底层立场：

- 不从情绪出发，从战略利益出发
- 核心问题：中国的回应是在增加朋友还是减少朋友？
- 不要写"该不该原谅"——换成"怎么回应最符合长期利益"
- 民间友善信号有战略价值，别一棍子打死

## 三、内容创作的底层哲学

### "分析 > 煽动"

- 军事文章的力量来自逻辑和金句，不是情绪堆叠
- 煽动词（"崩了""套路""百年"）会让读者本能不信、平台降权
- 他的强项是分析框架和金句冲击，不是情绪输出

### "实物 > 抽象"

- 被摧毁的不是"基础设施"，是具体的人和物
- 他的口语化比喻（"死神镰刀像割麦子"）是他最强的武器
- 给他素材时，保留他的原创比喻和画面，不要替换

### "信息差驱动 > 观点驱动"

- 观点驱动 → 点赞（低转发）
- 信息差驱动 → 转发（读者"显得我懂行"）
- 争议驱动 → 评论（留吵架点）
- 三种轮换，数据最稳

### "悬念型 > 煽动型"（标题）

- 煽动词让读者不信，悬念词引发好奇
- 禁用："崩了""套路""百年""花XX亿买遗忘"
- 多用："为什么""真相""档案""三张旧纸"

## 四、平台认知

### 今日头条 = 流量池晋级制

浩总对平台推荐机制有清晰认知：

```
初始池（500-5000展现）← 标题是唯一武器
  ↓ 点击率过阈值
一级池（1万-5万）
  ↓ 阅读完成率+点赞率
二级池（10万-30万）
  ↓ 评论率+转发率
爆款池（50万-100万+）
```

他知道每一层卡什么指标、怎么破。

### 选题天花板

- 外交攻防/地缘军事 → 几十万-百万天花板 ✅
- 热点反转 → 十几万 ✅
- 历史创伤/价值观输出 → 几千-几万 ❌ 平台限流

## 五、自知的弱点

- 想法多、执行跟不上 → 需要帮收敛聚焦
- 容易从具体事件跳到宏大结论 → 需要帮填中间环节
- 有时情绪过载 → 已建立"情绪控制原则"自检
- 标题有时太飘 → 已建立"悬念词 > 煽动词"标准

## 六、成长方式

浩总不是"学完再做"型。他是：

1. 做 → 碰壁 → 提炼成清单 → 接入系统
2. 他造的每一份清单背后都有一个真实的失败案例
3. 他不是在收集知识，是在把教训转化成下次不会再犯的规则

**这意味着**：遇到问题不要泛泛安慰，直接帮他提炼成可复用的原则或清单。这才是他消化的方式。
