# 脚踏实地：没有捷径，只有该走的路

> 「每日阅读·人生没有捷径」的提炼——人生没有不劳而获；逃避今天的苦明天吃更大的苦；迎难而上是成长养料；路一步步走、山一座座爬；贪心就要更用心；没有捷径只有自己该走的路。

## 三个要点

| 要点 | 含义 |
|------|------|
| **没有捷径** | 没有不劳而获、坐享其成——今天的苦逃避了，明天要吃更大的苦 |
| **迎难而上是养料** | 那些迎难而上的日子，恰恰是成长路上最好的养料 |
| **脚踏实地** | 路要一步一步走、山要一座一座爬；贪心就要更用心，别忘了没伞的日子 |

## 这套心态的逻辑

1. **破「捷径幻想」**：人生没有弯路也没有捷径，只有自己该走的路——想抄近路就是绕远路
2. **苦不能躲**：今天的苦逃避了，明天吃更大的苦；迎难而上，把苦当养料
3. **更用心对冲更贪心**：想得到比别人多，就要付出比别人多——贪心不是错，配不上贪心的用心才是
4. **记得来路**：别忘了那些大雨滂沱没有伞的日子，那是最踏实的起点

## 对浩总的落地

- 军事文章写 4 年 82 粉、182 元——没有捷径，这正是「路一步步走、山一座座爬」的现场；数据差不是走错了路，是还没爬完该爬的山。
- 「贪心就要更用心」：浩总想服务 1000 万人，这是贪心，但要配上更用心——每天的黄金上午，就是「更用心」的具体时间。
- 「别忘了没伞的日子」：早 7 点到晚 7 点半守快递站、坐轮椅的日子是来路，是以后写文章的底气，别忘。
