# 努力自律：最大的运气是努力

> 「每日阅读·运气」的提炼——以大多数人的努力程度还没资格谈运气；别把「运气好」当真，那是成功者的自谦；这世上最大的运气，是你从未停止过的努力；坚定梦想、保持自律，才会遇到属于你的好运。

## 三个要点

| 要点 | 含义 |
|------|------|
| **实力不够，别谈运气** | 还没轮到拼运气，薄弱的实力就先让你败下阵来 |
| **「运气好」是自谦** | 不劳而获、运气好只是成功者的客套话，别当真 |
| **最大的运气是努力** | 别走捷径，持续努力 + 自律，才会遇到好运 |

## 这套心态的逻辑

1. 破「运气幻想」：以为别人靠运气、自己也能靠运气——其实大多数人的努力还没到谈运气的份上
2. 立「实力优先」：实力不够时，先别惦记运气，先把努力攒够
3. 落「努力即运气」：最大的运气不是天上掉的，是持续努力和自律攒出来的
