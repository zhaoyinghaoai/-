# 初心易得始终难守：重复的力量

> 「每日阅读·初心易得始终难守」的提炼——水滴石穿不是水的力量，而是重复的力量；开始容易，坚持到底才是真考验。

## 三个要点

| 要点 | 含义 |
|------|------|
| **初心易得，始终难守** | 「不忘初心方得始终」的下一句才是关键——起头容易，守到底难 |
| **重复的力量** | 水滴石穿靠的不是水的力量，是重复；再远的路走着走着就近了，再难的事做着做着就成了 |
| **活成自己想要的模样** | 不羡慕谁、不讨好谁，面朝阳光、嘴角上扬，默默努力 |

## 这套心态的逻辑

1. 起点是「初心」——每个人都有想开始的时候，但初心太容易得到，所以不值钱
2. 变量是「重复」——把简单的事一天天重复下去，水滴石穿，量变产生质变
3. 结果是「始终」——能守住始终的人，才能活成自己想要的模样

## 对浩总的落地

- 浩总「想法多、执行跟不上」的根源正是「初心易得」——新点子三天两头冒，但难在「始终难守」。
- 「重复的力量」直接回应军事文章写了 4 年、82 粉这件事——4 年的重复没有白费，是在水滴石穿；别盯着即时反馈，盯着「重复」本身。
- 「活成自己想要的模样」提醒：不羡慕别人的爆款、不讨好平台算法，默默写好自己的东西。
