# 复盘自省：向自己学习最深刻

> 「每日阅读·复盘是一种向自己学习的方式」的提炼——听过道理却过不好是因为没复盘；像棋手回看每一步，回顾做过的事、分析预期与结果的差距、提炼经验教训；学习有三种方式，最深刻的是向自己学习，复盘就是这种学习。

## 三个要点

| 要点 | 含义 |
|------|------|
| **道理不落地，因为没复盘** | 大道理都懂，缺的是对自己经历的回顾反思 |
| **复盘 = 回看每一步** | 回顾做过的事 → 分析差距 → 提炼教训 → 指导未来 |
| **向自己学习最深刻** | 向书本/他人学是输入，向自己学是从实践里长经验 |

## 这套方法的逻辑

1. 定「复盘对象」：复盘的不是空道理，是自己「做过的事」
2. 找「预期差距」：对照预期看结果，差距在哪、为什么
3. 炼「经验教训」：把一次经历提炼成下次能用的原则，指导未来行动

## 对浩总的落地

- 浩总核心卡点之一「缺少反馈、难以持续」——复盘正是最便宜的自我反馈：不用等人给反馈，自己回看每天「做过的事」就能长经验。
- 军事文章写了 4 年 82 粉，与其「一直写、不回头」，不如每周回看一次：哪篇数据好、为什么，把经验提炼成下一次的选题和写法。
- 「想法多、执行跟不上」也可以用复盘治：每天睡前回看「今天到底做了哪一件」，比空想新点子更有用。

## 一句话总结

**听过道理却过不好一生，因为没复盘——回看每一步、提炼教训，向自己学习才是最深刻的学习。**
