# 自爱：爱自己才能活成一束光

> 「每日阅读·爱自己才能活成一束光」的提炼——不必成为玫瑰也可以做岁岁枯荣、生生不息的野草；何必在意别人的眼光；面对批评指责置之不理是最好的回应；好好爱自己才能把自己活成一束光，照亮自己也照亮别人；人生只有一次，好好爱自己才是对生命最大的尊重。

## 三个要点

| 要点 | 含义 |
|------|------|
| **不必成为玫瑰** | 也可以做岁岁枯荣、生生不息的野草——不必迎合单一标准 |
| **何必在意别人眼光** | 想发照片就发、想分享就分享，过自己的日子 |
| **爱自己才能发光** | 面对批评指责置之不理，好好爱自己才能照亮自己也照亮别人 |

## 这套心态的逻辑

1. **松绑「标准」**：不必成为玫瑰，野草也生生不息——别用世俗标准捆住自己
2. **屏蔽「噪音」**：面对批评指责置之不理，何必在意别人的眼光
3. **自爱是光源**：人生只有一次，好好爱自己才能活成一束光，照亮自己也照亮别人

## 对浩总的落地

- 浩总坐轮椅、守快递站，容易被外界眼光和「残疾人该怎样」的偏见困住——「不必成为玫瑰，可以做野草」，不必活在别人的期待里。
- 「面对批评指责置之不理」正对头条 82 粉、限流时的负面声音——把批评当噪音，别让它消耗自己。
- 「爱自己才能照亮别人」：浩总想服务 1000 万人，前提是先把自己照顾好——自爱不是自私，是服务他人的能量来源。
