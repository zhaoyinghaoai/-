# 攀登不放弃：山再高，总能登顶

> 「每日阅读·山再高往上攀总能登顶」的提炼——山再高往上攀总能登顶、路再长走下去定能到达；放弃的路不能选，成长的路不能拒；身在井隅，心向星光。

## 三个要点

| 要点 | 出处 | 一句话 |
|------|------|--------|
| **攀登与坚持** | 「山再高，往上攀，总能登顶」 | 经历过一次次考验才能成长，哪怕雨雪纷飞也要追寻阳光 |
| **两条路** | 「放弃的路不能选，成长的路不能拒」 | 只有一条路走不通——放弃；只有一条路必须走——成长 |
| **心向星光、从容** | 「身在井隅，心向星光」 | 眼里有诗自向远方，且行且看且从容；每个人是不一样的烟火 |

## 这条线：认路 → 攀上去 → 扛考验 → 向星光

1. **认路**：放弃的路不能选，成长的路不能拒——把「不放弃」定为默认选项
2. **攀上去**：山再高往上攀、路再长走下去，一步步登顶
3. **扛考验**：人生就是经历一次次考验才能成长，雨雪纷飞也要追阳光
4. **向星光**：身在井隅也不低头，心向星光、从容前行

## 对浩总的落地

- 浩总军事文章写 4 年、82 粉、182 元——正是「山再高往上攀」的现场；眼前没登顶不代表路错了，是还没走到。
- 解法：把「还在爬」当成常态，不因一时没结果就退回「放弃的路」；一步步攀，终能登顶。
