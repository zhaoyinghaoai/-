# 敬业爱岗：把工作当事业干

> 「每日阅读·敬业与爱岗」的提炼——敬业三步（爱业→勤业→精业）；把工作当事业干，小我融进大我，小舞台演出大戏剧。

## 三个要点

| 要点 | 含义 |
|------|------|
| **爱业（第一步）** | 敬业首在爱业，对本职工作的热爱是朴素的职业情感 |
| **勤业 + 精业（第二、三步）** | 业精于勤荒于嬉——勤勉是职业操守；精通业务是职业价值追求 |
| **把工作当事业干** | 专心致志以事其业，平淡中见奇、寻常中出彩；爱岗彰显乐业与执着，小我融进大我 |

## 这条线：爱业 → 勤业 → 精业

1. **爱业**：先喜欢上自己的活儿——对本职工作有热爱，是敬业的起点
2. **勤业**：业精于勤荒于嬉——立足岗位勤勉工作，是职业操守、职业品格
3. **精业**：精通业务——从「会干」到「干得精」，体现职业上的价值追求
4. **事业化**：把工作当事业干，小我融进大我，小舞台也能演出大戏剧

## 对浩总的落地

- 浩总的「舞台」不大——村级快递代收点，日均不到 100 件，但「小舞台演出大戏剧」正是说给他听的：舞台大小不决定戏的大小，决定戏的是怎么演。
- 「把工作当事业干」直接回应浩总的处境：眼下守快递点是生计，但若以「爱业→勤业→精业」对待，就是在给 AI 创业攒用户理解、攒耐心、攒执行手感。
- 「业精于勤荒于嬉」和「下笨功夫」一脉相承：不飘、不贪快，把手头这一件事做精。
