# 人生基本功：4系统12个底层能力

> **核心洞见**：努力积累的是经验，一换环境就失灵；底层能力是"底层代码"，代码对了，跑什么程序都能跑。人生越早培养这12个底层能力，越早受益。

## 二、系统逻辑（为什么是这个顺序）

1. **认知系统 = 算法**：其他人在积累经验，你进化的是算法，指数级差距——认知杠杆
2. **自我管理系统 = 运行环境**：算法再好，想法落不了地等于零
3. **人际系统 = 外部资源接口**：在亲情、友情、工作一切有人的地方交换资源
4. **实践系统 = 结果输出**：想法→行动→结果的最小闭环

**四者递进**：算得对 → 管得住 → 借得动 → 做得出

## 三、12能力速查与提升路径

### 系统一：认知系统（决定成长速度）

**1. 元认知** — 看见自己的思考过程
- 普通人做错决定后："当时太冲动了"（浅层归因）
- 有元认知的人："我当时为什么冲动？受了什么影响？下次怎么不受干扰？"（找根源）
- 路径：读《学会提问》｜听万维钢《精英日课》｜情绪上头后写三行（我的判断是什么 / 基于事实还是情绪 / 下次的新规则）

**2. 系统思维** — 看结构，不看单点
- 例：职场升职≠努力≠成绩，背后是"搞关系+领导力+带动人做事"的整条链
- 路径：读《系统之美》｜看梁宁《产品思维三十讲》｜遇问题先画三个变量（谁影响它 / 它影响谁 / 哪环节最关键）

**3. 知识迁移** — 学的是活水
- 例：作者把自媒体包装封面视频的方法用到职场汇报，把搞定客户的沟通用到家里
- 路径：读《认知天性》《好好学习》｜听《知行小酒馆》｜每学一个方法强制搬到三场景（工作 / 关系 / 赚钱或自媒体）

### 系统二：自我管理系统（决定想法能否落地）

**4. 目标与精力** — 有限资源管理
- 现阶段最重要的目标只可能有1-2个，半年后才能执行的不是目标，是分散精力
- 四象限法：重要紧急→马上做｜重要不紧急→推进日程｜不重要不紧急→删除/限制｜不重要紧急→推诿/拒绝/模块化
- 路径：读《精力管理》｜学四象限法｜每周只保留1-2个主目标

**5. 抗压与韧性** — 把打击当过程不当结果
- 聪明人把失败当过程，普通人当结果；没韧性的人一定会被打败
- 路径：读《反脆弱》｜看彭凯平积极心理学｜每次被打击后写三件事（事实是什么 / 损失了什么 / 下一步还能做什么）

**6. 自律与延迟满足** — 为长期复利克制短期欲望
- 靠短期打鸡血做事的人，拿不到长期才有的最大利益
- 路径：读《掌控习惯》《自控力》｜听《纵横四海》｜把诱惑移远、把开始变简单，目标拆成今天能完成的15分钟动作

### 系统三：人际系统（决定能否交换到资源）

**7. 冲突处理** — 化对立为共赢
- 例："你怎么每次都这样？"一出口对方就防御了；正确顺序是 事实>感受>需求>请求，不审判对方
- 路径：读《关键对话》《非暴力沟通》｜看脱不花《沟通的方法》｜冲突时按"事实>感受>需求>请求"说

**8. 共情与社交直觉** — 会看局的人
- 会社交的不是话最多的，是能感知场域、看局的人（社会化能力）
- 被"好孩子思维"驯化的人会看不起这个能力，很可惜——它是大杠杆
- 路径：读《社会心理学》｜听《Steve说》｜每次社交后复盘（对方在注意什么 / 想被怎么看见 / 想保住什么利益）

**9. 影响力与说服力** — 能影响人的人才是老大
- 让别人愿意相信你、配合你、帮你推动事情
- 路径：读《影响力》｜看刘润《五分钟商学院》｜说服前先写三点（他想要什么 / 他怕什么 / 我能给他什么好处）

### 系统四：实践系统（决定想法能否变成结果）

**10. 问题解决** — 拆解大问题
- "我想赚钱"拆成：靠什么赚钱→有什么技能→技能怎么变产品→这周先做哪一步
- 路径：读《金字塔原理》《你的灯亮着吗》｜看结构化思维公开课｜把大问题拆成（问题是什么 / 卡点在哪 / 15分钟内能先做哪一步）

**11. 执行与迭代** — 先发最小版本
- 典型失败：标题研究1个月、定位研究1个月、设备买齐几个月，一条没发
- 正确：先发最小版本→数据不好改标题→完播率低改节奏；**不是想明白了才开始，是开始了才能想明白**
- 路径：读《精益创业》｜看梁宁《产品思维课30讲》｜最小版本+只改一个变量+用反馈决定下一版

**12. 资源整合** — 不硬扛，借力
- 普通人：什么都要自己扛，不会就憋，没资源就熬
- 高手：知道去哪找信息、借资源、用平台、问人，把别人的经验能力资源嫁接到自己身上
- 路径：读《跃迁》《联盟》｜听《商业就是这样》｜遇问题先列四个入口（信息在哪找 / 工具用什么 / 人问谁 / 平台借哪个）

## 四、对浩总的启发

1. **浩总最典型的模式就是"实践系统"和"自我管理系统"薄弱**：想法多执行跟不上、收藏多转化少、焦虑多动作少——与视频里"实践系统"的描述完全吻合
2. 现有知识库里 [[最小验证方法论]]、[[行动力-从荀子到现代执行]]、[[人生设计思维]] 与"执行与迭代""问题解决"同源，可互相印证
3. 快递点就是天然训练场：每天接触大量的人和突发情况，冲突处理、元认知、抗压韧性都能在日常里练
