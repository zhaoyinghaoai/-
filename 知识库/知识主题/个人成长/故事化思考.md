# 故事化思考

> 浩总最稳定的思考方式：**看故事 → 接到自己身上 → 悟出道理**。14 天日记里有 7 次在用，从正面榜样进化到反面教训，再到「被故事确认」「被故事分类」。

## 是什么

故事化思考 = 用故事作为思考的载体。不直接说教，而是从故事里抽出一个道理，再套到自己身上检验。

## 三个关键升级

1. **从正面到反面**（08-24）：前三天用故事学正面榜样（孙悟空、背包），鱼塘短剧开始用别人的失败推演教训——同一套本事，多了一个方向。
2. **从道理到方法论**（08-25）：鱼塘故事（先选事）＋ 铁杵磨针（再磨事）拼成一套「先选事、再磨事」的完整判断流程。
3. **从学故事到被故事确认**（08-29）：许师傅的故事没有教新东西，是把他心里早就信的「真实比漂亮值钱」再照一遍——方向感已经稳了，外面的故事只是添砖，不是指路。
4. **从确认到造分类器**（09-05 升级）：穿越短剧不仅「确认」，而是「造维度」——把天下的本事分成「厨师证 / 靠环境」两桶。故事化思考从「接住情绪 / 验证观点」进化到「建判断标准」。从那天起，他遇事会习惯性问一句「换环境它还在不在」。

## 浩总可怎么用

- 写军事文章：把热点事件讲成故事再拔观点——这是他的看家本领，也是文章有代入感的原因
- 教女儿：道理讲不明白时，先给故事
- 自我反思：遇到卡点，找一个「和我处境相似的故事」，站在故事里角色的位置推演一遍
- 建判断标准（09-05 升级用法）：遇到「值不值得做」的决策，先找一篇故事做透这个问题的极端情形，故事里的角色怎么做，自己就怎么做——故事是分类器
