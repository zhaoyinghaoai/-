# 稳得住：戒骄戒躁，下笨功夫

> 「每日阅读·稳得住」的提炼——成功之后不飘，浮躁时代肯下笨功夫，默默耕耘静待花开。

## 三个要点

| 要点 | 含义 |
|------|------|
| **心态稳（戒骄戒躁）** | 面对成功谦逊低调；成功之后如何稳住心态，是更大的考验 |
| **下笨功夫（练真功夫）** | 聪明人遍地、都想要快结果的时代，肯下笨功夫才能练真功夫 |
| **静待花开（默默耕耘）** | 成功不唾手可得；不动声色默默耕耘的人，后劲更足 |

## 这套心态的逻辑

1. 别被「聪明人快钱」的思维陷阱带偏——想快速拿到结果，却又不愿付出超常的努力
2. 真正厉害的角色不敲锣打鼓、不动声色——把劲用在耕耘上，而不是用在昭告天下上
3. 稳 = 对成功的谦逊 + 对过程的坚持 + 对结果的耐心

## 对浩总的落地

- **浩总的卡点**：想法多、执行跟不上、缺少反馈难以持续。
- **「稳得住」给解法**：把「想法多」收窄成「一件事下笨功夫」——军事文章写了 4 年、82 粉，正是「下笨功夫」的路子；别盯着即时反馈，先静待花开。
- 面对小成绩（一篇文章小爆、一单小钱），保持低调，继续默默耕耘，戒骄戒躁。
