# 推测机器 — 先推测试错，再修机器

> 你不是在学习，你是在典藏。题一变，全白学。

## 核心观点

**「典藏式学习」**= 阅读理解 → 收藏 → 等机会用。问题是世界不断在变，出题人自己都不知道下个题是什么——你收藏的那些答案，题一变全废了。

**「推测机器」**= 先推测试错 → 根据反馈修自己的推测。错的那道题不重要，重要的是"我的推测哪里跟真实世界有了偏差"。修好推测机器，原来错的那一片题全自动对了。

### 五步法

1. 找到**真正的问题**（不是"黄金三秒的技巧"，是"怎么让用户留下来"）
2. 找到**最简单的解决方案**——跨域借用，不从零学（相声怎么留住人？TED 怎么让人有收获？电影怎么让人入迷？）
3. **快速实验，看反馈**
4. 根据反馈**修推测机器**
5. 重复——"三张卷子内搞定一门考试"

## 金句

> 错了不是那一道题错了，是我的推测机器跟真实世界有了偏差。修好推测机器，原来错的那一片题，全自动对了。

## 浩总现状对照

- 学习流程"**AI 先批改示范 → 自己动手写 → 迭代优化**"，就是推测机器打法：写（推测）→ 批改（反馈）→ 修（迭代）。
- 读书号"**考官三问**"同理：先答题暴露偏差，再修正理解——比划线收藏多走了一整圈。
- ⚠️ 对应的坑：**素材收藏了一堆不消化 = 典藏**。本知识库"原始材料只进不出"没问题，前提是进来的要被消化成页面——这正是每日摄入存在的意义。
