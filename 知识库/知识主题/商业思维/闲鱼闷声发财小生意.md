# 闲鱼闷声发财小生意

> 个体创业的起点，往往就是从帮别人解决一个10块钱的具体小麻烦开始的。

## 两个案例

### 案例一：帮人改PDF文件
- **需求**：改PDF里的字，字体对不上、版面全乱、格式跑偏
- **定价**：20-50元/单
- **收入**：一天几十单，月入过万
- **本质**：用户自己搞特别费劲，但摸透流程的人几分钟搞定

### 案例二：整理微信聊天记录导出文档
- **需求**：合同细节、业务沟通记录需要整理提交给公司或律师
- **定价**：30-100元/单，按条数或页数收费
- **效率**：熟练后十几分钟一单

## 共性特征

- 客单价低、需求琐碎、频次高
- 用户自己搞费劲，但会做的人几分钟搞定
- 用户买的不是技术，是省下的时间和精力

## 核心方法论

1. **不需要高门槛**——只需要比用户多懂一点点
2. **标准化交付**——把流程跑通，做成SOP
3. **AI降低成本**——AI工具降低了交付成本，但用户需求还在
4. **一个人一台电脑就能开始**

## 行动建议

1. 逛闲鱼、淘宝，看销量高但不起眼的服务
2. 问身边的人最近有什么琐碎又不得不做的事
3. 学会用AI工具组合，形成标准化交付流程
4. 先从一个具体小需求开始，积累几十个客户再放大

## 对浩总的启发

这和浩总想做的PPT兼职逻辑完全一致：
- PPT = 用户自己做费劲，会做的人半小时搞定
- AI能大幅降低制作成本
- 一个人一台电脑就能开始
- 先接单积累客户，再放大

**本质上，PPT兼职就是"帮人解决具体小麻烦"的模型之一。**
