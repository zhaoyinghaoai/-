# NPV 净现值：这笔买卖到底该不该做

> **一句话：把这个东西今天值多少，减掉今天要掏的钱。正的干，负的散。**
>
> DCF 告诉你"它值多少"，NPV 告诉你"**那我要不要掏这笔钱**"。

**中文名**：净现值。「**净**」就是**扣掉成本剩下的**。
**英文原词**：`Net Present Value` —— Net（净、扣掉后的）＋ Present（现在的）＋ Value（价值）。

**来历（30 秒）**：现值这个概念是一百多年前经济学家**欧文·费雪**系统讲透的（1907 年那本讲利息率的书）。把它当成「该不该投」的**判据**，是后来算大工程账的时候定下来的规矩——**修铁路、建水坝，先算 NPV，正的才批**。

## 一、它解决什么问题

[[DCF-一个东西到底值多少]] 回答的是「**这东西值多少**」——**给的是一个价格**。

但手里拿着一个价格，还有一问没答：

> **"那我要不要掏这笔钱？"**

**NPV 就是回答这一句的。** 它是从「知道价格」走到「**拍板**」的那一步。

## 二、公式

```
NPV =  折回来的钱  −  今天要掏的钱
```

```
NPV =  PV（未来那一串钱） −  C₀
```

两个部分，挨个认：

- **折回来的钱**：未来每一年的钱各自折回今天，加起来 —— **就是 DCF 那一套**
- **C₀**：今天掏出去的钱（成本）

⚠️ **这个式子有一个写法上的坑，先说清**：

我最初写成 `NPV = Σ Cₜ/(1+r)ᵗ − C₀`。这个写法**容易读错**——`Σ Cₜ/(1+r)ᵗ` 长得像一个「还要算的东西」，其实它是一个「**已经算完的成品**」。

（10-05 当堂就踩了这个：把已经折好的 5154.194 又除了一次 `(1+r)³`，答案直接反了。见第七节。）

**所以这个式子记住中文版就够：折回来的钱 − 今天要掏的钱。**

## 三、🔴 唯一要守住的一条：等式两边都必须是「今天的钱」

**任何一个数拿到手，先问一句：这是「今天的」，还是「未来的」？**

- **今天的** → 直接用
- **未来的** → 折过来 —— **但只折一次**

**这条一破，整道题就反了。**

**为什么**：NPV 是把两笔钱放在**同一个时间点**上比。时间点不齐，比的就不是钱，是错觉。

## 四、判据（就三行）

- **NPV 正 → 干**（你捡了便宜）
- **NPV 负 → 不干**（你多掏了钱）
- **NPV 等于 0 → 白干**（不亏不赚，图个忙）

**NPV = 0 的那个价，就是「底价线」。**（见第六节）

## 五、它和 DCF 的分工

- **DCF 回答：这东西值多少** —— 给的是一个**价格**（**标价**）
- **NPV 回答：买它净赚多少** —— 给的是一个**数**，正负决定做不做（**拍板**）

**一句话：DCF 标价，NPV 拍板。**

两个式子不是两个工具，是**一条流水线的两道工序**：先算值多少，再减成本下结论。

## 六、🔴 它有「两面」——买家和卖家看的是相反的方向

**这一节是 2026-10-05 浩总自己做题时走出来的，题面里没问。**

同一个东西、同一条价线，站在两边是**两条相反的结论**：

**站在买方**（你要掏钱买）：

- 这条线是**上限**
- 出价**低于**它才划算，**越低越好** → 挑报价低的那个

**站在卖方**（你要把它出手）：

- 这条线是**下限**
- 出价**高于**它才划算，**越高越好** → 挑报价高的那个

**同一个数，给出两条完全相反的建议。**

**因为它们回答的是两个问题**：**「值不值这个价」**（买方）和**「卖得贵不贵」**（卖方）。

> **浩总原话（10-05）**：「**如果我要租的话，从乙处租。如果是我转让的话，我转给甲。**」
> —— 前半句是题面问的，**后半句是他自己补的**。

## 七、它和「底价线」是一条线

折现算出来的那个数，**就是 NPV = 0 的价——也就是底价线**。

- 出价 **高于**底价线 → NPV **负** → 亏
- 出价 **低于**底价线 → NPV **正** → 赚
- 出价 **正好** → NPV **0** → 白干

**「要不要出手」这类事，先算这条线。** 有人出价，心里一比就知道，不用每次重新纠结。

**买方愿出 ≤ 这条线，卖方愿收 ≥ 这条线** —— 中间这条线，就是双方的分水界。

## 八、手算记录（2026-10-05 实走）

**示范（我给的）**：昨天那台设备（3 年 ×2000 @8% → 今天值 **5154.194**）

- 老板开 **5500** → `NPV = 5154.194 − 5500 = ` **−345.806** → **不买**

**第一题（他做，第一次答错、第二次对）**

- 老板改口 **4800** → `NPV = 5154.194 − 4800 = ` **+354.194** → **可以要**

**第二题（巩固，4 项折现，一次全对）**：村口铺面，4 年 ×2500 @10%

- 四项折现：2272.73 ／ 2066.12 ／ 1878.29 ／ 1707.54
- 加起来 **7924.68**（精确值 7924.66，**差 2 分**——他是每项截到分再加，两种做法都对）
- 甲 **9000** → `NPV = 7924.68 − 9000 = ` **−1075.32**（负）→ **不接**
- 乙 **7000** → `NPV = 7924.68 − 7000 = ` **+924.68**（正）→ **接**
- **他的答**：「如果我要租的话，从乙处租。如果是我转让的话，我转给甲。」→ **第二句题面没问**（见第六节）

## 九、坑位清单

1. 🔴 **把折完的现值又折一遍**（10-05 踩）—— `5154.194` 本来就是「今天的钱」，不用再除 `(1+r)³`。**同一笔钱折两遍，结论直接反了**（该做的题答成"不做"）
2. **把成本也拿去折**（新手通病）—— `C₀` 本来就在今天，**不用折**
3. **忘了减成本** —— 只算了个 DCF 就说"划算"，那还没算完
4. **正负看反** —— 负的是**亏**，不是"便宜"
5. **NPV 只有一点点正 ≠ 好买卖** —— 那说明这生意几乎白干，赚的是辛苦钱（这时候要问问：同样的力气，有没有更好的去处）
6. **折现率选错，结论全变** —— NPV 对 `r` 很敏感，`r` 越大 NPV 越小。**`r` 是假设，不是事实**
7. **多项连加，注意进位**（同 DCF）—— 四笔以上加总容易歪一点，分两步加、留中间结果

## 十、现实里什么时候用

凡是「**先掏一笔钱，之后慢慢回钱**」的事，都要算它：

1. **有人转让生意／设备／铺面** —— 算 NPV 决定接不接
2. **买台机器省人工** —— 省下的钱折回来，跟机器价一比
3. **加盟费、装修投入** —— 未来几年多赚的折回来，跟投入一比
4. **站在卖方也一样** —— 自己盘店出手，算清这条线，心里有底，不至于被人压价压到亏
5. **赊账 vs 现结** —— 也是同一套：把不同时间点的钱拉到一起比

**共同点：凡是钱要分好几次到手或出手的事，都要先拉到同一个时间点，再相减。**

## 一句话总结

**NPV ＝ 折回来的钱 − 今天要掏的钱。正的干，负的散。**

**等式两边必须都是「今天的钱」——未来的折过来，但只折一次。**

**它是 DCF 的下一步：DCF 告诉你值多少，NPV 告诉你该不该掏。**

**记住「底价线」：那条线就是 NPV = 0 的价。买方低于它才划算，卖方高于它才划算。**
