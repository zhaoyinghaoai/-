# 招聘情报掘金方法论

> **一句话定义：** 把招聘软件当商业情报雷达，通过系统化扫描发现需求缺口、暴利领域和产业迁移机会的搞钱方法论。

---

## 核心框架

### 三个层次

```
┌──────────────┐
│  第1层：发现   │ ← 搜关键词看企业痛点（高提成/急聘/合伙人）
├──────────────┤
│  第2层：验证   │ ← 连看50个JD拼SOP + 面试套老板洞察
├──────────────┤
│  第3层：套利   │ ← 跨界组合溢价 / 产业游牧卡位 / 卖铲子
└──────────────┘
```

### 四个核心认知

| 认知 | 旧思维 | 新思维 |
|------|--------|--------|
| 招聘软件 | 找工作的地方 | 商业情报金矿 |
| 岗位描述 | 岗位要求 | 企业流血伤口 |
| 奇葩组合 | 奇怪的需求 | 暴利定价权 |
| 求职面试 | 求一份工作 | 免费商业调研 |

---

## 方法论拆解

### 一、需求扫描（第1步）

**搜索关键词：** 高提成 / 急聘 / 合伙人 / 分红 / 上市 / 可兼职

这些词背后是企业最急迫的需求——愿意分股份、给超高提成、标注"急"，说明不是一般缺人，是缺到影响生意。

### 二、SOP拼图（第2步）

连看50个同领域岗位→把JD内容拼起来→形成完整业务SOP。

一家公司把赚钱流程写在招聘要求里，50家公司=50份实战经验免费白嫖。

### 三、暴利定位（第3步）

寻找把两个不相关技能"缝"在一起的岗位。单技能卷、跨界稀缺。

**判定公式：** A技能熟悉度×B技能熟悉度 → 两者都在60-80分区间 = 最高溢价

### 四、产业套利（第4步+第6步）

两个维度：
- **地理套利：** 切城市→产业迁移→人才缺口→提前卡位
- **时间套利：** 盯疯狂扩招的陌生小公司→资本悄悄注入→顺势获取赛道经验

### 五、现金流管道（第7步）

搜「远程/兼职/不坐班/一单一结」→把闲置技能立刻变现。

浩总场景：快递代收点下午空闲时段，可接远程兼职（AI标注、数据审核等）。

### 六、卖铲子（第8步）

发现工具需求暴增→做本地化教程/培训/代运营。

**核心逻辑：** 淘金热时不挖金子，卖铲子和牛仔裤。

### 七、财富热力图（第9-10步）

30天每天10分钟→把高薪急聘岗位钉在地图上→形成个人财富指南。

**日常化：** 当成终身习惯，每天10分钟=持续的认知复利。

## 对浩总的启示

| 步骤 | 可操作性 | 具体行动 |
|------|---------|---------|
| 第1-2步 | ⭐⭐⭐⭐⭐ | 今天就可以开始搜，零成本 |
| 第7步 | ⭐⭐⭐⭐⭐ | 兼职管道适合快递点空闲时段 |
| 第8步 | ⭐⭐⭐⭐ | 发现工具需求→做本地化（信息差变现） |
| 第9步 | ⭐⭐⭐ | 需持续30天，但每天只要10分钟 |
| 第3-6步 | ⭐⭐ | 需一定积累后才见效 |

**最小启动方案：** 明天开始每天打开招聘APP花10分钟搜关键词，先把1-2步跑通，信息差自然积累。
