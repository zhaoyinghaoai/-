# DCF 现金流折现法：一个东西到底值多少

> **一句话：把未来每一年的钱，各自打折拉回今天，再加起来。**
>
> **它给的是"这东西今天值多少"——不是"它明天涨不涨"。**

**中文名**：现金流折现法（也叫"折现现金流法"，语序不同，一个东西）。
**英文原词**：`Discounted Cash Flow`——被动结构，是**现金流**被**折现**，所以"现金流折现法"这个语序更贴原意。

**战场上它在哪**：

- 券商研报里它叫「**绝对估值法**」——和 PE、PB 那类「相对估值法」对着叫
- 资产评估报告里官方名叫「**收益法**」，DCF 是它最主要的做法
- 一句话分工：**PE/PB 看"别人卖多少钱"，DCF 算"这东西本身值多少"**

## 一、它解决什么问题

前面几张卡，管的是**一笔钱**随时间变：

- [[72法则-多少年翻一倍]] 和复利——**往前滚**：今天的钱，将来变成多少
- 折现——**往回拉**：将来的钱，今天值多少

**但现实里钱不是一笔，是一串。**

一个生意、一台设备、一辆车、一家店：它未来会**一年一年地**给你钱。

问：**这一串未来的钱，今天加起来值多少？**

**DCF 就是回答这一句的。**它是所有公式里唯一一个真正"给东西定价"的。

## 二、公式

```
价值 = C₁/(1+r)¹ + C₂/(1+r)² + C₃/(1+r)³ + … + Cₜ/(1+r)ᵗ
```

写成符号就是：

```
价值 = Σ  Cₜ / (1+r)ᵗ
```

三个符号，挨个认：

- **Cₜ**：第 t 年进来的钱（现金流）。`C₁` 是第一年，`C₂` 第二年……
- **r**：折现率。（用什么数，见第七节）
- **Σ**：就是"**加起来**"的符号，没别的意思。它把从第 1 年到第 t 年的每一项全加起来。

**每一项在干什么**：把**那一年的钱单独拉回今天**。

- `C₁/(1+r)¹` — 第 1 年的钱，往回拉 1 年
- `C₂/(1+r)²` — 第 2 年的钱，往回拉 2 年
- `C₃/(1+r)³` — 第 3 年的钱，往回拉 3 年

**年限在第几项，就折几次。** 这就是全部。

## 三、🔴 核心只有一条：各自折，折完再加

**这是 DCF 唯一真正的死穴。**

```
✅ 正确：  C₁/(1+r)¹ + C₂/(1+r)² + C₃/(1+r)³
❌ 错的：  (C₁ + C₂ + C₃) / (1+r)³        ← 先加再折
```

**错在哪**：那个偷懒的写法，把第 1 年、第 2 年就到手的钱，**统统当成第 3 年才到手的**，每笔都多折了一两年。

**为什么多折就是错**：因为——**早到的钱更值钱。**

第 1 年就到手的 1000 块，你拿去存银行、拿去周转，它自己会长；第 3 年才到手的 1000 块，中间这两年什么也生不出来。**同样 1000 块，"早两年"本身就是一笔钱。**

（这条在折现那张卡里已经踩过：**多笔各自折再加总，别先加再折**。DCF 就是它的正式名字。）

## 四、完整走一遍（引入例 · 村东头老李的快递点）

> **题**：老李要转让村东头那个快递点。"一年净赚 **1000 块**，往后三年都这样。三年后我不干了，这店也没人接、不值钱。"折现率按 **10%**。
> **问**：今天最多掏多少钱买它？

**① 把未来的钱排成一排**

```
第 1 年   1000
第 2 年   1000
第 3 年   1000
```

**② 每一笔各自拉回今天**

```
第 1 年：1000 ÷ 1.1¹   = 1000 ÷ 1.1    = 909.09
第 2 年：1000 ÷ 1.1²   = 1000 ÷ 1.21   = 826.45
第 3 年：1000 ÷ 1.1³   = 1000 ÷ 1.331  = 751.31
```

**看着这三行，注意一件事**：钱数一模一样（都是 1000），折出来的数**一年比一年小**。

**这就是"时间在扣钱"的样子。** 同样 1000 块，晚一年到，就少 80 多。

**③ 加起来**

```
909.09 + 826.45 + 751.31 = 2486.85 元
```

**→ 今天最多掏 2486.85 块。** 超过这个数就是亏；低于这个数就是赚。

**对照一下偷懒版**（先加 3000，再折三年）：

```
3000 ÷ 1.331 = 2253.94 元
```

**少算了 233 块。**

**这 233 块是什么？** 是"晚到"的代价——偷懒版把第 1、2 年的钱也当成第 3 年才到，白扣了两年。**233 块就是这两年白扣出来的。**

## 五、当堂练习（10-04 实走）

**题**

> 一台设备，未来 **3 年**每年带来 **2000 元**，3 年后报废、不值钱。折现率 **8%**。今天最多花多少钱买它？

**浩总的推导（原样照抄）**

```
今天值多少钱=C₁/(1+r)¹ + C₂/(1+r)² + C₃/(1+r)³
2000/1.08+2000/1.08^2+2000/1.08^3
=1851.852+1714.678+1587.664
=5155.194（元）
```

**批改**

| 格子 | 判 |
|---|---|
| 公式 | ✅ 一字不差 |
| 三项**各自**折 | ✅ **没掉进「先加再折」的坑**——DCF 的核心规矩，**第一遍就守住了** |
| 第一项 1851.852 | ✅（2000÷1.08） |
| 第二项 1714.678 | ✅（2000÷1.1664） |
| 第三项 1587.664 | ✅（2000÷1.259712） |
| 合计 | ❌ 实际 **5154.194**，他写 **5155.194**——**个位多了 1** |

**结论：DCF 第 1 天 · 过。** 方法一次到位，那 1 块钱是**三项连加的进位手滑**，不是不会。

**这个错，粗估挡不住**（这条要单独记住）

三项加上去，`1851.852 + 1714.678 + 1587.664`，进位时歪一点很正常。

**问题是**：**三项都往上进位估一遍，也是 5155**——和错的那个数一模一样。真值 5154 本来就离 5155 只差 1，落在粗估误差里。**粗估这次帮不上忙。**

**只能用"验"，两个动作二选一**：

1. **分两步加、留中间结果**：前两项先加成 **3566.530**，再加第三项
2. **加完倒着减回去**：`5155.194 − 1587.664 = 3567.530`，跟前两项的和 **3566.530** 对不上 → 一眼看出歪了

**顺带说**：上一节那个引入例的三个数（909.09 / 826.45 / 751.31）他也全对——**两题三个格子以上，一个没错，错的全在连加那一步。**

## 六、DCF 和折现是同一件事

不是两个公式，是**一个公式的两种用法**：

- **折现**：一笔钱，往回拉一步 → `C/(1+r)ⁿ`（只有一项，是 DCF 的最简版）
- **DCF**：一串钱，每一项都往回拉，然后加起来 → `Σ Cₜ/(1+r)ᵗ`

**一句话：DCF 就是"折现"干很多遍。**

**所以学起来几乎不用花力气**——折现本来就熟，DCF 只是把同一件事每一年做一遍，再求和。

**上一节那三行**，每一行单独拎出来都是一道折现题：

```
1000 ÷ 1.1¹    ← 折现题（一笔钱、1 年）
1000 ÷ 1.1²    ← 折现题（一笔钱、2 年）
1000 ÷ 1.1³    ← 折现题（一笔钱、3 年）
```

**DCF 的"新"，只新在最后那一下加法，和"每一笔的年限不一样"这一件事。**

## 七、r 用什么数（以及这张卡不展开的部分）

折现率 r 不是现成的数，**它是你选的**。常用的参照系：

- **无风险利率**（国债利率）—— 这是"钱躺着的保底"，低于它不划算
- ＋ **风险补偿** —— 这件事越不确定，加得越多
- ＝ **折现率**

**⚠️ 一句话说完 DCF 的真正难点**：

> **公式是干净的，脏的在你喂给它的两个数上——C（每年能赚多少）和 r（折现率）。**

- C 少估一点，估值就掉一截
- r 多给 2 个点，估值就掉一截

**所以两个人对同一家公司算出天差地别，从来不是公式吵，是假设吵。**

**边界（本节不展开）**：上面的算法只处理了"明确知道有几年"的情况。现实里的生意**三年之后还在赚**，那一大截怎么办——是下一步的事。**现在不用碰。**

## 八、它在现实里什么时候用

**这道题你已经在生活里做过很多遍，只是没给它起名字：**

1. **有人要转让一个生意给你** —— 他报的价，跟 DCF 算出来的数比一比，高多少一目了然
2. **判断"赊账还是现结"** —— 都是 10 万，今天给和一年后给，**是两个数**。一年后给的 10 万，折回今天可能只值 9 万出头（这中间就是利息/时间价值）
3. **买东西看"几年回本"** —— 一台机器 2 万，一年省 5000，四年回本；用折现算一遍，回本年数会比"4 年"长
4. **看研报里的目标价** —— 底下那套估值，多半就是 DCF（绝对估值那一类）
5. **分期 vs 全款** —— "分期 12 期每期 900"和"全款 10000"，比的是**把 12 期折回今天的和**，不是把 12 期加起来

**共同点：凡是"钱要分好几次到手/出手"的事，都要把每一笔拉回同一个时间点再比。**

**不折现就直接加，等于把不同年份的钱当成同一年的钱——这是最隐蔽的一类算错。**

## 九、坑位清单

1. **先加再折**（最大的坑）—— 多笔必须**各自折完再加**；偷懒版会少算"晚到"的代价（老李那例少 233）
2. **年限写错**—— `C₃` 要除以 `(1+r)³`，不是 `(1+r)`。**第几项就折几次**
3. **三项以上连加，容易进位手滑**（10-04 新踩）—— 真值 5154.194 写成 5155.194。**粗估挡不住**（三项全进位也是 5155）→ 只能**分两步加留中间结果**，或**倒着减回去验**
4. **别和"翻倍"混**—— DCF 是**折回来**（越往前越小），72 法则/复利是**滚出去**（越往后越大）。方向相反
5. **它不是"预测涨跌"**—— DCF 给的是"值多少"，市场给的是"卖多少"。**两者差出来，才是机会**
6. **公式不难，假设难**—— 算出来的数再精确，也不代表那个数可信；**要先问 C 和 r 是怎么来的**

## 十、手算记录（2026-10-04 实走）

| 题 | 折现率 | 三项 | 合计 |
|---|---|---|---|
| 老李快递点（引入例，我给） | 10% | 909.09 ／ 826.45 ／ 751.31 | **2486.85**（偷懒版 2253.94，少 233） |
| 设备 3 年（他做） | 8% | 1851.852 ／ 1714.678 ／ 1587.664 | **5154.194**（他写 5155.194，个位手滑） |

**他做对的两件事，比得数值钱**：

- **第一遍就没掉"先加再折"的坑**——这是 DCF 唯一的核心规矩
- **三项数值一笔没错**——错只错在最后那次连加

## 一句话总结

**未来每一年的钱，各自除以自己的 `(1+r)ᵗ` 折回今天，再加起来——这就是一个东西今天的价。**

**核心只有一条：各自折、折完加。先加再折，会把早到的钱当成晚到的，一律算少。**

**公式干净，难在 C 和 r；但这两格填错也不慌——先问一句：这两个数是谁给的、凭什么。**
