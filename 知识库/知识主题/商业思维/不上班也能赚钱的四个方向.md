# 不上班也能赚钱的四个方向

> 大环境不好时，商机反而更清晰——所有人都在找出路。

## 四个方向

### 1. 转运玄学
- **案例**：手机福字贴纸，从100多跌到几块钱，七八个月窗口期有人翻身
- **原理**：想翻身的人永远在市场，配合"以前很惨买了之后好了"的故事
- **本质**：低成本高溢价，卖的是心理安慰
- **对应框架**：[[赚钱的4个底层框架|情绪]]

### 2. 平价经济
- **参考**：日本90年代经济泡沫期 → 优衣库、无印良品崛起
- **当前案例**：拼多多、蜜雪冰城、名创优品、零食折扣店
- **逻辑**：不是不花钱，是不乱花钱。以前看性价比，现在看谁更便宜
- **对应框架**：[[赚钱的4个底层框架|刚需]]

### 3. 带人赚钱（卖铲子）
- 跨境运营、AI编程培训、短视频代运营、IP孵化
- **本质**：别人挖金矿，你卖铲子——给迷茫的人指一条路
- **特点**：永远有市场，不管经济好坏
- **对应框架**：[[赚钱的4个底层框架|信息差]]

### 4. 情绪价值
- 当代人精神压力到临界点，花钱买情绪价值是刚需
- 宠物经济、单身经济、银发经济、自媒体
- 自媒体 = 用最低成本给最大快乐和陪伴
- **对应框架**：[[赚钱的4个底层框架|情绪]]

四个方向分别对应"赚钱4个底层框架"中的某一个。理解了框架，就能自己找到更多方向。
