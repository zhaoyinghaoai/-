# 开方与小数指数：没有计算器也能算

> **一句话：小数点后面的次数，一半是乘法、一半是开方；开不尽的方，靠猜、平方、往下调。**
>
> 它解决的问题是——**手机上做题、手边没计算器，也得把数算到"能判断"的程度。**

## 一、小数指数怎么算

**规则：整数部分照常乘，小数部分开根号。**

拆开的依据是「指数相加 = 幂相乘」（这条在 [[72法则-多少年翻一倍]] 里已经用过）：

```
2^4.5 = 2^4 × 2^0.5
         ↑      ↑
   整数部分照常乘   小数部分开根号
```

- `2^4 = 16`
- `2^0.5 = √2 ≈ 1.41`
- 所以 `2^4.5 = 16 × 1.41 ≈ 22.6`

**而且这个答案能先圈一个区间**：翻 4 次是 16 倍、翻 5 次是 32 倍 → **4.5 次必然落在 16 和 32 之间**。**一掉出区间，不用往下算，一定错。**

## 二、为什么 0.5 次方 = 开平方

用「指数相加」反过来看：

```
2^0.5 × 2^0.5 = 2^(0.5+0.5) = 2^1 = 2
```

**两个「半个」拼成一个整的。**

所以「2 的 0.5 次方」就是那个**乘两次正好等于 2** 的数 —— `√2 ≈ 1.41`。

**推广**：

```
a 的 n 分之一次方 = a 开 n 次方
```

**口诀：分母管「开几次」，分子管「乘几次」。**

- `2^(1/2) = √2 ≈ 1.41`
- `8^(1/3) = ³√8 = 2`（因为 2×2×2 = 8）
- `16^(1/4) = ⁴√16 = 2`（因为 2 自乘 4 次 = 16）

## 三、开不尽的时候：猜 → 平方 → 调

不是特殊值的方，靠**估**。

**求 √10：**

1. **先夹**：3² = 9，4² = 16 → √10 落在 **3 和 4 之间**
2. **试 3.2**：3.2 × 3.2 = 10.24 → 比 10 **大** → 往下调
3. **试 3.16**：3.16 × 3.16 = 9.9856 → 还小一点点
4. **试 3.162**：3.162 × 3.162 = 9.998 → 够了

→ **√10 ≈ 3.162**

**判据一句话：平方后比目标小就往上调，比目标大就往下调。**

每一步都在缩小范围，不是瞎猜。

## 四、更快的版本：一步取中

```
新数 =（猜的数 + 目标 ÷ 猜的数）÷ 2
```

**「目标」＝根号里的那个数**（求 √10，目标就是 10；求 √2，目标就是 2）。

**那个「÷2」＝求平均数**，跟「2 次方根」没有半点关系。

> 就是你常说的「**平均下来**八九十件」那个平均。

**为什么它能越猜越准**：

**「猜的数」和「目标÷猜的数」永远一左一右。** 你猜小了，后者一定偏大；你猜大了，后者一定偏小。**两个数分居真值两边，取中间就靠近。**

**求 √10，从 4 起手**（4 是偏大的）：

```
(4 + 10÷4) ÷ 2 = (4 + 2.5) ÷ 2 = 3.25            ← 一轮就从 4 落到 3.25
(3.25 + 10÷3.25) ÷ 2 = (3.25 + 3.0769) ÷ 2 = 3.1635
```

真值 3.1623。**两轮就到。**

**起手数随便挑，不必偏小** —— 这是 10-03 纠正过来的一条：「猜的数」**不是「偏小的那个」**，是**你随手提的那个**，可大可小。

## 五、什么时候真的需要开方（边界）

**在 72 法则里，几乎永远不需要。**

因为手上有现成的锚：**8 年翻一倍**。要算半个（4 年）就用 `1.09⁴`，**连续平方，全是乘法**：

```
1.09 × 1.09 = 1.1881
1.1881 × 1.1881 = 1.4116 ≈ 1.41
```

**两条路是同一个数**：`√2 ≈ 1.41`（通法）与 `1.09⁴ ≈ 1.41`（连乘），说的都是**「半个 8 年 = 半个翻倍 = 2 的 0.5 次方」**。

**只有反推的时候才要开方。**

> 例：有人说「我 5 年翻了一倍」，问那年化多少？
>
> `2^(1/5) = ⁵√2 ≈ 1.148` → **年化约 14.8%**
>
> 拿这个再去验他：72 ÷ 14.8 ≈ 4.9 年，**对得上**。

## 六、精度只需要一两位小数

真实场景里，**1.41 和 1.4142 拿去判断「这个收益率可不可信」，没有任何区别。**

**不用算准，算到能判断就够。**

## 七、两个保命动作

**① 念算式，数字念全**

「**十六** 乘 **一点四一**」——不是「第一项乘第二项」。**数字从嘴里过一遍，串了就露馅。**

（这条是 10-02 期望值那次立的；10-03 又救回一次：`2.63` → `22.63`）

**② 先粗估，圈一个区间**

4.5 次方必然在 16~32 之间；0.5 次方必然在 1~2 之间。**一掉出区间，不用往下算。**

（10-03 这一条只给了一半，导致漏挡一次 → **凡把指数拆成两半的题，每一半都要给区间**。）

## 八、🔴 一个数字只能有一个身份

这条是 **2026-10-03 浩总自己揪出来的**。

牛顿法 `新数 =（猜的数 + 目标 ÷ 猜的数）÷ 2` 里，我拿 **√2** 举例 —— 于是式子里 **2 同时是「目标」** 和 **「÷2 的那个 2」**。

他直接问：**「这个 2 是 2 次方根的意思吗？」**

**答案是：两个 2 毫无关系。** 一个是举例用的数字，一个是公式自带的求平均。

**规矩：同一个式子里，一个数字只能有一个身份。** 讲题人和出题人都要守这条；**看到撞车要当场问、当场改**。

（顺带说明他那句问话的价值：他在假设「同一个符号应该只有一个意思」——**这个假设本身是对的**，错的是题面。）
