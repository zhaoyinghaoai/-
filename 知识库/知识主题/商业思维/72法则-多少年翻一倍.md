# 72 法则：多少年翻一倍

> **一个除法，把"收益率"翻译成"时间"。**
> 它不问你赚多少，问你多久翻一倍。

## 一、它解决什么问题

你手里一笔钱，按某个年化收益率滚下去，**多久能翻一倍？**

就这么一句。听起来简单，但它是**把百分数翻译成时间**的唯一一个心算工具——而时间是你直接能感受到的东西。

## 二、公式

```
翻倍年数 = 72 ÷ 年化收益率的数字
```

**除的是"百分号里那个数"，不是小数。**

- 年化 6% → `72 ÷ 6 = ` **12 年**翻倍
- 年化 8% → `72 ÷ 8 = ` **9 年**翻倍
- 年化 12% → `72 ÷ 12 = ` **6 年**翻倍

**别把 6% 写成 0.06 去算**——那样算出来是 1200，得除以 100 才对。直接用 6。

## 三、精确公式（能讲出为什么）

```
n = ln 2 ÷ ln(1 + r)        ← r 用小数（年化 8% → r = 0.08）
```

### 四步推导（2026-09-29 浩总亲自走完）

**第一步 · 把"翻倍"写成式子**

本金 100、年化 8%：一年后 `100 × 1.08`，两年后 `100 × 1.08 × 1.08`，n 年后：

```
100 × (1.08)^n
```

**第二步 · "翻倍"是什么意思**

翻倍 = 结果变成原来的 2 倍 → `100 × (1.08)^n = 200` → 两边除以 100：

```
(1.08)^n = 2
```

**这就是"翻倍"的全部数学含义。**

**第三步 · 把 n 从头顶搬下来**

两边同时取 ln，左边用"指数搬下来"那条法则：

```
ln[(1.08)^n] = ln 2   →   n × ln(1.08) = ln 2
```

**第四步 · 除过去**

```
n = ln 2 ÷ ln(1.08)
```

**验算**：`0.6931 ÷ 0.07696 = 9.0065` → 约 9 年，跟 72 法则给的一致。

### n 的白话读法（浩总自己问出来的）

> **"100 乘以多少个 1.08，才能等于 200？"**

**n 就是在问"要乘几个 1.08"**——这正是对数的定义。所以真正的写法是：

```
n = log₁.₀₈ 2
```

**但计算器上只有 ln 和 log₁₀ 两个键，所以要用换底公式。**

## 四、换底公式（从"话"到"算式"的一步）

```
log_a b = ln b ÷ ln a
           ↑     ↑
         真数b   底a
```

**口诀：上面 b、下面 a，上下用同一个底。**

### 它成立的证明（一行的）

设 `x = log_a b` → 按定义 `a^x = b` → 两边取 ln → `x × ln a = ln b` → `x = ln b ÷ ln a`。

**又是"指数搬下来"那一条法则在起作用。**

### 验证（用已会的结果反查）

| 算式 | 换底展开 | 值 |
|---|---|---|
| `log₂ 8` | `ln8 ÷ ln2 = 2.0794 ÷ 0.6931` | 3 ✓ |
| `log₃ 27` | `ln27 ÷ ln3 = 3.2958 ÷ 1.0986` | 3 ✓ |
| `log₅ 125` | `ln125 ÷ ln5 = 4.8283 ÷ 1.6094` | 3 ✓ |
| `log₄ 64` | `ln64 ÷ ln4 = 4.1589 ÷ 1.3863` | 3 ✓ |

**底换成 log₁₀ 也一样**（`log₁₀8 ÷ log₁₀2 = 0.9031 ÷ 0.3010 = 3`）。**换到任何底都行，只要上下用同一个。**

### 所以两个写法是同一件事

```
n = log₁.₀₈ 2          ← 真正的答案（"话"）
n = ln 2 ÷ ln 1.08     ← 换底之后（可执行的算式）
```

## 五、为什么是 72（近似从哪来）

把 `ln2 = 0.6931` 的百分号搬到分子上 → `69.31`。

而 `100 × ln(1.08) = 7.696`（**比 `100 × 0.08 = 8` 略小**），所以精确值是 `69.31 ÷ 7.696 = 9.006`。

**但用 8 除：`69.31 ÷ 8 = 8.66`**——心算时略少了点。

**为了让心算准一点，大家把分子从 69 调到 72**（`72 ÷ 8 = 9` 正好对上）。

**所以 72 不是天上掉的，是刻意挑的一个"好除又差不多准"的数。**

## 六、🔴 适用边界（它的偏差在哪）

因为 `ln2 ÷ ln(1+r)` 不是常数，随利率变：

| 年化 | 该用的分子 | 72 的偏差 |
|---|---|---|
| 4% | 70.7 | 略乐观（几乎没差） |
| 8% | 72.1 | **几乎正好** |
| 12% | 74.2 | 略悲观 |
| 24% | 77.4 | **明显乐观**（说 3 年，实际约 3.2 年） |

**结论：6% ~ 10% 放心用；高利率（15% 以上）算出来的年数要往上加一点。**

**验证方法**（浩总亲算过）：年化 24%，`1.24³ = 1.9066`，三年还没到 2 倍 → 72 说的 3 年偏乐观。

## 七、🔴 72 法则真正的用处：把"翻倍次数"变成加法

**它最大的价值不是算年数，是让你数"翻了几次倍"。**

因为复利是乘法，但**"翻倍次数"是加法**：

- 翻 1 次 = 2 倍
- 翻 2 次 = 4 倍
- 翻 3 次 = 8 倍
- 翻 4 次 = 16 倍

**每翻一次，前一次的全部都要再翻一遍。** 次数差 1，结果就差一倍。

对比 36 年（浩总走过的）：

- 年化 8%（9 年翻倍）：36 ÷ 9 = 4 次 → **16 倍**
- 年化 4%（18 年翻倍）：36 ÷ 18 = 2 次 → **4 倍**

**收益率只差一倍，结果差 4 倍。这才是复利吓人的地方。**

⚠️ **口径提醒**：翻倍是"到达"式的，通常按整数说。60 年年化 3%（24 年翻倍）→ **完整翻 2 次（48 年），剩 12 年翻不完第 3 次**。要说"变成 5.65 倍"（`2^2.5`），别说"翻了 2.5 次"——后者容易让人以为真翻了两个半跟头。

## 八、⚠️ 最大的用处：它是个"可信度探测器"

72 法则有个隐含前提——**这个收益率能一直保持。**

- 银行理财 3% 能保持很多年 → 可以套
- 有人说"年化 24%，三年翻倍" → **这段数字本身就该让你停一下**

**能做长期年化 24% 的，人类历史上没几个人（巴菲特长期约 20%）。**

**72 法则让你把"年化 X%"翻译成"多少年翻倍"，然后拿这个数去问：这个速度，可信吗？**

## 九、几个手算记录（2026-09-29 实走）

| 年化 | 翻倍年数 | 长周期结果 |
|---|---|---|
| 8% | **9 年** | 36 年 → 4 次 → **16 倍** |
| 4% | **18 年** | 36 年 → 2 次 → **4 倍** |
| 3% | **24 年** | 60 年 → `2^2.5` → **5.65 倍** |
| 24% | 72 说 3 年（实际约 3.2 年） | 边界验算 |

**10 万块、60 年的一笔账**（说明这个法则的分量）：

- 年化 3% → `60÷24 = 2.5` 次 → **56.5 万**
- 年化 8% → `60÷9 ≈ 6.67` 次 → **约 1010 万**

**同样 10 万、同样 60 年，差在"年化 3%"和"年化 8%"这五个字上。**

## 附：对数复习（2026-09-29，浩总说"对数是我高中学的"）

这张卡里用到两个对数工具，都是高中内容，捡回来的路径如下：

**① 对数＝反过来的指数**

- `2³ = 8`（指数：给次数算结果）
- `log₂8 = 3`（对数：**给结果问次数**）

**② 两条特殊值**：`log 1 = 0`（任何底）／`log 自己 = 1`（任何底）

**③ 三条法则**（高中的全部）

```
log(A × B) = logA + logB     ← 乘法变加法
log(A ÷ B) = logA − logB     ← 除法变减法
log(Aⁿ)    = n × logA         ← 指数搬下来（推导翻倍公式就靠这条）
```

**④ `ln` 和 `log` 的区别**：底不同。`log` 底是 10，`ln` 底是 `e ≈ 2.718`。**换底之后结果完全一样**，习惯上用 ln。

**练习记录（八道全对）**：`log₂32=5`／`log₃27=3`／`log₁₀10000=4`／`log₉1=0`／`log₆6=1`／`log₂8+log₂4=5（=log₂32）`／`log₃81−log₃9=2（=log₃9）`／`log₂8³=9`。

**⑤ 函数图像长什么样**

两条曲线（`ln x` 和 `log₁₀ x`）的形状完全一样，只有一处不同：

- **都过 `(1, 0)`** —— 因为任何数的 0 次方都等于 1，所以 x=1 时 y 必然是 0。**两条线在这里相交。**
- **在 x=1 右边往上爬，越爬越慢**（曲线越来越平）
- **在 x=1 左边往下跌，永远碰不到 0**（x=0 处无定义，是垂直渐近线）
- **`ln` 比 `log₁₀` 更陡**，因为它的底更小（`e ≈ 2.718 < 10`）。**底越小，曲线越陡。**

**⑥ 🔴 图像上最要紧的一条性质：横着翻倍，竖着加法**

| x 从 | 到 | x 翻几倍 | y 增多少 |
|---|---|---|---|
| 1 | 2 | 2 倍 | `ln2 − ln1 = 0.69` |
| 2 | 4 | 2 倍 | `ln4 − ln2 = 0.69` |
| 4 | 8 | 2 倍 | `ln8 − ln4 = 0.69` |
| 8 | 16 | 2 倍 | `ln16 − ln8 = 0.69` |

**每一行都加 0.69，不管从哪儿开始。** 横轴在乘（×2 ×2 ×2），纵轴在加（+0.69 +0.69 +0.69）。

**这就是"乘法变加法"在图像上的样子——对数的全部本事就在这儿。**

（这也是曲线越来越平的原因：x 要横着翻好几倍，y 才加那么一点。）

**⑦ 对数能解决的生活问题（四类）**

1. **多久翻倍** —— 钱、粉丝、用户数。72 法则就是它。
   > 82 粉、每篇乘 1.3 倍 → `ln(1000÷82) ÷ ln1.3 = 2.501 ÷ 0.262 ≈ 9.5` → **约 10 篇到 1000 粉**
2. **把"翻多少倍"变成感觉** —— 人脑对倍数是失灵的。1 万→100 万是 100 倍，100 万→1 亿也是 100 倍，**感觉差很远，倍数完全一样**。看到大数字先问"翻了几倍"。
3. **分贝、地震、pH 全是对数** —— 因为这些量的实际跨度太大（声音能量差 1 万亿倍才写成 130 分贝；**地震 6 级和 7 级能量差 31.6 倍**；**pH 差 1 就是 10 倍**）。
   **规律：只要一个量能跨好几个数量级，就用对数把它压平。**
4. **反推规模和代数** —— 病毒 R0=3 的病毒传 8 代是 `3^8 = 6561` 人。**问"翻了几代"比问"乘了几倍"好算得多。**

**⑧ 一个防错动作：先粗估数量级，再细算**

算完这类对数题，**先心算一个大概，挡掉明显错的结果**。

> 例：`1.3^10` 是多少？`1.3³ ≈ 2.2` → `1.3⁶ ≈ 4.8` → `1.3⁹ ≈ 10.6`。10 次就到 10.6 倍了，所以 82 粉到 1000 粉是**约 10 篇**，算出 20 篇明显不对。

## 一句话总结

**72 ÷ 年化数字 = 翻倍年数（6%~10% 最准）。**

**精确版是 `ln2 ÷ ln(1+r)`，本质就是问"1.08 要乘自己几次才到 2"——72 是把 ln 换成一个好除的固定数字的产物。**

**它的价值有两层：把收益率翻译成时间，以及——拿这个时间去质问那个收益率可不可信。**

**对数的核心一句话：横着翻倍，竖着加法（`×(1+r)` 变成 `+ln(1+r)`）。**
