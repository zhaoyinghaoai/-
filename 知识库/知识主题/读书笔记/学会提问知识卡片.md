# 学会提问 · 可运行知识卡片

> 用姜胡说「可运行知识卡片 4+2」格式，把《学会提问》读书系列（第9–13天）压成"一看就能跑"的卡片。
> 4 主区块：① 一句话本质 / ② 因果原理 / ③ 可执行方法 / ④ 场景与边界。
> +2 补位：实操卡补「情境/结果/经验等级」；洞见卡补「来源/验证计划/命运分流」。

---

## 卡片 1：纯观点（情绪拉满，证据是零）〔洞见卡〕

**一句话本质**：没有证据支撑的断言只是"纯观点"——再激动也不等于真。

**② 因果/原理**：情绪是放大器，不是证据。一句话戳中你（愤怒/认同/恐惧），你会误以为"说得好对"，但"戳中"≠"有依据"。作者布朗把无证据支撑的断言称为 mere opinion（纯观点）。我们常被情绪带着走，把"爽"当成"对"。

**③ 可执行方法**：刷到/听到一句特别戳你的话 → 停 3 秒，问一句"证据呢？它拿出了什么事实、数据、例子？"答不上来 → 在心里标记为「纯观点」，不拿它当结论。

**④ 场景与边界**：适用 = 刷到爆款观点、别人热荐、自己"说得真对"的瞬间。不适用 = 已经给出证据的观点（这时该进入「掂分量」卡）。失败恢复 = 发现自己被带节奏，回到"问证据"这一步即可。

**+2 补位**
- 来源：《学会提问》纯观点章；验证计划：下次刷到戳心视频，先问证据再决定信不信；命运分流：能持续做到 → 少被带节奏、省时间；做不到 → 继续当情绪韭菜。

## 卡片 2：掂分量（理由 vs 证据 / 查来路 / 材料真假）〔实操卡〕

**一句话本质**：听到"稳赚""肯定行"，先掂两层——理由是真是假？来路靠不靠得住？再怀疑材料本身是不是假的。

**② 因果/原理**：一个结论 = 理由 + 证据撑着。理由回答"为什么"，证据是事实。很多人只给指令/口号（"跟着我做"）没有证据；就算有证据，也可能来路不明（"我朋友在做"是传闻）；甚至材料是假的（数据编的、例子挑着讲）。三层任一塌，结论不值钱。

**③ 可执行方法**：听到诱人结论 →
1. 找出理由和证据，先区分"这是理由还是指令"（理由回答为什么，指令只说去干吧）；
2. 给证据过筛：第一层 = 是不是事实（传闻站不住）；第二层 = 来路正不正（谁说的、图什么）；
3. 怀疑材料本身：数据/例子会不会是编的。三层任一过不了 → 不信、不投钱。

**④ 场景与边界**：适用 = 别人推荐项目/产品/赚钱法、刷到"月入十万"之类。不适用 = 自己已验证过的小事。失败恢复 = 拿不准就"先不投钱、先查证"。

**+2 补位**
- 情境：刷到"跟着我做，月入十万"。结果：发现只有指令没证据 → 放弃。经验等级：初级（刚练，概念区分仍要抠）。

## 卡片 3：抽象词多重解读（说清是本分）〔实操卡〕

**一句话本质**：词越抽象，越容易被各说各话；把话说清楚，是一种本分。

**② 因果/原理**：抽象词（"尽快""问题不大""你看着办"）像多孔容器，每个人往里塞自己的理解。说话人以为说清了，听的人猜出另一种意思 → 纠纷。书里说：想让人信你，说服者有责任先澄清歧义。含糊的代价比具体贵——表达不好不是词汇少，是脑子里没有稳定的表达系统。

**③ 可执行方法**：今天起把口头禅换成具体话——
- 不说"很累" → "从早上八点开会到下午五点，脑子木了"；
- 不说"尽快" → "周三下班前"；
- 不说"一会儿查" → "现在查，两分钟给你结果"。
微信回消息前先想一句：对方要不要猜？

**④ 场景与边界**：适用 = 跟人约事、回客户、安排活。不适用 = 已双方默认的细节。失败恢复 = 发现对方理解偏了，立刻补一句具体时间/标准。

**+2 补位**
- 情境：快递点客户微信问件到没到。结果：改口"现在查，两分钟给你" → 纠纷少一半。经验等级：已验证（浩总亲测有效）。

## 卡片 4：找结论（目的藏不住）〔洞见卡〕

**一句话本质**：一段话里，结论往往藏在"他到底想让你干嘛"后面。

**② 因果/原理**：说服型内容先抛结论/观点，再补理由。先抓"他最后要我做什么、信什么"，才不会被中间的情绪和例子带跑。结论找不到，后面的理由再漂亮也无处安放。

**③ 可执行方法**：读一段带观点的文字 → 先问"他想让我得出什么结论？"再回头看他的理由撑不撑得住。卡住时就找"所以呢？他要我怎样？"

**④ 场景与边界**：适用 = 看文章、听人安利、刷短视频观点。不适用 = 纯信息播报（天气预报、通知）。失败恢复 = 分不清时，把"他想让我信/做啥"写下来，往往一句话就显形。

**+2 补位**
- 来源：《学会提问》找结论章；验证计划：下条推送先找结论再细读；命运分流：练成 → 一眼看穿套路；不练 → 被结论牵着走。

## 卡片 5：AI当考官（读后先考再写）〔实操卡〕

**一句话本质**：读完一章别让 AI 代写，让 AI 当考官——抽结构、反问、找你理解里的漏洞，答完再动笔。

**② 因果/原理**：大多数人用 AI = 帮我总结/提炼/写。姜胡说用 AI = 不让给答案，让找漏洞。输入质量决定输出质量：先被考、被指出盲区，写出来的东西才有锋利度，而不是 AI 味浓的复述。

**③ 可执行方法**（触发词：口述后说"考我/用考官模式/AI当考官"）：
1. **概念区分题**：用自己的话拆核心概念（如"理由 vs 证据"）；
2. **实战应用题**：给现实场景/金句，让你过两层筛子（掂分量、查来路）；
3. **找漏洞题**：挑战你结论的边界（如"证据本身也可能是假的"）。
批改：先肯定对的部分，再纠正，给"锚句"帮记，答不出时引导你自己推。题目数量按章节复杂度加减（常 2–4 题，由易到难），答到没漏洞为止再成文。

**④ 场景与边界**：适用 = 每天读书口述后、写文章前。不适用 = 赶时间纯记录、或已经很熟的内容。失败恢复 = 没空就直接成文，但标注"未过考官"回头补。

**+2 补位**
- 情境：第12天《掂分量》首次跑通，浩总三题全答对/自推，文章补进"材料是假的"层。结果：理解更扎实、文章更有锋利度。经验等级：已跑通 1 次，建议设为默认。

## 卡片 6：读书别变成"为记录而读"（元反思）〔洞见卡〕

**一句话本质**：读书别滑向"为了记录而读"——囤知识不内化，只是仓鼠囤货。

**② 因果/原理**：当目标从"搞懂、能用"变成"今天又读了、又记了"，记录本身成了奖赏，成长反而停了。书读了一肚子，落不到行动，就是库存（呼应姜胡说"低库存、高周转"）。

**③ 可执行方法**：每读完一章问自己"这条我明天能用上吗？"答不出 → 别急着记，先想一个能用上的具体场景；记录是为用，不是为凑数。

**④ 场景与边界**：适用 = 每天读书打卡、记了一堆笔记却无变化。不适用 = 纯娱乐性阅读。失败恢复 = 发现自己又在为打卡而读，停一天，换成"只输出一条能用上的话"。

**+2 补位**
- 来源：第11天元反思《读书成了任务记录成了瘾》；验证计划：本周每篇笔记都逼自己写"明天怎么用"；命运分流：做到 → 读书真长本事；做不到 → 继续囤货式成长。

## 卡片 7：姜胡说三步读书法（选书/挑爆点/输出）〔实操卡〕

**一句话本质**：别从头硬啃——选好书、挑戳你的章节、结合自身输出，三步把书变成自己的。

**② 因果/原理**：从头读到尾效率低、忘得快；先翻目录挑最有感触的章节（作者加粗 + 读者热议 = 情绪爆点），精力集中在能触动自己的地方，输出时才有真情实感，自媒体也才好看。

**③ 可执行方法**：
1. **选书**：个人成长类好书，不贪多（《原子习惯》《深度工作》《穷查理宝典》等）；
2. **读书（最关键）**：翻目录 → 挑"我感兴趣 + 作者加粗 + 读者热议"三条件都满足的章节重点读；
3. **输出**：再读一遍 → 结合自身经历 → 整理成文章/口播。

**④ 场景与边界**：适用 = 任何想读且想产出的书。不适用 = 需要系统啃完的教材/专业书。失败恢复 = 读不下去就换章节或换书，不硬撑。

**+2 补位**
- 情境：浩总每天读《学会提问》只盯戳自己的句子。结果：8% 进度就出 3 篇文。经验等级：已跑通。

## 怎么用这批卡片

- **低库存、高周转**（姜胡说信念）：卡片是"能跑"的，不是收藏的。每张都该能直接变成一条朋友圈、一段口播、或下次读书的提醒。
- **和文章的关系**：`产出/读书内容/成品文章/` 是完整成文；本页是压过的"原子知识"，写新文章时来这儿捞素材。
- **待补**：无——7 张卡已覆盖第9–13天全部内容（5 张概念/方法卡 + 第11天元反思卡 + 姜胡说三步读书法卡）。
