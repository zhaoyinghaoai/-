# 蹲下去：先接住情绪，再看

> 浩总在 W38 周（09-16 ~ 09-19）连续四天练的同一门功课：**不急着管，先看见**。回信里四天连续点破——"连着四天，你在练同一样东西"。这是他从"教女儿什么"到"先看见她在看什么"的一次姿态大转弯。

## 一句话

**站着，人在对面，是评判者；蹲下去，人在旁边，看的是同一个东西。**（浩总 09-18 自己说的）

## 两种姿势的对照

| | 站着（评判者） | 蹲下去（同看） |
|---|---|---|
| 位置 | 人在对面 | 人在旁边 |
| 看什么 | 她**能不能成才**（能力信号） | 她**在看什么**（世界本身） |
| 先做什么 | 讲道理 / 纠正 / 评价 | 接住情绪 / 陪她看 |
| 妹妹踩泡泡 | （不适用——还没被派任务） | "哇，你看这个颜色" |
| 姐姐踩泡泡 | "踩它干嘛？脏不脏？" | （最难做到的一次蹲下） |

## 四天功课时间线（2026-09）

| 日期 | 功课 | 动作 |

## 镜头问题（09-18 最狠的一句）

浩总原话：「**如果换成赵春林的话，我可能会批评她的。**」

- 姐姐被放在"将来要担事的人"的位置上，她做的事自动被当**能力信号**读（这样对不对？有没有长进？）；妹妹还没被派任务，做的事只被当**她在看什么**读。
- **不是爱有差别，是镜头不一样。** 任务越重，镜头越难换回来。
- 解法很轻，不用改育儿思路：哪次她做一件"没用的、不涨本事的"事，先蹲一次，什么都不说，陪她看三秒。⚠️ 别提前宣布"爸爸以后要蹲下来看你"——一说就变成新任务。

## 要点

1. **先接住情绪，再问原因**——顺序反了（一哭就问"你怎么了"）她只会哭得更凶；等哭完再问，"为什么"才答得出来。
2. **解释解决"去不去"，解决不了"我不想被留下"**——她不是不懂，她是懂了还是难过。递过来的是情绪，回道理对不上。
3. **刹车不发生在开始，发生在中途**——"吼了一句就收住"比"忍住没吼"真实，也比它有用：圣人式的忍住只能演一次，中途刹住能演一辈子。
4. **真正的收获不是"她不哭了"，是"她愿意当着你的面哭"**——她知道这儿是安全的。
