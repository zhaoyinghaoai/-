# 家教：言传身教，以身作则

> 「每日阅读·家庭是人生的第一个课堂」的提炼——家庭是第一个课堂、父母是第一任老师；好的教育是言传身教、以身作则，严管+厚爱，知识与品德并重，成绩与身心健康兼顾。

## 三个要点

| 要点 | 含义 |
|------|------|
| **第一课堂 / 第一任老师** | 孩子从牙牙学语就开始接受家教，有什么样的家教就有什么样的人 |
| **言传身教、以身作则** | 好的教育是爱与陪伴、尊重与理解；父母做好榜样，孩子自会跟随 |
| **严管+厚爱，德才兼备** | 严管与厚爱并重、知识与品德并重、成绩与身心健康并重 |

## 这套理念的逻辑

1. 先认「位置」：家庭是第一个课堂，父母是第一任老师——教育不是交给学校的任务，从家里就开始了
2. 再定「方法」：最好的教法不是讲道理，是「做给孩子看」——言传身教、以身作则
3. 最后配「平衡」：严管不冷、厚爱不溺；教知识更培品德；看成绩更看身心健康

## 对浩总的落地

- 浩总有两个女儿（3岁半 / 1岁半），正处在「牙牙学语」起步阶段，这个阶段父母的一言一行都是教材。
- 「言传身教」对浩总尤其有意义：与其讲一堆大道理，不如让孩子看到爸爸每天上午雷打不动写东西、读书——爸爸怎么过日子，孩子就学会怎么过日子。
- 「严管+厚爱」提醒：管教不是凶，是「有边界 + 有温度」；别只盯成绩，身体和心里健康同样要紧。
