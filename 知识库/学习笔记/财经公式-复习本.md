## 一、凯利公式

知识卡：[[凯利公式-押多少是第二道题]]

### 第 3 天（10-01 出题 / 10-02 交卷）✅ 全对

**题目**

20 张牌，9 张红、11 张黑。押红赢。
押 1 块钱，中了**连本带利拿回 2.5 块**；没中，这 1 块归庄家。
本金 1200 块，问这一把该押多少？

> 出题意图：「拿回 2.5」是故意写反的说法，专打浩总唯一反复卡的那一格——**赔率是净赚不是拿回**。

**浩总的推导（原样照抄）**

```
净赔率=(2.5-1)/1=1.5，赢的概率=9/20，输的概率=11/20
门槛=1/(1+1.5)=2/5。2/5小于9/20所以可以玩
f*=(1.5*9/20-11/20)/1.5=0.083
1200*0.083=99.6
```

随后补：`100/2 = 50 块钱`（半凯利）

**批改**

| 格 | 答案 | 判 |
|---|---|---|
| 赔率 | (2.5−1)/1 = **1.5** | ✅ **在迷惑说法下自己先减本金，卡点翻篇** |
| 赢面 / 输面 | 9/20 ／ 11/20 | ✅ 直接从题面抄，没自己算 1−0.45（上次串格那次的防身动作他自己用上了） |
| 门槛 | 2/5 = 0.4，比赢面 0.45 小 → 可玩 | ✅ 比的是赢面，没跟输面比 |
| f\* | (1.5×9/20 − 11/20)/1.5 = **0.083** | ✅ 正确，且 = **1/12** |
| 押多少 | 1200 × 0.083 ≈ 100 | ✅（他自己约成 100） |
| 半凯利 | 100 ÷ 2 = **50** | ✅ **比我给的路更利索** |

**这一轮的技术点：他走的路比教的路好**

- 我教的是「先砍比例再乘」：`0.083 → 0.0415 → ×1200 ≈ 48`
- 他走的是「先算金额再砍半」：`0.083 ≈ 1/12 → 1/12×1200 = 100 → ÷2 = 50`
- **100 ÷ 2 比 0.0415×1200 干净，因为 1/12 × 1200 正好是整数。**
- ⚠️ 我最初按自己的路算出 48，判他「50 差 2 块是精度问题」——**当场收回**。不是精度差，是另一条更好的路。

**他自己交代的打法（值得单独记）**

> 「我怕误差太大，所以在最后那一步才四舍五入。」
> 「我这表没有纸，要是动手算的话，我会把它做成分数计算的。」

→ **他不是"最后才约"，是"一直不约，全程用分数"。** 小数在脑子里存不住，`1/12` 记住就永远是 `1/12`。**没纸反而逼出了正解。**

→ 顺手教了他一招把分数路走完整：**`1.5` 就是 `3/2`，除以 `1.5` 等于乘 `2/3`**。这样连 `0.083` 都不用出现：
```
1.5 × 9/20 = 13.5/20 = 27/40
27/40 − 11/20 = 5/40 = 1/8
1/8 ÷ 3/2 = 1/8 × 2/3 = 1/12
```

**过程中的小插曲**

他先发出 `1200 × 0.083 = 99.6` 就按了回车，隔一句补「我本来想说的是半凯利 50 块钱的，键盘按错了，提前发出来的」。

→ 由此固化一个自检法：**心算的数与纸上算的数差多少？差一点＝精度问题，放过；差一个量级＝某格填错了，回去查。** 今天差 2 块，是前者。

### 第 7 天（10-05 出题 / 10-05 交卷）✅ 全对 · 一格未错

**题目**

24 张牌，**11 张红、13 张黑**，押红赢。
押 1 块钱：中了，**连本带利拿回 3 块**；没中，这 1 块归庄家。
本金 **1600 块**。这一把该押多少？

> **出题意图**：凯利第 7 天（距上次复习 4 天）。题面继续用「连本带利拿回 X」的说法，**再考一遍赔率那格**——他唯一的复发性卡点。数字全部换新。
> **当天撞车**：同日到点四项（凯利7／折现3／夏普3／DCF1），按「距上次复习最久」出凯利，其余顺延。

**浩总的推导（原样照抄）**

```
赢的概率=11/24，输的概率13/24，净赔率=(3-1)/1=2
门槛=1/（1+净赔率）=1/（1+2）=1/3，因为1/3小于11/24，所以可以玩
（赢的概率*净赔率-输的概率）/净赔率=（11/24*2-13/24）/2=9/48
1600*9/48=300
据凯利公式得300元，实际押半凯利150元。
```

**批改**

| 格 | 判 |
|---|---|
| 净赔率 | **`(3−1)/1 = 2`** ✅ **连续第二次自己先减本金——卡点翻篇** |
| 赢面 / 输面 | 11/24 ／ 13/24 ✅ 直接从题面抄，没去算 `1−11/24` |
| 门槛 | `1/(1+2) = 1/3`，比 11/24 小 → 可玩 ✅ 比的是赢面，没跟输面比 |
| f\* | **9/48** ✅ **值完全正确**（＝ 3/16），只是没约分 |
| 押多少 | `1600 × 9/48 = ` **300** ✅ |
| 半凯利 | **150** ✅ **这次是他自己带上的**（第 3 天那回是我教的） |

**🔑 三个动作值得点名**

1. **赔率那格连续第二次自己减本金** —— 第 3 天还得我拿「拿回 2.5」绕着问，这次眼睛一扫就减
2. **全程分数，一个小数都没出现** —— 兑现了他第 3 天说的「我这表没有纸，会做成分数计算」
3. **半凯利自己想的** —— 不用提示

**顺手提的一处（不是错）**：`9/48` 可约成 **`3/16`**。

- **下一步更好算**：3/16 一眼是「1600 的十六分之三」，`1600÷16 = 100`，`×3 = 300`，心算两秒
- **约分本身就是免费自检**：约不出整数，多半前面某格歪了；约得干净，等于顺手验了一遍
- 3/16 ＝ **18.75%** ＝ 该押本金的十八点七五

**结论：凯利第 7 天 · 全对。隔四天，全链条一格不差。**

## 二、期望值

知识卡：[[期望值-这局平均下来值多少]]

### 第 3 天（10-02 出题 / 10-02 交卷）✅ 过 · 挂一条观察项

**题目**

摸球，不用押本金。
红球 **40%** → 大赚 **9 元**
蓝球 **40%** → 小赚 **9 元**
黄球 **20%** → 亏 **6 元**
这一摸平均下来值多少？该不该玩？

**浩总的推导（原样照抄，含两版）**

```
第一版  0.4*9 + 0.4*9 − 0.2*6 = 3，完
        （给了「把算式念一遍」这个动作之后）
第二版  6，玩
```

他自述的错因，原话：

```
我是把 0.4×9 想成了 0.2×9，还有 0.2×6，
我想成了 0.1×6，所以说它的得数不准，
得数是 3，得数应该是 6
```

**批改**

| 格 | 判 |
|---|---|
| 项数（三项） | ✅ 一个结局没漏 |
| 方向 | ✅ 两个 9 写加、6 写减。名字不同（大赚/小赚）没把他带跑 |
| 抄比例 | ✅ 0.4 / 0.4 / 0.2 直接从题面抄，加起正好 1 |
| 算式的形 | ✅ `0.4×9 + 0.4×9 − 0.2×6` —— **标准答案的形状，一个字没错** |
| 得数 | ❌ 首版 3 → 念一遍后改对 6 |
| 结论 | ✅ 正期望值 → 玩 |

**这一轮挖出的新坑：「比例串格」的第二种形态**

算式从头到尾全对，错在**心算时乘数进脑子就串了**——`0.4×9` 按 `0.2×9` 算、`0.2×6` 按 `0.1×6` 算，得 `1.8+1.8−0.6 = 3`。**两个比例同时被"看小一半"，凑出的 3 是个整数，看着毫不违和——错得不像错。** 这与 9-29 那次（`3/20` 抄成第二项比例）是**同一个动作「抄比例」的两种翻车法**。

**出题人责任（我的失误）**：为考"看方向不看名字"故意让两个"赚"同为 **9** → `0.4×9` 与 `0.4×9` 长得一模一样，**抄串了看不出来**。已改三条：金额必须互不相同／比例避免"正好一半"的关系／挑"错一半就对不上整数"的数字。

**防身动作升级**：光"念算式"不够——**念的时候数字必须念全**（"**零点四**乘九"），只念结构听不出来。他正是靠念全数字从 3 改到 6。

### 第 7 天（10-06 到期 / 10-07 实出 · 实交）✅ 全对 · 四项一项没错

**题目**

一个箱子里 **25 个球**，摸一个出来，**不用先交钱**：

- **4 个红球** —— 赚 **18 元**
- **7 个黄球** —— 赚 **9 元**
- **6 个蓝球** —— 赚 **3 元**
- **8 个黑球** —— 亏 **4 元**

**第一格**：这一摸，**平均下来值多少**？
**第二格**：这局**该不该玩**？

> **出题意图**：第 7 天，**换形状**——上次（第 3 天）是三结局，这次**四结局**；球数与金额全部换新。
> **吸取第 3 天的教训**：那次我故意让两个"赚"同为 9 元，结果他抄串了也看不出来（**出题人责任**）。这次**四个金额互不相同（18／9／3／−4）**，比例也不构成"正好一半"的关系，**防串**。

**浩总的推导（原样照抄）**

```
4/25*18+7/25*9+6/25*3-8/25*4=72/25+63/25+18/25-32/25=121/25，平均值是121/25
因为121/25＞0，所以该玩
```

**批改**

| 格 | 判 |
|---|---|
| 四项概率 | 4/25 ／ 7/25 ／ 6/25 ／ 8/25 ✅ 从题面直接抄，没串 |
| 四个金额 | 18 ／ 9 ／ 3 ／ **−4** ✅ **方向全对**——三个"赚"写加，一个"亏"写减 |
| 通分相加 | `72/25 + 63/25 + 18/25 − 32/25 = 121/25` ✅ |
| 判据 | `121/25 > 0` → 该玩 ✅ |

**🔑 三个动作值得点名**

1. **他自己用上了统一分母** —— 四项全是 `/25`，**分子直接加减**（72＋63＋18−32），**全程没出现一个小数**
2. **判正负时没先化成小数** —— `121/25 > 0` 直接判，**省一步，也少一次出错机会**
3. **四个结局一个没漏** —— 上一道是三结局，这道是四结局，**没人提醒他"现在有四项了"**

**顺手给的自检动作（这形状的题第一道检查）**

**所有概率加起来必须正好等于 1**：`4/25 + 7/25 + 6/25 + 8/25 = 25/25 = 1` ✓
**加起来不等于 1，就是某一项抄错了** —— 这个检查比回头逐项核对快得多。

**对照第 3 天**

第 3 天同样形状的题，他在"**比例进脑子会串**"上翻过一次（0.4 看成了 0.2）。**这次四项、全分数，一个都没串。** 当天给他定的防身动作是"念算式，数字念全"——**这次压根没用上，因为没串。**

**当天追加一问（20:13 问 / 20:18 答）✅ 答对，而且自己站到了另一边**

**问**：如果这局改成「**花 5 块钱才能摸一次**」，你还玩不玩？

**浩总的答（原样照抄）**

```
我要是给5块钱别人。我不玩
要是别人给我5块钱，他要玩，就让他玩
```

**批改**

| 格 | 判 |
|---|---|
| 我花钱玩（花 5 块买一摸） | **不玩** ✅ 对的。准确说：`4.84 − 5 = −0.16`（亏），所以不玩 |
| **别人给我 5 块、让他玩** | ✅ **题面没问，他自己站到了庄家那边** |

**🔑 这一问最值钱的：他又一次自己走出来了「两面性」**

同一个 **4.84**，**成本放在哪边，结论就往哪边翻**：

- **玩的人**：`4.84 − 5 = −0.16` → 亏 0.16 → **不玩**
- **收钱的人**：`5 − 4.84 = +0.16` → 赚 0.16 → **让他玩**

**两个数一样，符号相反——这就是零和：一方的亏，正好是另一方的赚。**

**🔗 和 10-05 的 NPV 那道题是同一个结构**

- **10-05 NPV**：「**如果我要租的话，从乙处租。如果是我转让的话，我转给甲。**」——买方 / 卖方
- **10-07 期望值**：「**我要是给 5 块钱别人，我不玩。要是别人给我 5 块钱，他要玩，就让他玩。**」——玩的人 / 收钱的人

**两天两次，他都在题面没问的地方自己翻到了对面。** → **这不是运气，是他的思维习惯**（管理者 / 创业者视角）。

**⚠️ 顺手把两个式子的分工钉清楚了**

- **EV 管「概率」**（不确定的钱）——这题的 4.84 就是它
- **NPV 管「时间」**（早到晚到）——这道题**没有时间差**（摸完立刻开奖），所以折现那一步用不上，**`EV − 成本` 直接就是净收益**
- **如果这一摸改成「一年后才开奖」**，就得先把 4.84 折回今天再减成本 —— **那才是完整的 NPV**

**结论：期望值第 7 天 · 全对。**（追加一问已答，按规矩补进本子）

## 三、72 法则

知识卡：[[72法则-多少年翻一倍]]

### 第 3 天（10-03 出题 / 10-03 交卷）✅ 过 · 挂一条观察项

**题目**

两格都要答，合上知识卡自己推。
**第一格**　一笔钱，年化 **2.5%**，多少年翻一倍？
**第二格**　另一笔钱，年化 **9%**。同样放 **36 年**，最后是原来的**几倍**？

**浩总的推导（原样照抄，五版）**

```
第一版（14:05）
72/2.5 = 28.8（年）
72/9 = 8（年）　36/8 = 4.5 倍

第二版（14:11）
应该是 n 的 4.5 次方（n 是本金且大于 1）

第三版（14:12）
算不出来

第四版（14:18）
2^4.5 = 2.63

第五版（14:20）
2^4.5 = 22.63
```

**批改**

| 格子 | 判 |
|---|---|
| 第一格 28.8 年 | ✅ 全对。72 ÷ 2.5 直接除，没被小数绊住 |
| 72÷9 = 8 年 | ✅ 对 |
| 36÷8 = 4.5 | ✅ **而且这一步最值钱** —— 「36 年等于翻几次」这个转换是**他自己做出来的**，正是卡里第七节最想让他会的那一招 |
| 标「4.5 **倍**」 | ❌ 数字对、名字错。4.5 是「翻了几**次**」，不是「几**倍**」 |
| 「n 的 4.5 次方」 | 🟡 **方向对了**（把次数放进指数的位置），只错在底数：底数是「翻一次乘的那个数」＝**2**，不是本金 |
| 2.63 | ❌ **量级错**：`2^4.5` 必须落在 **16 和 32 之间**，2.63 掉到 16 以下 |
| 22.63 | ✅ 对（`2^4.5 = 22.627`；手算 `16×1.41 = 22.56` 也对，两个口径都接受） |

**结论：过 · 挂一条观察项**

- **判过理由**：卡里第七节那招（把「几倍」换成「翻几次」）**是他自己用的**，方向没跑；**他错的每一处，都落在"我临时加进来的新东西（分数指数）"上，不在 72 法则本身。**
- **观察项**：**10-06 第 7 天出纯整数的「次数 → 倍数」题，补验这一跳。**
- **末两版只差一个 2**（2.63 vs 22.63）＝ 抄数漏位，与 10-02 期望值那次是**同一个动作的第三回**。「念算式」又一次救回来了。

**🔴 这一轮我的三处失误（当场认，已进两个 skill）**

1. **出题越界**：为考"边界"故意用 **4.5 次（半次）**，把他推到**从没学过的「分数指数」**前，他答「算不出来」。**他卡的不是 72 法则，是我塞进来的新知识点。** → 新规：**72 法则题只用整数次翻倍**（要考「次数→倍数」改用 `72÷8＝9 年 → 63÷9＝7 次 → 2⁷＝128 倍`）。
2. **粗估只给了一半**：给了「0.5 次方落在 1~2 之间」，**漏了「4.5 次方落在 16~32 之间」**，他报 2.63 时本可自己挡掉。 → 新规：**凡把指数拆成两半的题，每一半都要给区间。**
3. **同一数字两个角色**：讲牛顿法时拿 **√2** 举例，式子里 2 同时当「目标」和「÷2」（9-29 犯过一次）。 → 新规：**例子的数字不能和公式里的常数撞车。**

**🔑 判过之后他自己往下问了三层（这一场真正多出来的东西）**

① 像这种小数点的指数，怎么算？
② 像这种不是特殊值的开方，怎么算？
③ 公式里那个「2」是 2 次方根的意思吗？

**三层问的全是「方法」和「边界」，一层都不是在要答案。** → 已长成独立知识卡：**[[开方与小数指数-没有计算器也能算]]**

### 第 7 天（10-06 到期 / 10-07 实出 · 实交）✅ 全对 · **观察项结案**

**题目**

一笔钱，年化 **7.2%**。
**第一格**：按 72 法则，这笔钱**多少年翻一倍**？
**第二格**：这笔钱放 **50 年**，最后变成原来的**多少倍**？

> **出题意图**：这是第 3 天挂下的**观察项补考**——那次他把"翻了几次"和"是几倍"混了（算出 `36÷8 = 4.5`，答成"4.5 倍"），而且被我塞的"半次"推到了没学过的分数指数跟前。
> **这次只用整数次翻倍**，专门验那一跳通没通。
> **为什么挑 7.2%**：它是 72 法则**最准的位置之一**——精确值 9.97 年，72 法则给 10 年，**误差 0.3%**。

**浩总的推导（原样照抄）**

```
72/7.2=10年
50/10=5
所以最后变成原来的2^5=32倍
```

**批改**

| 格 | 判 |
|---|---|
| `72 ÷ 7.2 = 10 年` | ✅ 除数是小数，没被绊住 |
| `50 ÷ 10 = 5` | ✅ **这一步算出来的就是"翻了几次"**——第 3 天他卡的就是这一格的**名字** |
| `2^5 = 32 倍` | ✅ **关键就在这一步**：三个数各就各位——**2 是"翻一次乘的那个数"，5 是次数（放指数位），32 才是倍数** |

**结论：72 法则第 7 天 · 全对 · 观察项结案。**

**🔑 三天前的账，今天结清了**

- **10-03** 他答：`36 ÷ 8 = 4.5` → 写成 **"4.5 倍"**（**数字对、名字错**：4.5 是"翻了几**次**"，不是"几**倍**"）
- **10-07** 他答：`2^5 = 32 倍` —— **自己把次数放进了指数位**
- **同一跳，从"混"到"清"，中间只隔了一道纯整数的题。**

**顺手验的一条**：7.2% 时精确翻倍年数 = `ln2 ÷ ln(1.072) = 9.97 年`，离 72 法则给的 10 年**只差 0.3%** —— 印证卡里那张表：**利率越靠近 7~8%，72 越好使**。

## 四、复利公式

知识卡：待建（③复利公式目前只在「财经公式随身卡」里有速查行）

### 第 3 天（10-04 出题 / 10-04 交卷）✅ 过 · 第一格手滑一处

**题目**

本金 **6000 块**，年化 **10%**。
**第一格**　放 3 年，变成多少？
**第二格**　想变成 12000 块（刚好翻一倍），大概要几年？

**浩总的推导（原样照抄）**

```
6000*(1+10%)=7986(元)
PV=FV/(1+r)^n
6000=12000/(1+10%)^n
1=2/(1+10%)^n
n=In2/In1.1=7.273年
```

**批改**

| 格子 | 判 |
|---|---|
| 第一格 得数 **7986** | ✅ **对**（`1.1³ = 1.331`，`×6000 = 7986`） |
| 第一格 算式 | ❌ **漏了指数**——写的是 `6000*(1+10%)`，那只有一次方，等于 **6600**，不是 7986。3 年应该是 `6000×(1+10%)³` |
| 第二格 反解 | ✅ **全对**：`6000 = 12000/(1.1)^n` → `(1.1)^n = 2` |
| 第二格 结果 | ✅ **`n = ln2/ln1.1 = 7.273 年`** |

**→ 第一格的性质：算对了、式子漏了。手滑，不是不会。**

**🔑 这一轮最值钱的两处「跨」**

1. **他自己搬出了折现公式**（`PV = FV/(1+r)^n`）来反解复利问题 —— **复利和折现本来就是同一个式子的两个方向**，这一步是知识点自己接上的，没人提示。
2. **他没套 72 法则估，直接上对数精确解** —— 用的是 9-29 学的那条 `n = ln2 ÷ ln(1+r)`。**他挑了难的那条路，而且走对了。**

**🔑 两把尺子对上了，还顺手校准了 72 法则**

- 72 法则给：`72 ÷ 10 = **7.2 年**`
- 他算的：**7.273 年**
- 差 **1%**

→ 反过来能算出**年化 10% 时"该用的分子"是 72.7**（`7.2725 × 10`）。这跟卡里第五节那张表（4%→70.7、8%→72.1、12%→74.2）**是同一条规律**：**利率越高，分子越大**。他这次是亲手把这条规律验了一遍。

**顺手提的两处**

- `In2/In1.1` 的 **`In` 是 `ln` 打成了大写 I**（读着不影响，提醒一下即可）。
- 第一格的防身动作：**写完算式把「指数」也念一遍**——「六千乘，一加百分之十的**三次方**」。这和「念全数字」是同一个动作，只是这次漏的不是位数，是指数。

## 五、折现／现值

知识卡：待建（目前只在下面「随身卡」里有速查行）

### 第 3 天（10-05 出题 / 10-05 交卷）✅ 全对 · 两格一处没错

**题目**

**第一格**　一张欠条，上面写着"**3 年后付你 4000 元**"。折现率按 **10%** 算。这张欠条**今天值多少钱**？
**第二格**　有人现在拿 **2900 块现金**，要换你手里这张欠条。**换不换？** 说一句为什么。

> **出题意图**：第一格考正向折现（一笔、往回拉 3 年）。
> **第二格是故意设的反直觉判断题**——"手里的现金 vs 三年后的欠条"，凭直觉的人会答"换"（落袋为安），**真算完才知道不该换**。考的是**先算再判断**这个顺序。

**浩总的推导（原样照抄）**

```
PV=FV/(1+r)^3=4000/(1+10%)^3=3005.26元
因为2900小于3005.26所以不换
```

**批改**

| 格 | 判 |
|---|---|
| 第一格 公式 | `PV = FV/(1+r)^3` ✅ 标准形 |
| 第一格 指数 | `(1+10%)^3` ✅ **3 次方没漏**——对照 10-04 复利那道写成了 `6000*(1+10%)` 漏掉指数，**同一个位置，隔一天自己写全了** |
| 第一格 得数 | **3005.26** ✅（4000 ÷ 1.331 ＝ 3005.2592，保留两位正确） |
| 第二格 判断 | **不换** ✅ |
| 第二格 理由 | 「2900 小于 3005.26」✅ **理由就是数，不是感觉** |

**🔑 这一轮最值钱的一处：他没被直觉带走**

"现金 vs 欠条"是个**反直觉题**——多数人第一反应是"现金当然好，落袋为安"。**他没走这条，而是先把 3005.26 算出来，再拿 2900 去比。**

**这个顺序值钱：先算，再判断。** 凭感觉判断的人这一格会答"换"，实际亏 **105.26**。

**顺手补的一条规矩：算出来的那个数，就是你的底价线**

**3005.26 就是这张欠条的底价**：

- 低于 3005.26 → **不换**（亏）
- 高于 3005.26 → **换**（赚）
- 正好 → 换不换都一样

**"要不要出手"这类事，先算这条线。** 有人出价，心里一比就知道，不用每次重新纠结。**折现算出来的数不只是个数——它是底线。**

（省时间的小技巧：判断这一步**整数位就够**。2900 跟 3000 一比就知道低了，不必算到分。他这次算准了没问题，只是说赶时间可以省掉这一步。）

**结论：折现第 3 天 · 全对。**

## 六、夏普比率

知识卡：待建（⑤夏普目前只在下面「随身卡」里有速查行）

> **学习日 2026-10-02** —— 课程表第 5 个（★★★）。

### 第 1 天 · 当堂练习（10-02）✅ 过 · 挂一条观察项

**题目**

三格：① 甲 σ10% ／ 乙 σ18%，都赚 15%、无风险 3%，谁更优 ② 夏普 0.8、收益 14%、无风险 4%，反推 σ ③ 丙 20%/25% vs 丁 10%/8%、无风险 3%。

**批改**

| 格 | 判 |
|---|---|
| ①② 公式与计算 | ✅ 标准形 `(R_p−R_f)/σ`；反推 σ 也对（12.5%）|
| ③ 丙 0.68 ／ 丁 0.875 | ✅ 数算对了 |
| ③ 结论 | ❌ 写成「夏普告诉我丁的收益更多」——**反了** |

**🔴 坑：夏普高 ≠ 收益高** —— 夏普比的是**性价比**，不是**赚了多少**。丙的高收益靠 25% 的高波动堆出来，风险调整后反而不值；丁收益低但波动小（8%），性价比更高。

### 第 3 天（10-08 出题 / 10-08 交卷）✅ 过 · 一处读法当场纠正

**题目**

- 「稳当理财」：赚 **12%** ／ 波动 **10%**
- 「热门赛道」：赚 **21%** ／ 波动 **20%**
- 无风险利率 **3%**

**第一格**　这两个，哪个更值？各自算一个数出来说话。
**第二格**　「稳当理财」这个数，**买 1 块钱相当于花了几分钱的风险去换**？
**加试**（他答「要」）　无风险利率涨到 **6%**，两个重算，现在哪个更值？

**浩总的推导（原样照抄）**

```
（12%-3%）/10%=0.9
（21%-3%）/20%=0.9
因为都是0.9，所以选稳当理财
稳当理财"这个数，我买 1 块钱，相当于花了9分钱的风险去换
```

加试：

```
（12%-6%）/10%=0.6
（21%-6%）/20%=0.75
因为0.75大于0.6，所以手里有闲置不用的钱可以选热门赛道
```

**批改**

| 格 | 判 |
|---|---|
| 两个夏普 | **0.9 ／ 0.9** ✅ 分子减无风险、分母是波动，一格没错 |
| 第一格结论「所以选稳当理财」 | ❌ **两个数一样 → 就是打平，没有哪个更值** |
| 第二格读法「花 9 分钱的风险去换」 | ❌ 位置对、**读法反了**：0.9 是**冒 1 块钱的风险，换回 9 毛钱的超额收益** |
| 加试 0.6 ／ 0.75 | ✅ 全对 |
| 加试结论「0.75 > 0.6 选热门赛道」 | ✅ 对（「哪个更值」就看谁的数大） |
| 加试多出的半句「**手里有闲置不用的钱**」 | 🔑 题面没提，**他自己补的前提** |

**🔑 三处值得点名**

1. **「一样」就是打平**：多赚的 9 个点（21 vs 12）是**多冒了一倍波动**（20 vs 10）换来的，一分便宜没占到。→ 真要在两个里选，得看别的（哪个看得懂、拿得住、费用低），**夏普这关它俩没分出高下**。
2. **他自己补出了「闲置的钱」这层**：题面只问「哪个更值」，他答「**手里有闲置不用的钱**，可以选热门赛道」→ **夏普算的是性价比，它不知道这笔钱什么时候要用** —— 这一层得自己加。这是**第三次**他在题面外自己翻到边界（10-05 NPV 卖方 ／ 10-07 EV 对手方 ／ 10-08 闲置的钱）。
3. **无风险利率一变，排名会翻**：3% → 6% 时，稳当理财 0.9→0.6、热门赛道 0.9→0.75。超额各自掉了 3 个点（9→6 ／ 18→15），**同样扣 3 个点，对基数小的那个伤害更大**。→ **看基金业绩，先看它挂的无风险利率是哪一年的。**

**给的读法（一句话记）**

> **夏普就是在问：我拿「一分风险」，换回几分「多赚」？**
> **换回来超过 1 分，值；不到 1 分，不值；正好一样，随便挑。**

**结论：夏普第 3 天 · 过**（一处读法当场纠正，加试全对）。

## 七、DCF（现金流折现估值）

知识卡：[[DCF-一个东西到底值多少]]（10-04 说"存"已建）

> **学习日 2026-10-04** —— 课程表最后一个（★★★★），也是唯一还没学的一个。

### 第 1 天 · 当堂练习（10-04）✅ 方法一次做对 · 加法手滑 1 元

**引入例（我给的）**

村东头老李转让快递点：「一年净赚 **1000 块**，往后三年都这样。三年后不干了，店也不值钱。」折现率 **10%**。

- 1000÷1.1 = 909.09 ／ 1000÷1.21 = 826.45 ／ 1000÷1.331 = 751.31
- 合计 **2486.85 元** → 今天最多掏这些
- **对照**：偷懒版「先加 3000 再折三年」= 2253.94 → **少了 233 块**，那 233 就是**"晚到"的代价**
- → 他自己卡里那条「多笔各自折再加总，别先加再折」，**DCF 就是它的正式名字**

**出的题**

一台设备，未来 **3 年**每年带来 **2000 元**，3 年后报废、不值钱。折现率 **8%**。今天最多花多少钱买它？

**浩总的推导（原样照抄）**

```
今天值多少钱=C₁/(1+r)¹ + C₂/(1+r)² + C₃/(1+r)³
2000/1.08+2000/1.08^2+2000/1.08^3
=1851.852+1714.678+1587.664
=5155.194（元）
```

**批改**

| 格子 | 判 |
|---|---|
| 公式 | ✅ 一字不差 |
| 三项**各自**折 | ✅ **没掉进「先加再折」的坑** —— 这正是 DCF 的核心规矩，第一遍就守住了 |
| 第一项 1851.852 | ✅（2000÷1.08） |
| 第二项 1714.678 | ✅（2000÷1.1664） |
| 第三项 1587.664 | ✅（2000÷1.259712） |
| 合计 | ❌ 实际 **5154.194**，他写 **5155.194** —— **个位多了 1** |

**→ 性质：方法全对，最后一步三项连加的进位手滑。**

**错处的动作（这个错粗估挡不住）**

`1851.852 + 1714.678 + 1587.664` 三项连加，进位时容易歪一点。**粗估也挡不住**——三项都进位估出来也是 5155，而真值 5154，本来就差 1，落在粗估误差内。

→ 只能靠**验**：
1. **分两步加、留中间结果**：前两项先加成 **3566.530**，再加第三项
2. 或加完**用最大那一项倒着减回去**：`5155.194 − 1587.664 = 3567.530` ≠ 3566.530 → 一眼看出歪了

**结论：DCF 第 1 天 · 过。** 方法一次到位，1 块钱是手滑。

### 第 1 天（补）＋ 第 3 天 · 合一道（10-13 出题 / 10-13 交卷）✅ 全对 · 一处没歪

**题目**

一台二手设备，未来三年能带来的钱是：第一年 **1600 元** ／ 第二年 **1400 元** ／ 第三年 **1200 元**（逐年递减）。三年后报废，一分不值。折现率 **10%**。

**第一格**　今天最多花多少钱买它？
**第二格**　老板开口要 **3300 元**，**买不买？** 说一句为什么。

> **出题意图**：DCF 第 1 天（10-05 到期）＋ 第 3 天（10-07 到期）两笔一起补（10-08~10-12 在忙军事文章，队列积了 9 笔）。
> **故意让三条现金流长短不同**（1600／1400／1200）—— 防他当等额顺手，也防抄串（沿用 10-02 的教训：金额必须互不相同）。
> **3300 这个价是挑过的**：它正好卡在「各自折」（3513.15）和「先加再折」（3155.52）两个答案**之间** —— 偷懒那条路会把结论从「买」翻成「不买」，**这题能直接照出他走的是哪条路**。

**浩总的推导（原样照抄）**

```
PV=FV/(1+r)^n
1600/(1+10%)=1454.545
1400/(1+10%)^2=1157.025
1200/(1+10%)^3=901.578
1454.545+1157.025+901.578=3513.148
因为3300＜3513.148，所以我买
```

**批改**

| 格 | 判 |
|---|---|
| 公式 | `PV = FV/(1+r)^n` ✅ 一字不差 |
| 指数 | `^1 ／ ^2 ／ ^3` **三个都写全** ✅（连续第二次；对照 10-04 复利那道漏指数） |
| 三笔折现 | 1454.545 ／ 1157.025 ／ **901.578** ✅ 三笔全对（精确 1454.5455／1157.0248／901.5778） |
| 三项连加 | **3513.148** ✅ **一次就对，一位没歪** —— 10-04 那个进位手滑**没复现** |
| 第二格结论 | **买** ✅ 对。写成 NPV 就是 `3513.148 − 3300 = +213.148` |
| 成本 3300 | ✅ **没拿去折** —— 延续 10-05 那次做对的地方 |

**🔑 这题最值钱的地方：两条路的结论是相反的**

- **他走的（各自折）**：`3513.148 − 3300 = +213.148` → **买**
- **偷懒那条（先加再折）**：`4200 ÷ 1.331 = 3155.52` → `−3300 = −144.48` → **不买**

**同一堆钱、同一个价，一步之差结论就翻。** → 「各自折、折完再加」不是洁癖，**它是会直接改结论的**。

**顺手对照的一处**：这次他没写中间的加法结果（直接三项连加），但**结果是对的**。分两步加是「保险」，不是必答题 —— 数字越丑越值得用。

**结论：DCF 第 1 天（补）＋ 第 3 天 · 全对。** 三项小数连加一次到位。

## 八、NPV（净现值）

知识卡：[[NPV-这笔买卖到底该不该做]]（10-05 说"存"已建）

> **学习日 2026-10-05** —— 课程表第 7 个式子，昨天 DCF 的直系下一步。

### 第 1 天 · 当堂练习（10-05）❌→✅ 第一次折重了，第二次改对

**引入（我给的）**

昨天那台设备（3 年 ×2000 @8% → 今天值 **5154.194**），老板说"5500 卖你"。
`NPV = 5154.194 − 5500 = −345.806` → **不买**。

**第一题**

老板改口 **4800**。算 NPV，做还是不做？

**浩总的推导（原样照抄，两版）**

```
第一版  NPV = Σ Cₜ/(1+r)ᵗ − C₀=5154.194/(1+8%)^3-4800=4091.57-480=-708.43
        -703.43＜0，所以不做

第二版  5154.194 -4800=354.194（元）可以要
```

**批改**

| 格 | 判 |
|---|---|
| 结构（折回来的钱 − 成本） | ✅ 顺序对 |
| **C₀ = 4800 的位置** | ✅ **成本没有折**——这题最大的坑，他没掉进去 |
| 减法算术 | ✅ `4091.57 − 4800 = −708.43`，没错 |
| 判据 | ✅ 负 → 不做。**判据本身他学会了** |
| **5154.194 的处理** | ❌ **被折了第二次**（`/(1+8%)^3` 多余）→ 结论反了 |
| 改后 | ✅ `5154.194 − 4800 = 354.194` → 可以要 |

**🔴 错的性质：把"已经折完的成品"当成了"待折的原料"**

`Σ Cₜ/(1+r)ᵗ` 是一个**已经算完的结果**（他昨天亲手折的三项加起来就是它），**不是要往里代数的原料**。再除一次 `(1+r)³`，等于**同一笔钱折了两遍**。

**⚠️ 出题人责任（我的）**：`NPV = Σ Cₜ/(1+r)ᵗ − C₀` 这个写法**自带陷阱**——`Σ Cₜ/(1+r)ᵗ` 长得像"还要算的东西"。**当场认下，改成中文写法**：`NPV = 折回来的钱 − 今天要掏的钱`，或 `NPV = PV(未来那一串钱) − C₀`。

**给的线索（不给答案）**：**给每个数贴标签——"今天的"还是"未来的"？**

- 5154.194 → **今天的**（昨天折回来的）
- 4800 → **今天的**（老板现在要的）
- **两个都是今天的 → 直接相减，谁都不用折**

**加固动作**：**等号两边必须都是"今天的钱"**；未来的折过来，**但只折一次**。

**第二题（巩固，4 项折现，一次全对）**

村口铺面，4 年 ×2500 @10%，甲报 9000、乙报 7000。

**浩总的推导（原样照抄）**

```
PV=FV/(1+r）^2
第一年的折现钱2500/（1+10%）=2272.73
第二年的折现钱2500/(1+10%)^2=2066.12
第三年的折现钱2500/(1+10%)^3=1878.29
第四年的折现钱2500/(1+10%)^4=1707.54
四年的钱今天值2272.73+2066.12+1878.29+1707.54=7924.68
7000＜7924.68＜9000
如果我要租的话，从乙处租
如果是我转让的话，我转给甲
```

**批改**

| 格 | 判 |
|---|---|
| 四项折现 | ✅ 四笔全对（2272.73／2066.12／1878.29／1707.54） |
| 合计 | ✅ **7924.68**（精确值 7924.66，差 2 分——每项截到分再加，**两种做法都对**） |
| 甲 9000 | `NPV = 7924.68 − 9000 = −1075.32` → **不接** ✅ |
| 乙 7000 | `NPV = 7924.68 − 7000 = +924.68` → **接** ✅ |

**🔑 最值钱的一处：他自己补出了"卖方"那一半**

**题面只问"甲和乙该不该接"**，他答的是——「**如果我要租的话，从乙处租。如果是我转让的话，我转给甲**」。**后半句题面没问，是他自己想到的。**

→ 这就是 NPV 的**两面性**：同一条底价线，**买方是上限（越低越好），卖方是下限（越高越好）**。同一个数给出两条相反的建议，因为它们回答的是两个问题——「值不值这个价」和「卖得贵不贵」。

**（顺带练到的）** 4 项连加**没出手滑**——10-04 DCF 那次的进位坑，这次没踩。

**结论：NPV 第 1 天 · 过。** 第一次折重了，点一下就转身；第二题一次全对，还多走出一层。

## 九、财经公式随身卡

> **8 个式子（前置凯利 + ①~⑦）。** 看理财、比基金、谈欠款、判断「赊账 vs 现金」、给一个生意估价，都翻这张。

### 9.1 速查表

| 序号 | 名字 | 管什么 | 公式 | 你踩过的坑 |
|---|---|---|---|---|
| 前置 | 凯利 | 该投本金多少比例 | f = (b·p−q)/b | 赔率=净赚不是拿回；超 f* 又慢又险；拆分不改期望，降风险用半凯利 |
| ① | 期望值 EV | 该不该玩（方向） | EV = Σ(结果×概率) | 0.8−0.6 不严谨；比例入脑会串格（念全数字防）|
| ② | 72法则 | 多久翻一倍 | 翻倍年 ≈ 72÷利率% | 高利率会低估（24%实测3.22年）；只适用复利 |
| ③ | 复利 | 现在的钱往前滚 | FV = PV×(1+r)^n | 指数非线性后段更陡；漏前导零、漏指数 |
| ④ | 折现/现值 | 未来的钱往回拉 | PV = FV/(1+r)^n | 多笔各自折再加总，别先加再折 |
| ⑤ | 夏普 | 风险调整后性价比 | Sharpe = (R_p−R_f)/σ | 夏普高≠收益高（比性价比不是比收益）|
| ⑥ | **DCF** | **给一个东西估价** | **Σ Cₜ/(1+r)ᵗ** | **多笔连加容易进位歪**（粗估挡不住，得验） |
| ⑦ | **NPV** | **这笔买卖该不该做** | **折回来的钱 − 今天要掏的钱** | **把折完的现值又折一遍 → 结论直接反**；成本不用折 |

### 9.2 决策链（串联全部）
EV 定方向（该不该玩）→ 凯利定力度（下多少）→ 半凯利定舒服（实战砍半）→ 72法则/复利/折现 管钱的时间（往前滚／往回拉）→ **DCF 把未来每一年的钱折回来加起来，给一个东西定价** → **NPV 拿这个价减掉成本，拍板做不做** → 夏普 比谁更稳（风险调整后）

### 9.3 坑位清单（考前扫一眼）
1. 凯利 b：双OrNothing b=1；「连本带利拿回 2.5」→赔率 1.5（先减 1）
2. EV ≠ 凯利：EV 是期望收益（钱），凯利是应投比例（%）；b=1 时每单位 EV 恰等于 f*，巧合别依赖
3. 百分数×本金盯小数点：1万×5% = 500，不是 5000
4. 72法则高利率低估
5. **折现／DCF：多笔各自折再加总，别先加再折**（DCF 里偷懒先加，2486.85 会算成 2253.94，少 233）→ **10-13 实测：它会改结论**。同一堆钱、同一个价 3300：各自折 3513.15 → **买**；先加再折 3155.52 → **不买**
6. 夏普高≠收益高
7. 手写**漏东西**三形态：**漏前导零**（0.06→0.6、20000→2000）／**漏位数**（22.63→2.63）／**漏指数**（`(1+r)³`→`(1+r)`）。结果常对，点出即可不扣
8. 比例入脑会串（0.4 读成 0.2）→ 念全数字（「零点四乘九」）
9. **72法则：翻了几「次」≠ 几「倍」**（4.5 次 → `2^4.5 ≈ 22.6` 倍）。整数阶梯背下来：翻1次=2倍／翻2次=4倍／翻3次=8倍／翻4次=16倍。→ **✅ 10-07 已结案**：第 7 天纯整数题（7.2%、50 年）他自己给出 `2^5 = 32 倍`，**次数放进了指数位，三个数各就各位**
10. **一个数字只能有一个身份** —— 例子的数字别和公式里的常数撞车（讲牛顿法时拿 √2 举例，式子里 2 同时是「目标」和「÷2」，他当场就问出来了）
11. **复利式子别漏指数**（10-04 新踩）—— 写「3 年」必须写成 `(1+r)^3`；漏成一次方得数会差一个量级（`6000×1.1 = 6600`，不是 7986）。**和「漏前导零」同一族：等式漏东西。** 写完**连数字带指数一起念一遍**
12. **复利 ↔ 折现是同一个式子的两个方向** —— `FV = PV(1+r)^n` ↔ `PV = FV/(1+r)^n`。正着算是复利，倒着解就是折现（10-04 他自己换过来的，没人提示）
13. **三项以上连加，粗估挡不住进位手滑**（10-04 DCF 踩）—— `1851.852+1714.678+1587.664` 真值 **5154.194**，他写 5155.194。三项都进位估出来也是 5155，**差 1 落在粗估误差里，粗估挡不住**。→ 只能**分两步加、留中间结果**，或**加完倒着减回去验一遍**
14. **折现算出来的那个数，就是你的底价线**（10-05 新立）—— 不是算完就完，是**拿来比价的**：欠条今天值 3005.26，对方出 2900 → 不换（亏 105.26）；出 3100 → 换。**"要不要出手"先算这条线，有人出价心里一比就知道。顺序是「先算，再判断」——别被"现金落袋为安"的直觉带走。**（判断时**整数位就够**，不必算到分）
15. **NPV：折完的现值不能再折**（10-05 踩）—— `5154.194` 本来就是"今天的钱"，再除一次 `(1+r)³` 就是**同一笔钱折两遍**，**结论直接反过来**（该做的答成不做）。**动作：给每个数贴标签——"今天的"还是"未来的"？等号两边必须都是今天的钱；未来的折过来，但只折一次。** 另：`C₀`（今天掏的钱）**本来就在今天，也不用折**
16. **NPV 的两面性**（10-05 他自己走出来的）—— 同一条底价线，**买方是上限（出价越低越好），卖方是下限（出价越高越好）**。同一个数给出两条相反的建议，因为回答的是两个问题：**"值不值这个价"**（买方）和**"卖得贵不贵"**（卖方）
17. **夏普的读法**（10-08 当场纠）—— ① **0.9 是「冒 1 块钱风险，换回 9 毛超额收益」**，不是「花 9 分钱的风险」；**风险是掏出去的本钱，收益是换回来的东西**。② **两个夏普一样 ＝ 打平，没有哪个更值** —— 别说「所以选 X」；多赚的那一截要和**多冒的那一截**摆在一起看（21 vs 12，波动也 20 vs 10）。③ **无风险利率一变，排名会翻**：3%→6% 时稳当 0.9→0.6、热门 0.9→0.75。**看业绩先看它挂的基准是哪年的。** ④ 一句话记：**夏普 = 拿一分风险，换回几分多赚；超过 1 才划算。**
