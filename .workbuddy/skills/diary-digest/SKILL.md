# 消化日记

> 依赖浩总个人知识库的目录结构：
> `原始材料/日记/`（只读输入）→ `知识库/日记回信/` → 产出 → `知识库/个人档案/成长记录.md`、`知识库/知识主题/`、`产出/复盘/`

## 触发方式

- **每周定时自动化**（automation「每周日记消化」当前为**每周一 07:45**；2026-09-30 从周一凌晨 2 点改的）
- **手动**：浩总说「消化日记」

## 铁律

- **原始材料只读**：`原始材料/日记/` 的原稿一字不动
- **消化是沉淀，不是评判**：不打分、不评级、不做情绪分析
- **无日记周不硬写**：成长记录只记一行「本周无日记」，跳过周复盘
- **不碰 git**：同步交给 obsidian-git 插件兜底（浩总「全自动不手动」约定）

## 工作流程

### 第一步：确定本次范围

- 看 `产出/复盘/` 里最新一篇周复盘的日期 = 上次消化截止点
- 本次范围 = 截止点之后新增的全部日记 + 对应 `知识库/日记回信/*-回信.md`
- **首期**（无历史复盘）→ 处理全部存量日记

### 第二步：读全部日记 + 回信

- 逐篇读，提炼每篇的核心认知变化/洞察
- 回信里的「我注意到的」是重要线索，但沉淀的是认知变化，不是复述回信

### 第三步：产出五样

#### 1. 成长记录时间线（追加 `知识库/个人档案/成长记录.md`）

按周分节，节标题格式：`## YYYY-MM-DD~MM-DD ｜ 第Wxx周`（首期可写 `｜ 首期（N篇）`）

每条一行：日期 + 认知标签 + 一句话 + 出处链接，格式：

```
- **08-24 落袋为安原则**：「没有落袋为安的钱，都是别人的钱」——从反面故事推演出风险原则（出处：[[2026-08-24]]）
```

认知标签用 4-6 字概括（如「情绪消化」「用户思维觉醒」「自我松绑」），一句话写清楚认知发生了什么变化。

#### 2. 金句摘录（≤3 条，同页「本周金句」区）

- 必须浩总**原话**，一字不改，不加工不拔高
- 格式：`> 「原话」—— 08-2x`

#### 3. 主题沉淀（条件触发，`知识库/知识主题/` 下）

- 同一主题在日记+回信中 **≥3 次** 出现才建/更新页
- **已有同主题页面** → 追加「2026-MM 日记印证」小节，不重复建页
- 子文件夹按主题归属：`个人成长/` `商业思维/` `写作/` 等
- 克制：宁缺毋滥，不每周都建新页

#### 4. 周复盘（`产出/复盘/日记周复盘_第Wxx周_YYYY-MM-DD.md`）

文件名：`日记周复盘_第Wxx周_YYYY-MM-DD.md`（如 `日记周复盘_第W35周_2026-08-31.md`）

模板：

```
# 日记周复盘 第Wxx周（MM-DD ~ MM-DD）

- **本周篇数**：N 篇（日期列一下）
- **主线在聊什么**：2-3 句概括本周日记反复出现的主题
- **卡点**：1-2 个（含本周已解决的，注明怎么解决的）
- **进步**：1-2 条（给具体证据，不空夸）
- **下周一个关注点**：1 条（从「可以再想想的」或本周未完成事项里挑最值得跟的）

## 思想变化

（本周看法/认知发生的**转折**——写清「从什么 → 到什么」，每条给一条原文证据+日期）

格式：
- **从 A → 到 B**：一句话说清变了什么（08-2x：「原话片段」）

只写**真发生了变化的**。这周没变化就写「本周无明显转折」，不要硬凑。

## 潜意识（观察 + 猜测）

### 观察（只用证据，不作解释）

（挑 2-4 条**可验证的现象**，不带任何心理判断）

例：
- 「XX」这个词本周出现 3 次（08-2x 两次、08-2x 一次）
- 某天的日记比别人长一倍，但写到某件事时突然收尾（08-2x）
- 周三写「无所谓」，周五又主动提起同一件事（08-2x、08-2x）
- 连续两天的日记都没提某件上周还在说的事

### 猜测（≤3 条，每条标「猜测」+ 给理由 + 允许否掉）

格式：
- **猜测 1**：……（理由：某天写了 XX、某天又没写 XX）——**这只是一个猜测，不对就说。**

（写法纪律：
- 猜测必须**从证据出发**，不许从"一般人会怎么想"出发
- 每条猜测都要**给出可以否掉它的口径**（"如果你觉得不对，说明我读偏了"）
- **不做心理诊断、不用心理学名词贴标签**（不说"这是回避型""这是讨好型"）
- **不指向人生决定**（不写"你该考虑换工作"这类）
- 宁少勿滥：凑不出 3 条就写 1-2 条）
```

#### 5. 回信沉淀（追加 `知识库/个人档案/回信沉淀.md`）

回信的独有价值在「我注意到的」（Hermes 的观察）、回信原则句、末尾问题。逐周追加：

- **观察档案**：回信「我注意到的」里的模式，按模式归并——已有模式只补新证据/升级（标日期），新模式才新增一条（标首见日期+出处链接）
- **回信金句**：Hermes 写出的原则句，每周 ≤2 条，格式：`> 「句子」—— MM-DD`
- **问题清单**：回信末尾「可以再想想的」的问题——新问题进对应分组的待回答区；浩总已回答的移到「✅ 已回答」区（标注回答日期与内容）
- 克制：观察按模式归并，不逐封罗列；金句宁缺毋滥

### 第四步：收尾

- 如有新页面，更新 `知识库/Index.md`
- 追加 `知识库/Log.md`：`## [YYYY-MM-DD] 消化日记 | 第Wxx周`
- 本次范围里的日记篇数、产出文件清单
- 不碰 git

## 忌讳

- 不评判浩总写的内容，不替他做人生总结
- 金句必须原话，改写了就不叫金句
- 主题页克制，宁缺毋滥
- 不把回信内容整段搬进沉淀页——只留认知变化
- 回信沉淀页同样克制：观察按模式归并，不逐封罗列（仅首期存量消化时全量归并一次）
- **「潜意识」那一节的额外纪律**（2026-09-30 浩总指定要有这一节，所以更要守边界）：
  - **观察和猜测必须分开写**，不许混在一段里让人分不清哪是事实哪是推测
  - **观察只有现象，没有解释**（写"出现 3 次"，不写"说明他焦虑"）
  - **猜测 ≤3 条，每条给理由，每条都留否定的口子**
  - **不用心理学标签、不做诊断、不指向人生决定**
