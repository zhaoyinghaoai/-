# 读书感悟制作流程（Reading Insight Flow）

浩总每天看店时读书，口述感悟，产出 = 公众号文章 + 社card + 朋友圈文案。已连续运行到**第31天**（2026-09-18）。书单进程：《学会提问》读到论证谬误章完（第21-26天）→ **第27天起开《芙蓉镇》新系列**（古华，第一届茅盾文学奖）。《芙蓉镇》进度：吊脚楼主（27）／秦癫子（28）／黎满庚（29）／谷燕山（30）／胡玉音（31）——**已形成"人物志"体例，一篇一个人**。

**换书＝换代**：新书开篇要当作"新系列第1篇"处理——
- 标题、意象、标签全部换口径，别沿用上一本的语感
- 系列标签＝`#书名` + `#读书笔记` + 第三标签随篇变（《学会提问》第三标签历次：#个人成长/#批判性思维/#创业思维/#防骗；《芙蓉镇》首篇用 #生活感悟）
- 第1篇可在文内留一句"换口味"的引子（本篇原话："本来是想换换口味…结果越读越沉"），承接上一本读者

**开场的固定动作**：浩总说"开工第N天"= 让我先复述昨天停在哪、再等他丢当天口述，不要自作主张定选题。

## 流程总览

```
口述感悟 → ①考官三问批改 → ②成文存档 → ③社card配图 → ④交付（Log/Index/记忆/朋友圈）
```

## ① 考官三问（2026-08-30 新增，学自姜胡说"AI当考官"；2026-08-31 起设为默认：口述后自动进入考官，除非浩总说"跳过/直接配图/赶时间"）

读完一章后**先当考官再写文章**，不让 AI 直接代写。三题由易到难，逐题批改 + 追问，答完才动笔：（"三题"为参考框架，非硬性数量——按章节复杂度加减，常 2–4 题；浩总答得磕巴、含糊的地方就多追问，已清楚的不凑数）

1. **概念区分题**：用你自己的话区分核心概念（例：理由 vs 证据）。拿口述里的原话举例。
2. **实战应用题**：给一个现实场景/金句，让他过两层筛子（先掂理由证据、再查来路目的）。
3. **找漏洞题**：挑战他文章里的比喻/结论——"证据本身也可能是假的"这种边界情况。

**题型随书切换（第27天立规）**：
- **道理书（《学会提问》类）= 拆招型**：三问都指向"拆开对方的论证"，越拆越锋利
- **小说/文学（《芙蓉镇》类）= 接住型**：三问指向"这书哪句在改你"。三个已验证好用的问法——
  ① **两个转变是一件事还是两件事**（逼他自己合并，往往合并后更紧）
  ② **拿他自己写的"金句"当靶子**（"他苦成那样都翻身了，我凭什么不行"→ 逼他拆出"押结果还是押动作"）
  ③ **给自己当作者**（"人人都有苦，那读者为什么看你的苦"→ 把他从共情推到"我的苦是怎么个苦法"这个专属位置）
  ④ **"换成你，你做不做"**（第30天新验证，最有效）——给一个具体动作（风雪拦军车），逼他从"评论人物"切到"表态自己"。**浩总这一题答得最好，答出"小孩子是国家的希望，不能因为他父母是坏分子，就给他也扣上一顶帽子"——比原著立意高一寸。**
  - **第31天再用一次验证**（胡玉音篇，问"那几年换成你，你撑不撑得住"）：浩总答出 **"要我死可以，要我被冤枉死的，那是万万不行的"**——已原样收进文章结尾收口。**这一问已成人物志固定第四问，每篇必出。**
- 🔴 **人物稿前置动作：核对人物关系与时间线**（2026-09-17 立案）。写《芙蓉镇》人物志前**必须核**：①这个人是谁的谁（前任/现任/干亲）②涉及时间点（哪件事发生在新楼盖起前还是后）。**9-17 我两处搞错被浩总抓出**：把胡玉音写成"寡妇家的女儿"（实为胡记客栈独女）、把"卖碎米时"写成"已是寡妇+新楼被收"（实为黎桂桂还活着、新楼还没盖）。**浩总读书极细，别凭印象写人物。**
- **批改时的落地要求**：浩总常给出方向对但偏虚的答案（如"他有一股精神"）。**批改要把虚词落成可写的判据**——"精神"→"两个人算的是两本账"（黎满庚账本只记自己／谷燕山把'我'也记进去了）。**只夸方向对是不够的，要给替换句。**
- **共性**：三问最终都要收成**一条主线**，且主线要能回到他自己的具体生活（守店、两条号、读写的动作）

**批改原则**（实测有效）：
- 先肯定对的部分（表格列出 ✅/⚠️），再纠正
- 给"锚句"帮助记忆（例："理由回答为什么，指令回答去干吧"；"筛子不拣内容，筛子专拣漏洞"）
- 纠正理解偏差时要讲清"为什么错"（例：他把"筛出"理解成"话里有啥"而非"经不起哪层检验"）
- 答不出来时引导他自己推（第3题他先说"没想过"，自己推出"材料有问题"——自己推出来的记得特别牢）

## ② 成文规范

- 标题：**优先从浩总当天口述里挑原话**（第21-26天实践：「多半没有那个，只有那几个」「一头扎进去不是勇敢，是没数」「看见一点好，就脑补成处处好」「最难看清的人，是自己」「网上忽悠你的话，逃不出这几招」「剩下这两招，不骂你，但更坑」）。他自己写的标题优先用（他常自写）。要求短语式有锋利感、别把结论说完
- **🔴 人物志体例（第29-33天成型，已固定，跨两本书通用）**：写小说人物时，**正文只写书里的人，作者的自省段不进正文**。9-16 砍黎满庚篇自省段、9-17 整段删谷燕山篇自省段、**9-19 又整节删掉《别急着开花》的"我的自留地是一本书"**（一篇 1,505 字里砍掉整节，浩总毫不犹豫）。**判据：自省段一进，读者注意力就从人物转到作者身上，收口那句判断句被稀释。** 若确要带自己，压成两三句挂在倒数第二节尾，或化成收口判词（9-20 许茂篇就是这么处理"自留地"三答的）。
- **🔴 改标题/改关键词前先 grep 全文**（9-16 立、9-17 再验证）：①改词看是否与既有表达撞上——撞上是坏事（打架）也可能是好事（呼应）。9-17 "干的好事"→"干的事"，正好把好坏都收进来，比原版更准 ②一题材多版本时，**哪张卡与压缩后正文不一致，就重做那张**
- frontmatter：tags/date/source/status/写作天数/配图
- 正文：第一人称口语化，书里的话是真的、想法是实的；结尾互动提问 + 标签行（《芙蓉镇》用 `#芙蓉镇 #读书笔记` + 第三标签随篇变）
- ✅ 底部**不加**"本文风格"声明（2026-09-13 浩总原话答复"不加"，已定死，以后不再问）
- 全文无"浩总"字样（去高高在上感）
- **字数**：常规稿约 1,600-2,200 字；浩总说"减到 1500 左右"时目标 **1,600±100**。
  - 🔴 **压缩要一次性规划砍哪几节，不要挤牙膏式微调**（9-16 曾用 5 轮才到位）。**手法优先级**：①梳理重复——两节讲同一件事就合并 ②删过渡句与情节复述 ③合并同类对账段 ④最后才动句子。**保骨头＝保留核心论点句与题眼**
- **字数校验工具（9-18 新增，别临时写脚本再删）**：`python .workbuddy/scripts/count_chars.py <稿件md>` —— 一次输出**正文字数／分节清单／破折号数／"浩总"字样数**。每篇写完先跑它，再发浩总。
- 存档：`产出/读书内容/成品文章/YYYY-MM-DD_标题_读书感悟.md`
- **🔴 交付时要把带 `**` 的全文贴在回复里**（2026-09-20 浩总定："直接在主页面呈现，这样加粗加黑的我也能复制到别的地方"）。
  - **病因**：纯文本版按固定规则把 `**` 剥掉了，**加粗信息在传递链路上直接丢失**——浩总拿纯文本复制去头条/公众号后台，根本看不出哪里该加粗，还得回头问一遍。
  - **正解**：回复正文里**直接贴一份带 `**` 标记的全文**（md 的语法，粘到别处也带着标记）。纯文本 txt 照旧产出，但**不再作为"看加粗"的载体**。
  - **加粗句自查**（写稿收尾必做）：① **每个小节的判断题/收口句必须加粗**（夹在段中的 judgment 最容易被扫过去）② **"结论句"的直接论据要加粗**（否则结论在版面上悬空）③ **对比句的两个前提都要加粗**（只加后半句，前半句的前提就丢了）④ 每篇 **15-20 处**为宜，别满屏加粗
- **同时产出一份"纯文本版"**（浩总明确要求过"文章要直接可以复制的"）：同目录 `..._读书感悟_纯文本.txt`。**别手写转换**，用脚本：`python .workbuddy/scripts/to_plain.py <稿件.md>`。它按固定规则转：删 frontmatter／行首 `#{1,6}` 去掉（`## 一、xxx`→`一、xxx`，`#芙蓉镇…`→`芙蓉镇…`）／行首 `> ` 去掉／`**` 去掉／`---` 保留。结尾保留标签行，方便手机长按全选复制

## ③ 社card配图（浩总说"配图"时）

目录：`产出/读书内容/配图/<主题>社card/`，8张 = 6小红书(1080×1440) + 公众号21:9(2100×900) + 1:1(1080×1080)

- 主题：ink-classic（暖纸 #f3f0e8 + 深墨 #0a0a0b），Editorial Magazine 排版
- 意象：SVG 线条画 + 大字水印（`fill="rgba(10,10,11,.03)"` 左右，font-size 400-760）——每张卡一个意象，对应文章段落。⚠️ **意象要一眼认得出**，"几何近似画具象物"必翻车（石磨画成两个盘子、手画成窗框）——判据与正确画法见 `render-social-cards` skill「意象可辨识铁律」
- **渲染关键（踩坑教训）**：viewport 必须 ≥2200 宽（用 2400×1600），用 `element.screenshot()` 而非 `page.screenshot(clip)`，否则 21:9 封面左右被截成黑色（body #1a1a1a）
- 输出 JPG quality 92；渲染后必须用 PIL 验证：21:9 尺寸 2100×900、四边像素为暖纸色（约 234,231,224）非深色
- 打包：**不要用 PowerShell `Compress-Archive`**（`-Force` 重打包实测不刷新，zip 里还是旧图）。**直接用现成脚本，不要每次重写**：`python .workbuddy/scripts/pack_cards.py <卡片目录> "公众号封面_第N天_<短标题>_21x9.jpg"` —— 一步做两件事：另存 21:9 封面到 `配图/` + 打 zip（8 jpg + 朋友圈文案，约 700-780KB）
- 渲染环境的坑（PATH 损坏 / node 版本目录名会变 / PIL 只在 venv）见 `render-social-cards` skill，别照抄旧版本号
- 21:9 封面复制到 `产出/读书内容/配图/公众号封面_第N天_标题_21x9.jpg`
- render.js 模板参数：CHROME=`C:/Users/Administrator/AppData/Local/Google/Chrome/Application/chrome.exe`；`headless:'new'`；`--force-device-scale-factor=1`；`document.fonts.ready`+3秒延时

- `知识库/Log.md` 追加记录；有知识库新页则更新 `知识库/Index.md`
- `.workbuddy/memory/YYYY-MM-DD.md` 追加工作记忆
- 朋友圈文案 3 条：金句版 / 接地气（看店感悟）版 / 互动版
  - 标签：**只留一个 `#读书`**，不堆标签（2026-09-07 浩总立规；长期记忆与项目记忆均已固化）。~~旧"标签跟当天文章连用 3 个"写法已作废~~
  - **末句用"聊聊"，不用"评论区聊聊"**——朋友圈是熟人圈，没有"评论区"这个叫法（浩总 2026-09-07 立规，已固化到长期记忆）
  - 公众号正文结尾仍可用"评论区聊聊"（那是公域语感），只有朋友圈版要改
- 🔴 **标题被浩总改词时 —— 六处回扫（少一处就出现两个版本）**：
  1. 稿件 frontmatter `title`　2. **稿件文件名**（`mv` 改名）　3. `cards.html` 里**三处** h-display（封面／21:9／1:1，长标题要顺手把字号调小一档）　4. `朋友圈文案3条.md` 的 H1　5. 重渲 → 重打包 → 重存 21:9 封面　6. 当日 memory 记录
  - 改完 **grep 全文**：看新词与正文是撞上还是呼应；**若新词正文里完全没出现，把这条判断报给浩总**（要不要补一句把标题坐实），别自己往正文里加
  - 封面另存名与 zip 名沿用**短标题**，与长标题解耦，不跟着改
- **🔴 删/改正文里的"一句话" → 也要扫四处**（9-20 删第33天收口判词立案）：**正文 md ／ 内页卡 pullquote ／ 封面 h-sub ／ 朋友圈文案**。**先 `grep` 关键词再动手**——本次 grep「整整一个时代」一击命中全部 3 个文件（正文 + 两处卡 + 朋友圈）。**别只改正文就交付**，改完重渲重打包。
  - 判词/金句被删后**要补一句顶上**（卡片和朋友圈不能空着），顶上的句子**从同节正文里挑**，保持同一出处
  - 🔴 **改完还要问一句：那张卡上的上下文够不够撑住新句子？**（9-20 追加）删掉"这两下，全是对着自己家里人的"后，卡面 lead 段**只写了赶集那一处**（因为原结论只提"家里人"，卡面就省了第二处）→ 新结论"对外人／对家里人"**失去了对照组**。**补上第二处情节再渲。** 即：不只扫"哪张卡引用了这句"，还要扫"引用它的那张卡，上下文齐不齐"
- **🔴 写"总结句"前先回看它总结的那几处，主语是不是同一个**（9-20 立案，浩总当场抓出）。反例：上一段刚写了"连云场一个妇女…"（**外人**），下一句总结成"这两下，**全是对着自己家里人的**"——总结句偷换了主语，是硬伤。**判据：把总结句里的关键名词圈出来，逐个回它要总结的那几处对一遍，有一个对不上就不能这么写。** 宁可拆成两句（"对外人他是…；对家里人他是…"），也不硬凑成一句
- **🔴 浩总说"这篇不发、先留着"时**（9-20 颜少春篇）：① frontmatter 改 `status: 素材保留（不发）`、`系列` 改"备用素材 · 留作《X人物篇》"、`写作天数` 改"未发布" ② **在文件头写清楚并入时的注意事项**（体例约束、可与哪篇日记/回信互证）③ 更新清单里**不计入篇数**，改写处置结论，别留"待定"
- **🔴 写人物志前，凡涉及"人物怎么想/怎么变的"，必须先跟浩总核一遍因果链**（9-21 立案，颜少春篇一口气被纠 3 处）。**他那本书读得比我细得多，我凭印象推的因果，经常方向就是反的。** 本次三处硬伤：
  1. **动作顺序反了**：写成"颜少春送药上门"，实为**许茂怄气病倒 → 她听说后托人捎药（本人没上门）→ 许茂当场掏钱让她转交 → 她收下**。**"谁主动、走没走上门"是人物性格的关键，别想当然。**
  2. **感情线起点误导**：写成"四姑娘心里装着金东水"——**像一见钟情**。实为**起初只怜惜侄子侄女 → 对郑百如先鄙视后不想看 → 离婚后才动心，她起初自己都没察觉**。
  3. **人物称谓**：金东水是"**大姐夫**"（大姐死了、没离婚、他没再娶），不是"前大姐夫"。
  - **做法**：人物志里凡是"因为…所以…"的句子，**动笔前先列一张因果链给浩总过一眼**，比写完再改省事十倍。
- **🔴 开头"交代出处"那句怎么处理**（9-21 浩总提问后定规）。原句：《许茂和他的女儿们》，周克芹写的，第一届茅盾文学奖。
  - **不能全删**：正文里一次都没出现书名，删了读者读到一半还在猜"在看什么书"，且丢掉了"这一点是读书笔记"的定位。
  - **正解＝保住出处、舍弃与正文无关的半句**，并进下一句：`《许茂和他的女儿们》，周克芹写的。上一篇写的是许茂……`
  - 判据：**奖项/作者名望这类"背书"，跟本篇正文没关系就是多余**；书名和作者名是"出处"，要留。
- **🔴 收尾不能只会"回扣开头"**（9-21 立案）。原结尾"前面那些事是因，这个是果"——**把开头说过的话又说了一遍，没有往外推一层**。浩总一句"这个结尾再重写一下"。
  - **正解：结尾要有一次"往上抬"**。本次改成先落反常识判断（`她做的每一件事，都不是在改变葫芦坝，是在改变一个许茂`），再推到更大的面上（`一个人的病，得一个人治。一个村子，得一个一个人地治。`）。
  - **判据：收尾句里如果找不到一个"比正文高一层的名词"（一个人 → 一个村子），就是原地踏步。**
  - ⚠️ 上抬之后**别再补一句回扣开头的话**——浩总随后就把"前面那些事是因，这个是果"删了，重复。
- **🔴 情节改动会连带改掉"中间那句台词"**（9-21）：原稿有"九姑娘递钱时说：人家给你药你就收着吧"。改成许茂**当场掏钱**后，这句中间人台词失去存在意义 → 一并删。**改情节链时，把链条上每一环的台词都过一遍，看哪句变成了悬空的。**
- **🔴🔴 写人物志要认准"视点人物"，只写他/她能看到的世界（9-22 立案，四姑娘篇）**
  - **病因**：浩总口头交代"郑百如先搞掉老金的支书、再烧了他家房子，把大姐急病了"——**那是给我补背景，不是让我写进文章**。我却把"郑百如放火烧了老金家的房子"当成素材写进了第一节。
  - **浩总原话点破了根子**：*"写郑百如烧房子是在最后的郑百如自己的心理活动看到的，我开始也不知道。"*
  - **两个错叠在一起**：① 违反视点（四姑娘不知道的事，文章不能说）② **用了作者故意延后给读者的信息**（那张牌放在很后面，从郑百如自己的心理活动里才揭）
  - **判据（动笔前必问）**：**我要用的这个事实，是在哪一章、从谁的视角出来的？** 只要它出现在后面、或只出现在某个角色的心理活动里 → **这一篇不能碰。**
  - **推论**：**"交代背景 ≠ 素材。"** 浩总口述里那些用于让我理解人物关系的信息，**默认不写**；要写进文章的，必须是他明确说"这句写上"的。
  - **本次正确写法**：只写四姑娘当时看得见的两件事（男人被整下去、房子烧了），火是谁放的不说。
  - **收尾自检**：改完 grep 关键词（本次扫 `放火`／`烧了老金`／`火烧` 全 0），确认没有残留。
