## 十一、学第 7 个式子：NPV 净现值（15:00~15:28）

**来历**：现值这个概念是经济学家**欧文·费雪**一百多年前讲透的（1907 年讲利息率那本书）；把它当成「该不该投」的**判据**，是后来算大工程账时定下来的规矩——修铁路、建水坝，先算 NPV，正的才批。
**一句话**：**NPV ＝ 折回来的钱 − 今天要掏的钱。正的干，负的散。**
**分工**：**DCF 标价（这东西值多少），NPV 拍板（买它净赚多少、做不做）。**

**引入**：拿昨天 DCF 那台设备接上（老板开 5500 → `NPV = 5154.194 − 5500 = −345.806` → 不买）。

### 第一题（老板改口 4800）—— 第一次错，点一下就对

**他的第一版（原样）**
```
NPV = Σ Cₜ/(1+r)ᵗ − C₀=5154.194/(1+8%)^3-4800=4091.57-480=-708.43
-703.43＜0，所以不做
```

**错在：把已经折完的 5154.194 又折了一遍**（多除 `(1+8%)^3`）→ **同一笔钱折两遍，结论直接反了**。

- **对的部分**：结构对（折回来的钱 − 成本）／**成本 4800 没有折**（这题最大的坑，他没掉进去）／减法算术对／**判据用得对**（负 → 不做）
- **⚠️ 病根至少一半在我**：`NPV = Σ Cₜ/(1+r)ᵗ − C₀` 这个符号式**把"成品"写成了一个"待算的东西"** → **当场认下**，改成中文写法 `折回来的钱 − 今天要掏的钱` / `PV(未来那一串钱) − C₀`

## 十三、浩总提问：先定标题 → 再定封面 → 最后写正文，是正常顺序吗？（20:00）

**他的原话**：「我这个是正常人写的时候应该这样做吗？先定标题，再定封面。做后写文章吗？」

**答：不是通用写法** —— 是**平台内容场景**专用的工艺，而且是他 **低量期恢复期的临时工艺**，不是永久规矩。

**两条线（他记的判据一句话）**：
- **通用写作**（小说《徐福东渡》／公文／日记）：想法 → 正文 → 标题（标题从正文里**提炼**）
- **平台内容**（头条／短视频／图书封面）：标题 → 封面 → 正文**兑现**

**给他的自查工具**（判据，不是背规则）：**读者是先看见标题封面，还是先想"我要看这个人的东西"？**
→ 先看标题封面 ＝ 入口先行；已经追着这个人看 ＝ 内容先行。

**说给他听的三点背景（防他以为倒序是"歪门邪道"）**：
1. **入口先行不是自媒体发明的** —— 出版社选题会先定书名和封面，作者才开始写
2. **明清制艺"先破题"** 也是这个顺序，中文写作传统里有根
3. 🔴 **但小说绝不能倒过来** —— 《徐福东渡》必须先有人物和故事，标题最后起（**这条要防的是我把"实验稿工艺"错误推广到他所有写作上**）

**为什么现在用倒序**：他以前的病是"**正文写完最后憋标题、配图随便找**"→ 标题封面都成了正文的附庸。低量期的核心问题不是"文章写得好不好"，是"**点击率出不来**"，所以把入口提到最前面。

**倒序的坑 ＝ 标题党**。防法就是五查里那条「**每个动词过一遍'这动作有信源吗'**」—— 那是**为倒序量身定制的安全阀**，不是额外负担。

**什么时候回到常规**：量级恢复后。届时"标题从正文里提炼"可以恢复。
