## 知识教学 · 凯利公式（浩总主动来学）

- **浩总路径**：先问「起源+方式+怎么运用」→ 我讲完（含曲线图）→ 浩总反馈**「还没完全搞懂，出一个例子，我看一遍搞不懂」** → 我出了一套**可手算算例**。
- **算例设计（已验证数字）**：
  - 例一：硬币局 b=2、p=0.5、本金 100 → **f\*=25%**；两条路径（先赢后输／先输后赢）**殊途同归 112.5**（乘法交换律）
  - 核心教具 **「成对倍数」= (1+f·b)×(1−f)**：f=12.5%→1.0938／**f=25%→1.125（顶点）**／f=37.5%→1.0938／f=50%→1.0／f=75%→0.625。**12.5% 与 37.5% 结果相同＝曲线以 f\* 为轴左右对称**
  - 连输十把对照：f=12.5% 余 26.3 元 vs f=37.5% 余 0.9 元（**同样收益率，风险天差地别**）
  - 例二：b=1、p=0.6 → **f\*=20%**；**关键教学点＝「一赢一输」法只在 p=0.5 时精确**，p≠0.5 时利润全来自「赢的次数比输多」，估错 p 就是悄无声息地亏
  - 全押演示：连赢五次 3200 → 输一次归零
- **给浩总讲解时的口径**：不用表格（他连着两天说看表格累）；每步写算式；末尾留「哪一步卡了指给我」的接口，并预告「可以把例二换数字重推一遍」。

### 第二轮修正（浩总当天反馈）

- **浩总原话**：「你不要都搞 0.5，搞 0.5，我不知道哪个 0.5 代表什么，你把 0.5 给调一下吧」
- **病根**：初版例一里 **0.5 同时当了四个角色**——胜率 p、输率 q、押注比例 f=50%、押 50% 时输的倍数 (1−f)。数字全撞，辨识度为零。
- **🔴 新铁律：给浩总做算例，同一篇里每个数字必须长得不一样。** 落笔前先做一遍「数字查重」——任一数字若承担两个以上角色，换例子重设，别靠文字解释去补救。
- **新算例（全部可手算、零数字冲突）**：
  - 主例：袋子 60 红 40 蓝，赔率 1、**赢面 0.6**、输面 0.4、本金 200 → **f\* = 0.2**，押 40 元
  - 走两把：先红后蓝 = 先蓝后红 = **192**（殊途同归仍在，但**低于 200**，顺势引出「利润全来自赢的次数比输多」）
  - **关键论证改用「典型路径次数法」**替代原「一赢一输」：5 把赢 3 输 2 → 1.2³ × 0.8² = 1.10592 → **221.2**
  - 排一排：不玩 200／押10% 215.6／**押20% 221.2（顶点）**／押25% 219.7／押40% **197.6（转亏）**／押50% 168.8／全押 0
  - 对照例：赔率 2、赢面 0.7 → 输面 0.3 → **f\* = 0.55**（数字 2/0.7/0.3/0.55，与主例零冲突）
- **🔴 方法升级：弃用「一赢一输」当通用教具。** 它只在 p=0.5 时精确；p≠0.5 时会推出「最优 f 反而亏」的误导结论（初版就埋了这个雷）。改用**典型路径次数法**：(1+b·f)^W × (1−f)^L，且该路径上最优 f 恰等于凯利值 (W·b − L) / (b·(W+L))，教学与理论自洽、不再打架。

### 第三轮：浩总卡在「赔率」这个词上（知识的诅咒复发）

- **浩总原话**：「你给的赔率×赢的机会= 1×0.6。这个 1 赔率是什么？」
- **我犯的错**：全程只用「净赚 1 倍」四个字带过 b 的定义，**默认他懂赔率**。这正是他 8 月写作课上已结业的核心概念「知识的诅咒」——**我自己换到了他的位置上还没换过去**。术语一旦「看着很简单」，我就跳过了落地。
- **🔴 补上的落地教具（可复用，任何带参数的算例通用）**：
  - **每个字母第一次出现，必须用「押 1 块之后两个结局」各说一遍**：押 1 块 → 赢了拿回 1+b 块（净赚 b）／输了拿回 0 块（净亏 1）。**不许只写「净赚 1 倍」。**
  - **保本胜率 = 1 ÷（1 + b）** —— 这是解释「赔率在管什么」的最有效工具，比任何形容词都强：
    - b=0.5 → 门槛 66.7%／b=1 → 50%／b=2 → 33.3%
  - 同一 60% 胜率扫赔率 → **b=2 押 40%／b=1 押 20%／b=0.5 答案是负数＝别上桌**（顺手证明「胜率高 ≠ 有优势，要跟门槛比」）
  - 读法落地：`b × p` 读作「平均每押 1 块，从赢的那几次收回多少」，`q × 1` 读作「平均每押 1 块，输的那几次亏掉多少」
- **待观察的隐患**：体彩/博彩写的是**返还倍数**（1.95 = 押 1 拿回 1.95 → b = 0.95），与公式口径差 1。已提醒「填公式前先减 1」，**浩总实际用时需再确认一次他有没有减**。

### 第五~六轮：台阶切细（浩总两次喊难，教学法当场改）

- 浩总原话：「还是不理解 怎么算你一步一步引导我吧」→ 立刻**弃用「出整题让他做」**这一招，改成：**用他刚听过的故事当演示素材**，台阶切成三步（抄数字 → 认公式 → 填数字），**每轮只走一步、明确停住**。
- **浩总第一次作答：「赔率：1-0.4=0.6」——算式对、格子错。** 诊断：他不是不会算，是**没认出这个格子问的是哪个问题**，属于在「套动作」而不是「认问题」。
- **🔴 由此立的新教具（比给符号下定义有效得多）：给每个变量配一句「它在问什么」**
  - **赔率** → 「赢了赚几倍？」（去找「净赚几块」那句话）
  - **赢的机会** → 「十次里赢几次？」
  - **输的机会** → 「十次里输几次？」（＝1 减上一格）
- **浩总第二次作答：「赔率：3-1=2，赢的机会是0.4」——全对**，而且题面从头到尾没有出现过「3」，**是他自己补出的「拿回 3 块 − 本金 1 块」** → 说明第三轮强调的「净赚 ≠ 拿回」已经内化。
- **🔴 节奏结论**：对浩总，**一次只走一步 + 明说「这次真的只剩一步」**最有效；一次给完整解法（哪怕出于善意）会直接触发「还是不理解」。

### 第七~九轮：收口与巩固

- 浩总独立答完门槛判断题（「该玩」）→ 第一题彻底通了。随后**主动要第二道**（「还要巩固一下，你再出一道题给我」）。
- **新教具：公式变形 `f* = p − q/b`**（该押多少 = 赢的机会 − 输的机会 ÷ 赔率）。用来还清「÷ 赔率 到底在干嘛」这笔债，比原式直观；本题 0.4 −（0.6÷2）= 0.1。一句话解释：**赔率 2 ＝ 赢一次顶输两次，所以输的风险按一半算**。
- **第二道巩固题**：10 张牌（3 红 7 黑），押红赢、赢了净赚 4 块，本金 100。

### 第十二轮：浩总自己问出边界情况（理解的标志）

- **浩总原话**：「答案有没有可能是零？要是零的话我们该不该玩」——**三道题做完后主动推演边界，不再是被动跟**。
- **答案**：f\* = 0 ⟺ **赢面恰好等于门槛**（推导：b·p − q = 0 → p = 1/(1+b) ＝门槛公式）。所以门槛那条线**就是 f\* 的正负分界**：
  - 赢面 < 门槛 → f\* 负 → 不玩
  - **赢面 ＝ 门槛 → f\* ＝ 0 → 不玩**（押 0% 就是不上桌）
  - 赢面 > 门槛 → f\* 正 → 玩
- **挂上去的三条理由**：①押 0% 与不上桌是同一件事 ②**零期望 ≠ 零成本**（花时间、承担波动、"先连输几把"的本金风险）③**机会成本**——同样的时间本金放到有优势的地方会有收益。
- **顺手补的新知识（赌场模型）**：赌场赚钱不是靠赢你，是靠**把门槛抬到你的赢面之上**。例：押大小本该赔率 1（门槛 50%），赌场只给 0.95 → 门槛涨到 1÷1.95 ≈ **51.3%**，你的 50% 就过不去了，那 1.3% 就是庄家利润。
- **出图**：SVG 左右分栏（门槛线左侧＝不玩／右侧＝玩），把「门槛＝玩不玩的分界线」一次画死。
