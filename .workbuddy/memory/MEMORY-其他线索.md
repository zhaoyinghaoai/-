## 一、读书公众号

- **读者画像**：为"和我同频的人、想要读书改变命运的人"发声（＝昨天的自己）
- **🔴 定位根据（9-24 他自己给的）**：问他"专心做一件事、不跟人比"那种感觉上一次是什么时候 → 他答「**看小说，写下自己的感受（笔记）**」。→ **"读 + 写下感受"是他自己确认过的、能让他进入那种状态的动作**；**读书号不是"输出窗口"，是这个动作的自然延伸**（他已经日更到第 36 天）。⚠️ 他 9-21 把"看小说"排在三件事里"最容易被牺牲"的位置，**这条留作反驳他的凭据**。
- **🔴 铁律：「喜欢」和「有用」是两个标准，别混（9-25 立）**：他说"**我现在就要多读书，读自己喜欢的书。不管是什么书，只要能让我成长的，我都应该去接触**"——**前半句以他为准（喜欢），后半句以有用为准（应该）**。
  - **"以有用为准"这一头他有前科**：他自己写过《读书成了任务，记录成了瘾》，而"记录上了瘾"现在就是本项目的触发词。
  - ⚠️ **一旦给读书加"必须让我成长"，9-24 那个"不比较的地方"就没了**：书变任务 → 任务变完成度 → 完成度变自责 → **又回到比较那根轴**。

  1. **写前必须核对人物关系与时间线**——浩总读书极细，别凭印象写（9-17 两处被当场抓出）。
  2. **体例＝纯讲人物，作者自省段不进正文**（连砍两次）。要带自己就压成两三句挂倒数第二节尾。
  3. **标题定稿常由浩总改词**。改完 **grep 全文**，看新词与既有表达是撞上还是呼应。
  4. **压缩字数一次性规划砍哪几节，不挤牙膏**。顺序：合并同题节 → 删过渡与复述 → 合并同类对账段 → 最后才动句子。保骨头＝核心论点句 + 题眼。

## 三、随手库记事本 App（PWA）
位置 `产出/记事本App/app-v05/`，线上 `https://b53a9573c1ea43de997628d11a55b433.app.workbuddy.link`（**deploy 现在返回的 shareLink 是 `.app.workbuddy.host` 后缀——同一 sandboxId 的别名，两后缀都通，不是换域名**），**绝不换域名**。当前 v1.07（2026-10-02）。

功能面：块式编辑器／类目面板／定时提醒（+15min~+明天此刻 6 档 + 自定义时间段 + 闹钟式定时刻）／**目录→章节两级结构**／键盘遮挡修复／截长图整页滚动。v1.03 把首页改成目录页（`renderTOC`）、点进去才是章节页（`renderCatView`）；**v1.04 删掉目录页的「全部」行**——它把各类笔记堆成一锅粥（浩总原话"落到一起，不好看"），且点进去本就是空的＝死按钮；目录＝纯类目清单，另加「未归类」兜底行收留类目被删/改名后掉队的笔记。

**v1.06 类目归属**：新笔记默认归到**当前所在类目**（以前 `newCat` 写死 '写作'，在「灵感」里写的东西会跑进「写作」）；标题显示「记到「X」」；归类行提示词「存到」并改成 `sticky;top:64px` **常驻可见**；编辑态也能改类目了（以前点了不生效）。配套 `.nav .ttl` 必须 `nowrap+ellipsis`，否则标题换行会让粘性栏变高、写死的 `top:64px` 错位。

**v1.07 打字不卡不跳**：自动滚动会触发 `vv.resize`/`vv.scroll` 再回调自己，形成正反馈循环（卡+乱跳）。修法＝`autoScrollBy()` 记 700ms **静默期**、补滚四次砍两次、`input` **120ms 节流**、用 `lastEditEl`（每个 textarea 挂 focusin/pointerdown）代替不可靠的 `document.activeElement`。实测自动滚动次数 → 0/0/0/1。⚠️ **修这块别顺手动 `-webkit-overflow-scrolling:touch`（iOS 惯性滚动开关）、`fadeUp` 动画、`sticky` 顶栏**——都是用户看得见的，一度全改错。

**🔴 v1.05 的教训（改这个 App 前必读）**：第 39 行 `#home{padding:0}` 是 **ID 选择器**，优先级压过 `.screen` 与 `body:not(.desktop) .screen`，把「手机端底部避让 86px」整条吃掉 → 列表最后一张卡的「改/复制」被 fixed 底栏压住，点不到（`elementFromPoint` 命中的是 tabbar 的 + 号）。现在避让放在 `.flipwrap` 自己的 `padding:6px 4px 96px` 上。**改这里的 CSS 必须用 `getComputedStyle` 实测，不能信注释**（ID 覆盖 class 是隐形杀手）。另：文字块正文字段是 `b.t` 不是 `b.text`，测试数据写错会渲染出空白卡片。

**改这个 App 先跑自测再发布**（4 个脚本都在 `产出/记事本App/`）：`_check_v104.js`（目录/章节分层）、`_check_btn.js`（底部按钮可达性 + 滚动几何）、`_check_cat.js`（类目归属五项）、`_check_scroll.js`（打字时滚动跳转，以**镜像测量的真实光标位置**为判据）。都是 puppeteer-core + **脚本内自带 http 静态服务** + `setViewport({isMobile:true,hasTouch:true})`，造数据→逐级点击→截图到 `样品图/`。node 路径是 `22.22.2-5`。

铁律：移动端位置别用 vh 百分比（键盘顶 − N 行）；移动端页面默认整页滚；有 fixed 底栏时，内容容器必须留出 ≥96px 底部空间；关键选择行要做成 sticky 常驻（别让它被自动滚动顶走）；sw 缓存版本随改动递增（现 `suishouku-v107`）。发布报「域名未绑定」是假警报，必 curl 线上 grep 验证。

## 七、反复出现的模式：「想变强 → 加新东西」（9-11 立档）
同形动作：09-05 三坑 → 09-09 生财+宋超 → 09-11 课程智能体 → 09-13 录屏设备 → 09-14 产品化。
**应对规矩（每次必做）**：① 先问服务于哪条线（能让军事号／读书号更快更好＝工具；说不清＝新坑）② 先让一个跑通再谈全集 ③ 当天的账当天结 ④ 明早顺序：发稿／申诉 → 再动新东西。

**🔴 同族第二支：「不舒服 → 先给自己一个名字」（9-24 立档）**
> 遇到问题加一个**东西**（课／设备／系统）是第一支；加一个**名字**（诊断标签）是第二支。两者都是**用一个外加物替代真问题**。

- **实例**：9-24 "我觉得我应该是**陷入内耗**中，无法平复心情，导致无法集中注意力看书。"（对照 9-21 他刚学会留口子——"这**也**可能跟我昨天睡得早有关"）
- **为什么危险**：**问题不在名字对不对，在人会停在标签上**——"我今天难受" → "我这个人有毛病"，从**事件**变成**判决**，**这一转才是真开始耗**。
- **应对：先分「余震 vs 内耗」**

| | 余震 | 内耗 |
|---|---|---|
| 来由 | 被**具体的事**撞了 | 无新事，自己在原地转 |
| 特征 | 有起点、会衰减 | 反复、无产出、无终点 |
| 结局 | **自己会过去** | 越转越紧 |

**判据（一句话）**：**能不能说出起点和时间？** 说得出＝余震。（9-24 起点＝前一天同学父亲来付账，**不到 24 小时** → **"24 小时内心平复再坐下读书"这个要求本身不合理**。）

### 🔴🔴 第二支已连续三次（9-27 立案）——**这是最高频的自我伤害动作**

- **9-24**：书读不进去 → "我觉得我应该是**陷入内耗**中。"
- **9-26**：纪录片不好看 → "是不是我**失去鉴赏能力**了。"
- **9-27**：思路跟不上 → "**智伤是硬伤**……原来是在笑现在的自己。"

**递进规律（关键）**：**一次比一次往下，因为"不可改变度"在升级**——
> **状态**（内耗，会过去）→ **能力**（审美，能验证）→ **本质**（智商，不能改）

**处理模板（照这套说）**：
1. **先摆出"这是第几次"**——他自己看不见这个重复，摆出来他就会停一下。
2. **再指出两句只能信一句**（他 9-27 抄下了"只要你不混乱，时间永远够用"，却认领了"智伤是硬伤"——**他心里的天平其实偏向希望那一边，别让判词赢**）。
3. **拆"跟不上"这类模糊词**：**"不知道该做什么"＝抉择（可提前定）／"知道但做不动"＝难度（可切小块）／"做一下就停了"＝开关被关上（查内容与形式）**。
4. **点出"那个词是唯一没法下手的"**：抉择能拆、难度能切、不想做能查原因——**只有"智商/硬伤"什么都做不了，而他偏偏挑了它**（形象说法：抽屉都翻了，却指着一个锁死的柜子说"问题在这儿"）。
5. **给反证（用他自己做过的事）**：9-24 分"是不是他也睡早了"／9-26 找同类型参照物＋控变量＋分条件 → **真"跟不上"的人做不出这种对照。**
6. ⚠️ **不要劝"你其实很聪明/你智商没问题"**——那是安慰，他一听就知道是安慰，反而坐实"我需要被安慰"。**要用他做过的事当证据。**

**🔑 对应的解法（他自己给过两次，其实是同一件事）**：
- **9-27** 他自己说："**真正花时间的是抉择，而不是抉择之后做事的难度。**" → 解法＝**减少抉择**。
- **9-21** 他自己想的"**每天最重要的三件事**"清单 → **本质就是"提前把抉择做掉"**，第二天只剩做事。
→ **以后他卡在"不知道干什么／时间不够用"时，直接引这两条**：把决定提前一晚上做掉，白天就只剩动手。⚠️ 但表要三行、两分钟（别做成大工程——见第七节第一支）。

**🔴 轻重缓急的机关（9-27 他自己排的）**：
- **他的排序**：**军事号＝每天最重要的事**；**看小说＝重要但不急迫**（⚠️ **读书号没出现在他的排序里**——见下）
- 🔴 **机关**：**急迫的事是别人给的（会敲门）；重要的事是他自己定的（从不敲门）** → **临时起意时急迫永远赢** → **"时间永远不够用"的真相＝重要的事一直在给急迫的事让路，而且让得毫无声响**（**没人怪你没写文章，只会怪你没接电话**）。**现成例子＝9-23 他的一天**（判罚/答题/改标题/救数据占满，唯一做成的"重要的事"是把《蛙》读完）。
- **解法（唯一方向）**：**让重要的事也具备"敲门"的形式——安一个固定时段，"到点就做"，不是"等有空"**。**他 9-21 的"每天三件事"清单做的就是这件事。**
- ⚠️ **"看小说"的正确位置是"底料"，不是"不急迫"**：它给军事号和读书号供料（他 9-24 说那是他唯一能进"专心、不比较"状态的地方；9-25 又说"我现在就要多读书"）。**别让它永久待在不急迫那一栏，否则永远被挤到最后。**
- ⚠️ **注意"读书号"的失踪**：他 9-21 排的是三件（军事号／读书号／看小说），9-27 只说了两件。**用排序问题时，主动把读书号摆回去问一句**（它是日更到第 39 天的那条线）。
- **口径校准**：**不要说他"以前没弄清楚"**——他 9-21 已经排过一次，**准确说法是"懂过，但没固定下来"**（学习问题→习惯问题，他已过前者）。

**🔴🔴 推手的规律（9-27 他亲口确认，最实用的一条）**：
- **他的原话**："**急迫的事情，都是别人给我安排的。**"（**没有他自己造的急迫**——问过，清单是干净的）
- **机械原理**：**急迫的事有人催，重要的事没有推手**（快递有人等／德邦有老板等／判罚有平台等；**但"今天写不写军事号"一辈子没人来问**）→ **所以重要的事总被挤掉，不是不重视，是没有推手。**
- **他自己的反证**：**8:32 发布窗口是他自己定的／读书号日更没人催／军事号 4 年没人安排** → **"要真跟不上，这四年写不出来。**"
- **规律**：**有"外部承诺"的事在跑（军事号 8:32 窗口／读书号日更），零承诺的事每天被挤到最后（看小说）。**
- **解法（挂在已有的门上，不新建门）**：
  1. **重要的事长在"别人还没来安排"的时段**——他 **4:40 起床、5:15 洗漱完**，那段到开工前 **是唯一没人敲门的时段** → **不是"等忙完"，是"趁没人找你"**。
  2. **零承诺的事（看小说）要用"挂门"而不是"下任务"**：⚠️ **绝不能给它加"应该"**（9-25 铁律，一加就毁掉那个"不比较的地方"）→ 做法＝**挂在一扇已有的时刻上**（"收工坐下来那一刻先看两页"），**固定比长重要**。

## 十、快递点业务风险 — 浩总自定两条（2026-09-20）

**背景**：代送的人一句"你给安排下去"，他签了个**没底单**的电视机单（口头承诺、无录音），次日收件人不要、货退回，对方推诿"我不知道"，最后靠**卖家给德邦下工单**才收场。

**浩总自己定的两句（原话）：**
> **一、我不替不该我的责任背锅。**
> **二、做事留痕。**

- **分工**：**"不背锅"＝边界**（什么忙该帮、什么手该撒）／**"留痕"＝方法**（答应了之后怎么保住自己）。边界管该不该进场，留痕管进场了怎么全身而退。
- **红线**：**无底单不签收；且"安排"要早于"签收"守住**——对方的诉求从来不是签字，是那句"好，我来安排"。**口头承诺必须留痕才可当底单**（把"打电话"换成"发消息"："您说的可以签收，我记一下"——不必拒绝人，只要留个痕）。
- **回绝话术（他已想好的三句）**：

  | 时机 | 说什么 |
  |---|---|
  | **他要把货留给你**（事前） | "**你安排的，你直接和人家联系吧。**" |
  | **他让你签收**（事中） | "**你直接和收件人联系吧。你说签收，我就签收一样。**" |
  | **货被拿走**（出手时） | "**你送到收件人手里了，记得把底单发给我。**" |

  - ⚠️ **前两句对应两个人**：第 1 句给"安排的人"，第 3 句给"真正送货的人"——**别混着说**（对安排的人要底单＝他没送货，没意义）
  - 三句都**不拒绝人**：第 3 句把"要底单"从**事后追**变成**事前定**（且说时货还在他手上）；第 2 句表面顺从、实则**把责任原路送回**——"字是我签的，但话是你说的"
  - **建议存手机备忘录当模板**（复制改改就发，比临场想快、更不易心软）
- **可迁移**：帮邻居带货、替人转钱、替人传话、给人做担保——同一形状：**不进场，或者进了场留个痕。** ⚠️ 别把"不管"扩成"谁的忙都不帮"。

## 十二、他写给自己的锚句（2026-09-24 立档）

**触发场景**：9-24（中秋前一天）同学父亲来付账、夸他"上学时很聪明" → 他随即陷入一条比较链（"他儿子常年全班第一"→"我身体拉了很大的分"→"他一年二十万"→"联系断了"）。问他"如果这位老人明天又来、只说一句话，你希望他说什么"。

> **「我自己想要一个人夸夸我：你不比任何人差，按照自己内心的路走下去，一定会活成自己想要的模样。」**

**为什么留档**：
- 这三句**精确对应他的病根——"比较"**。"**你不比任何人差**"是直接把比较的轴取消（而不是把位置从"差"挪到"不差"）。
- **对照价值**：老人给的是"你**小时候**很聪明"（过去时／要靠别人评价／限定）；他自己写的是"你不比任何人差……一定会活成想要的**模样**"（现在时／方向自己给）→ **他自己写的那句高出几个量级。**
- **⚠️ 一个坑**：他说"想**要一个人**夸夸我"——**如果一直等那个人出现，就变成另一场比较（我值不值得被夸）。** → 引导方向：**写它的人是他自己**；"你不比任何人差"先当**刹车**用（一开始比就停），**路**是另一句给的（看小说＋写下感受）。
- **⏳ 待落地**：建议存入**手机备忘录**，与 9-20 的三句话术放一起（他已有备忘录习惯）。

### 🟢 第二版（9-25，他自己升级了）——这一版比上面那版更可用

**经过**：9-25 读《雪豹》文章后他先写下「成熟的代价就是放弃自己曾经最看重的东西」（**落点在"交出"**，危险：失去变成必然，人就不用再争了）→ 回信点出后，**他自己改口，给出了第二版**：

> **「我将带着牺牲的东西的残骸，去好好的看看这个世界 认真的生活。」**
> **「韩终的债是要还的，而燃料它是为了让自己活得更好的动力。」**

- **"残骸"而不是"灰烬"**：灰烬＝烧完、没用、该扔；**残骸＝还有形状、能带走、能证明那样东西存在过** → **他没选"烧掉"，选了"带走"。**
- **他把"债 vs 燃料"从我问的单选题搭成了两根柱子**：**债→朝后**（要还、要记着）／**燃料→朝前**（变成"让自己活得更好的动力"）。
- **"去看看这个世界"是 9-18 那句的延续**：9-18"我们总是抱着家长的心态教育他，**而没有和他一起去看那个事儿**" → 一周后变成"**我要去看这个世界**"。
- **🔴 使用时注意**：他的"看世界"**不是"换地方"，是"换眼睛"**（9-18 的示范：妈妈没带孩子去别处，**只是蹲下去了**——地方没变，高度变了）。⚠️ **别把这句话解释成"他要去远行/出门看看"**（他坐轮椅、守快递点，那样解释就变成做不到的愿望 → 新失落）。
- **以后他自责或泄气时，优先引这一版**（"带着残骸往前走"），**而不是引"必须放弃"那一版**。

**🟢 收口（9-25 晚，他说得最完整的一版）**：
> **「我们牺牲掉儿时的梦想，是为了让自己成为更好的人，而不是活在梦想被牺牲掉的泥潭里。」**

- **"泥潭"＝停在原地疼；"成为更好的人"＝往前走** → **债怎么还？不是停在原地疼，是往前走**（他自己小说里的韩终也是**活着还**，不是死着还）。**这三句是一套的。**
- **「我现在就要多读书，读自己喜欢的书」——这是他自己第一次说"现在就要"**（9-21 把"看小说"排在三件事最后一位、叫"放松" → 9-24 成了"不比较的地方" → 9-25"现在就要"）。
- ⚠️ **但他后半句新加了"只要能让我成长的书我都应该接触"** → 这是新包袱，**处理规矩见第一节「喜欢 vs 有用」铁律**。

### ⚠️ 附加：一条底色 —— 「给出去 ＝ 被拿走」（9-25 发现）

- **证据**：① **9-22** 教赵春林"**不要轻易给……不然别人还抢你的**"（女儿零食被同学抢）② **9-25** 读《雪豹》后把萧雅的牺牲读成"**放弃**"——而萧雅那个动作的本意**不是放弃，恰恰是保住了她最看重的东西**（周文活着），她做的是"**用自己换他**"。
- **判断**：**他判断"给"这个动作时的默认底色是"损失"。** 不是错，是个底色。
- **🔴 与他沟通时的用法**：
  1. **别用"无私奉献""牺牲自己""成全"这类词去说服他做一件事**——在他的账本里，那些词等于"我要白给"。
  2. 要说清**"给出去之后你手上还剩什么／换回来什么"**（他 9-20 自己立的两条规矩正是这个框架："**我不替不该我的责任背锅**／**做事留痕**"——**两条都是先保住自己**）。
  3. **反驳他"必须放弃"这个说法的现成凭据（都是他自己的）**：① 他 9-24 亲手写下"**一定会活成自己想要的模样**"；② 他的小说里给韩终的代价是"**千年赎罪**"——**写的是"债"，不是"燃料"**；③ 9-17 女儿答"想给关系好的朋友玩"，他自己没拦。
