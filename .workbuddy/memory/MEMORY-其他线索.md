## 一、读书公众号

- **读者画像**：为"和我同频的人、想要读书改变命运的人"发声（＝昨天的自己）
- **🔴 定位根据（9-24 他自己给的）**：问他"专心做一件事、不跟人比"那种感觉上一次是什么时候 → 他答「**看小说，写下自己的感受（笔记）**」。→ **"读 + 写下感受"是他自己确认过的、能让他进入那种状态的动作**；**读书号不是"输出窗口"，是这个动作的自然延伸**（他已经日更到第 36 天）。⚠️ 他 9-21 把"看小说"排在三件事里"最容易被牺牲"的位置，**这条留作反驳他的凭据**。
- **🔴 铁律：「喜欢」和「有用」是两个标准，别混（9-25 立）**：他说"**我现在就要多读书，读自己喜欢的书。不管是什么书，只要能让我成长的，我都应该去接触**"——**前半句以他为准（喜欢），后半句以有用为准（应该）**。
  - **"以有用为准"这一头他有前科**：他自己写过《读书成了任务，记录成了瘾》，而"记录上了瘾"现在就是本项目的触发词。
  - ⚠️ **一旦给读书加"必须让我成长"，9-24 那个"不比较的地方"就没了**：书变任务 → 任务变完成度 → 完成度变自责 → **又回到比较那根轴**。

  1. **写前必须核对人物关系与时间线**——浩总读书极细，别凭印象写（9-17 两处被当场抓出）。
  2. **体例＝纯讲人物，作者自省段不进正文**（连砍两次）。要带自己就压成两三句挂倒数第二节尾。
  3. **标题定稿常由浩总改词**。改完 **grep 全文**，看新词与既有表达是撞上还是呼应。

## 七、反复出现的模式：「想变强 → 加新东西」（9-11 立档）
同形动作：09-05 三坑 → 09-09 生财+宋超 → 09-11 课程智能体 → 09-13 录屏设备 → 09-14 产品化。
**应对规矩（每次必做）**：① 先问服务于哪条线（能让军事号／读书号更快更好＝工具；说不清＝新坑）② 先让一个跑通再谈全集 ③ 当天的账当天结 ④ 明早顺序：发稿／申诉 → 再动新东西。

**🔴 同族第二支：「不舒服 → 先给自己一个名字」（9-24 立档）**
> 遇到问题加一个**东西**（课／设备／系统）是第一支；加一个**名字**（诊断标签）是第二支。两者都是**用一个外加物替代真问题**。

- **实例**：9-24 "我觉得我应该是**陷入内耗**中，无法平复心情，导致无法集中注意力看书。"（对照 9-21 他刚学会留口子——"这**也**可能跟我昨天睡得早有关"）
- **为什么危险**：**问题不在名字对不对，在人会停在标签上**——"我今天难受" → "我这个人有毛病"，从**事件**变成**判决**，**这一转才是真开始耗**。
- **应对：先分「余震 vs 内耗」**

| | 余震 | 内耗 |
|---|---|---|
| 来由 | 被**具体的事**撞了 | 无新事，自己在原地转 |
| 特征 | 有起点、会衰减 | 反复、无产出、无终点 |
| 结局 | **自己会过去** | 越转越紧 |

**判据（一句话）**：**能不能说出起点和时间？** 说得出＝余震。（9-24 起点＝前一天同学父亲来付账，**不到 24 小时** → **"24 小时内心平复再坐下读书"这个要求本身不合理**。）

- **给建议的方式：余震期给"许可"，不给"方法"。** 最优解是"**承认今天做不了**"，而不是"怎么治好它"。⚠️ 也不要布置一个缩小的任务当安慰（"就读一页"）——**那等于换个形式的考试。**

## 九、家庭
- 大女儿**赵春林**（3 岁半）；小女儿**赵思齐**（1 岁半）；媳妇与妈妈照顾孩子
- **🔴 教孩子的方式（9-18/9-19 两条）**：
  1. **对待姐姐和妹妹，镜头不一样**——姐姐被放在"将来要担事"的位置，行为被当**能力信号**读；妹妹没被派任务，行为被当**"她在看什么"**读（浩总自述："换成赵春林的话我可能会批评她"）。**解法只有一个动作：哪次她做"没用的、不涨本事的"事时，先蹲一次、什么都不说**（别提前宣布，一说就变新任务）
  2. **哭闹时"看"比"管"管用**——9-19 姊妹俩一起哭，他**吼了一句后中途刹住**，忙完**盯着她看了一会儿，她慢慢就不哭了**。**刹车在中途才是能重复的本事。** 解释过"带不下"她还哭，是因为**解释解决"去不去"，解决不了"我不想被留下"**
- **「教女儿赚钱本事」实验（9-13 起）**：泡泡枪 + 30 盒泡泡液。⚠️ **9-17 实况：泡泡液是"一小包一小包"分装** → 原"1 元／瓶"卖法作废。**9-17 问她自己想怎么分 → 答"只给关系好的朋友"** → 下一步：先把"给"做完，**等好朋友用完再来要的那天，才是"定价"入场时机**。
- **🔴 9-22 实验出第一个真实结果**：她把零食给同学**阮敬琪**（**老师还表扬了她**），对方反倒抢她东西、**以为她好欺负** → **「给」她学会了，「被拿走」还没学会**。浩总今天教两句：①「再抢就一耳巴子打他脸上」②「不要轻易给陌生人，要在能保护好零食的情况下再给」。⚠️ **两个待修正点已提**：①**抢她的是「她给过的同学」，不是「陌生人」**——用她自己 9-17 那句「想给关系好的朋友」更对得上 ②**打脸的次序要换**：先当场出声「这是我的，还给我」（**声音是给老师听的**）→ 把东西拿回来 → 告诉老师；**打不用教，要教「先出声、再找老师」**。**他的落点：善良要在保护好自己的前提下给，不然就成了别人眼中的软弱。**
- **📍 泡泡实验的场地问题（9-22）**：**他没让赵春林把泡泡水带去幼儿园**（觉得一小包不值一块钱），加上**老师明说家里玩具不许带去幼儿园** → **这不是实验暂停，是场地一直选错**：幼儿园是**别人的地盘**（老师的规矩、会抢东西的小朋友）→ **正确场地＝家门口／院子／熟人家的小孩**。⚠️ **"不值一块钱"不能当理由**——实验目的是**练手不是赚钱**，**不值钱恰恰是优点（送出去、亏了都不心疼）**；**泡泡水有保质期，搁久了会漏会失效**（要么近期用掉一批，要么降级，别挂着不动）。
- **给育儿建议的铁律（9-22 验证）**：**他教孩子管用的一直是「动作」不是「道理」**（9-19 盯着看就不哭；9-22 三岁半听不懂「陌生人」「有能力保护」这类条件句）→ **给建议时给一个能做的动作，不给一套该懂的道理。**
- 配合方式：**别教术语教动作**；卖不出去本就是目的；真卖出夸"你想的办法好"。

## 十、快递点业务风险 — 浩总自定两条（2026-09-20）

**背景**：代送的人一句"你给安排下去"，他签了个**没底单**的电视机单（口头承诺、无录音），次日收件人不要、货退回，对方推诿"我不知道"，最后靠**卖家给德邦下工单**才收场。

**浩总自己定的两句（原话）：**
> **一、我不替不该我的责任背锅。**
> **二、做事留痕。**

- **分工**：**"不背锅"＝边界**（什么忙该帮、什么手该撒）／**"留痕"＝方法**（答应了之后怎么保住自己）。边界管该不该进场，留痕管进场了怎么全身而退。
- **红线**：**无底单不签收；且"安排"要早于"签收"守住**——对方的诉求从来不是签字，是那句"好，我来安排"。**口头承诺必须留痕才可当底单**（把"打电话"换成"发消息"："您说的可以签收，我记一下"——不必拒绝人，只要留个痕）。
- **回绝话术（他已想好的三句）**：

  | 时机 | 说什么 |
  |---|---|
  | **他要把货留给你**（事前） | "**你安排的，你直接和人家联系吧。**" |
  | **他让你签收**（事中） | "**你直接和收件人联系吧。你说签收，我就签收一样。**" |
  | **货被拿走**（出手时） | "**你送到收件人手里了，记得把底单发给我。**" |

  - ⚠️ **前两句对应两个人**：第 1 句给"安排的人"，第 3 句给"真正送货的人"——**别混着说**（对安排的人要底单＝他没送货，没意义）
  - 三句都**不拒绝人**：第 3 句把"要底单"从**事后追**变成**事前定**（且说时货还在他手上）；第 2 句表面顺从、实则**把责任原路送回**——"字是我签的，但话是你说的"
  - **建议存手机备忘录当模板**（复制改改就发，比临场想快、更不易心软）
- **可迁移**：帮邻居带货、替人转钱、替人传话、给人做担保——同一形状：**不进场，或者进了场留个痕。** ⚠️ 别把"不管"扩成"谁的忙都不帮"。

### 🔴 德邦签收流程（2026-09-23 浩总提出）——真正的"结构性问题"

**症状**：**德邦件都要先打电话、然后才能发短信签收，光这个一天花掉 2 小时**，浩总"很上火"。他说想做**一个帮他打电话、能录音的软件**。

- **判读**：判罚／数据是偶发，**这个天天付**——是三个上火源里**唯一结构性的、可以砍的**；且它**吃正撞浩总上午黄金 1 小时**。
- 🔴 **第一原则：先改流程，再考虑工具。** 该问的是 **"能不能把『打电话』这一环省掉"**，不是"怎么写一个会打电话的软件"。
  - **要查的**（先问老板/德邦业务员/网点）：
    1. **能不能批量**（一个电话／一条群消息确认一片；有没有批量签收入口）
    2. **能不能换人打**（老板打／德邦业务员自己联系收件人）
    3. **能不能换渠道**（网点专用系统、企业微信、代签协议）
    4. **能不能定时段**（集中到一段打，别零星插进上午黄金时间）
- **技术可行性（备用）**：真要做，**不是"AI 打电话"（难、外呼需线路/资质、易被标记骚扰）**，而是**「外呼 + 通话自动录音」**——Android 上 `CALL_PHONE` 就**要** `CALL_PHONE` 权限走系统拨号 + 现场录音（**双卡要选 SIM**）。国内可用现成工具：**小米自带通话录音**（他有小米）；要自动拨号＋录音可用 **Tasker/AutoInput 调系统拨号＋通话录音**。**iOS 做不到**。
- ⚠️ **法律提醒**：**别静默录**——`《民诉法解释》`以后**录音只作证据、不作"合法授权"**；告知一句"我这通电话会录音"最稳（也刚好符合他 9-20 自定的"**做事留痕**"）。

## 十二、他写给自己的锚句（2026-09-24 立档）

**触发场景**：9-24（中秋前一天）同学父亲来付账、夸他"上学时很聪明" → 他随即陷入一条比较链（"他儿子常年全班第一"→"我身体拉了很大的分"→"他一年二十万"→"联系断了"）。问他"如果这位老人明天又来、只说一句话，你希望他说什么"。

**他的原话（照存）**：
> **「我自己想要一个人夸夸我：你不比任何人差，按照自己内心的路走下去，一定会活成自己想要的模样。」**

**为什么留档**：
- 这三句**精确对应他的病根——"比较"**。"**你不比任何人差**"是直接把比较的轴取消（而不是把位置从"差"挪到"不差"）。
- **对照价值**：老人给的是"你**小时候**很聪明"（过去时／要靠别人评价／限定）；他自己写的是"你不比任何人差……一定会活成想要的**模样**"（现在时／方向自己给）→ **他自己写的那句高出几个量级。**
- **⚠️ 一个坑**：他说"想**要一个人**夸夸我"——**如果一直等那个人出现，就变成另一场比较（我值不值得被夸）。** → 引导方向：**写它的人是他自己**；"你不比任何人差"先当**刹车**用（一开始比就停），**路**是另一句给的（看小说＋写下感受）。
- **⏳ 待落地**：建议存入**手机备忘录**，与 9-20 的三句话术放一起（他已有备忘录习惯）。

### 🟢 第二版（9-25，他自己升级了）——这一版比上面那版更可用

**经过**：9-25 读《雪豹》文章后他先写下「成熟的代价就是放弃自己曾经最看重的东西」（**落点在"交出"**，危险：失去变成必然，人就不用再争了）→ 回信点出后，**他自己改口，给出了第二版**：

> **「我将带着牺牲的东西的残骸，去好好的看看这个世界 认真的生活。」**
> **「韩终的债是要还的，而燃料它是为了让自己活得更好的动力。」**

- **"残骸"而不是"灰烬"**：灰烬＝烧完、没用、该扔；**残骸＝还有形状、能带走、能证明那样东西存在过** → **他没选"烧掉"，选了"带走"。**
- **他把"债 vs 燃料"从我问的单选题搭成了两根柱子**：**债→朝后**（要还、要记着）／**燃料→朝前**（变成"让自己活得更好的动力"）。
- **"去看看这个世界"是 9-18 那句的延续**：9-18"我们总是抱着家长的心态教育他，**而没有和他一起去看那个事儿**" → 一周后变成"**我要去看这个世界**"。
- **🔴 使用时注意**：他的"看世界"**不是"换地方"，是"换眼睛"**（9-18 的示范：妈妈没带孩子去别处，**只是蹲下去了**——地方没变，高度变了）。⚠️ **别把这句话解释成"他要去远行/出门看看"**（他坐轮椅、守快递点，那样解释就变成做不到的愿望 → 新失落）。
- **以后他自责或泄气时，优先引这一版**（"带着残骸往前走"），**而不是引"必须放弃"那一版**。

**🟢 收口（9-25 晚，他说得最完整的一版）**：
> **「我们牺牲掉儿时的梦想，是为了让自己成为更好的人，而不是活在梦想被牺牲掉的泥潭里。」**

- **"泥潭"＝停在原地疼；"成为更好的人"＝往前走** → **债怎么还？不是停在原地疼，是往前走**（他自己小说里的韩终也是**活着还**，不是死着还）。**这三句是一套的。**
- **「我现在就要多读书，读自己喜欢的书」——这是他自己第一次说"现在就要"**（9-21 把"看小说"排在三件事最后一位、叫"放松" → 9-24 成了"不比较的地方" → 9-25"现在就要"）。
- ⚠️ **但他后半句新加了"只要能让我成长的书我都应该接触"** → 这是新包袱，**处理规矩见第一节「喜欢 vs 有用」铁律**。

### ⚠️ 附加：一条底色 —— 「给出去 ＝ 被拿走」（9-25 发现）

- **证据**：① **9-22** 教赵春林"**不要轻易给……不然别人还抢你的**"（女儿零食被同学抢）② **9-25** 读《雪豹》后把萧雅的牺牲读成"**放弃**"——而萧雅那个动作的本意**不是放弃，恰恰是保住了她最看重的东西**（周文活着），她做的是"**用自己换他**"。
- **判断**：**他判断"给"这个动作时的默认底色是"损失"。** 不是错，是个底色。
- **🔴 与他沟通时的用法**：
  1. **别用"无私奉献""牺牲自己""成全"这类词去说服他做一件事**——在他的账本里，那些词等于"我要白给"。
  2. 要说清**"给出去之后你手上还剩什么／换回来什么"**（他 9-20 自己立的两条规矩正是这个框架："**我不替不该我的责任背锅**／**做事留痕**"——**两条都是先保住自己**）。
  3. **反驳他"必须放弃"这个说法的现成凭据（都是他自己的）**：① 他 9-24 亲手写下"**一定会活成自己想要的模样**"；② 他的小说里给韩终的代价是"**千年赎罪**"——**写的是"债"，不是"燃料"**；③ 9-17 女儿答"想给关系好的朋友玩"，他自己没拦。
