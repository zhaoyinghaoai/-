## 十、快递点业务风险 — 浩总自定两条（2026-09-20）

**背景**：代送的人一句"你给安排下去"，他签了个**没底单**的电视机单（口头承诺、无录音），次日收件人不要、货退回，对方推诿"我不知道"，最后靠**卖家给德邦下工单**才收场。

**浩总自己定的两句（原话）：**
> **一、我不替不该我的责任背锅。**
> **二、做事留痕。**

- **分工**：**"不背锅"＝边界**（什么忙该帮、什么手该撒）／**"留痕"＝方法**（答应了之后怎么保住自己）。边界管该不该进场，留痕管进场了怎么全身而退。
- **红线**：**无底单不签收；且"安排"要早于"签收"守住**——对方的诉求从来不是签字，是那句"好，我来安排"。**口头承诺必须留痕才可当底单**（把"打电话"换成"发消息"："您说的可以签收，我记一下"——不必拒绝人，只要留个痕）。
- **回绝话术（他已想好的三句）**：

  | 时机 | 说什么 |
  |---|---|
  | **他要把货留给你**（事前） | "**你安排的，你直接和人家联系吧。**" |
  | **他让你签收**（事中） | "**你直接和收件人联系吧。你说签收，我就签收一样。**" |
  | **货被拿走**（出手时） | "**你送到收件人手里了，记得把底单发给我。**" |

  - ⚠️ **前两句对应两个人**：第 1 句给"安排的人"，第 3 句给"真正送货的人"——**别混着说**（对安排的人要底单＝他没送货，没意义）
  - 三句都**不拒绝人**：第 3 句把"要底单"从**事后追**变成**事前定**（且说时货还在他手上）；第 2 句表面顺从、实则**把责任原路送回**——"字是我签的，但话是你说的"
  - **建议存手机备忘录当模板**（复制改改就发，比临场想快、更不易心软）
- **可迁移**：帮邻居带货、替人转钱、替人传话、给人做担保——同一形状：**不进场，或者进了场留个痕。** ⚠️ 别把"不管"扩成"谁的忙都不帮"。
