## 15:3x 随手库 v1.07 —— 改第一行的字，页面一下子跳到最后

**浩总反馈**：「随手库里面的向上滑怎么有点卡？比如说，你想修改第一行的内容，它一下子就跳到最后的一行去了」

**根因链（三个叠在一起）**
1. **自动滚动没有静默期**：点一下 + 敲一个字会连环触发好几个滚动（focusin 排的 `[120,300,600,900]` 四次补滚 + `input` 事件 + `visualViewport` 的 scroll/resize）
2. **自动滚动会触发自己的事件**：滚一下 → `vv.resize`/`vv.scroll` → 又调 `fix()` → 再滚，**正反馈循环**，这就是"卡"的来源
3. **靠 `document.activeElement` 判断"光标在哪"不可靠**：App 自己的键盘垫工具条会抢焦点 → 判错方向

**改法**
- `autoScrollBy()`：凡是这台代码滚出来的，记 700ms 静默期，期内 `fix()` 直接 return
- 补滚从 `[120,300,600,900]` 四次砍到 `[150,450]` 两次
- `input` 事件加 **120ms 节流**（连续输入合并成一次，手感不变、负担降一个量级）
- 每个 textarea 挂 `focusin`/`pointerdown` 记进 `lastEditEl`，不再依赖 `activeElement`

**实测**（`_check_scroll.js`，20 行笔记、模拟四个场景）：自动滚动触发次数降到 **0 / 0 / 0 / 1**，四个场景光标都稳定停在键盘上方。

**⚠️ 中途踩的两个坑（都记进 skill 了）**
1. **一度想做到"打字时零滚动"→ 弄出更糟的 bug**：点 textarea 的 padding 空白区（CSS padding 区不参与命中测试）时，浏览器把空白区滚进视野 → 光标被推到编辑器底边、屏幕上出现一大片空白。补救要加"聚焦补偿"：聚焦后一帧检查光标是否在视野舒适区（8%~55%），不对就**单调**滚回视口 1/3 处（单调＝永远收敛）。
2. **打磨时顺手想改掉 `-webkit-overflow-scrolling:touch`、`fadeUp` 动画、`sticky` 顶栏——全是错的**：`-webkit-overflow-scrolling: touch` 是 iOS 的**惯性滚动开关**，去掉滑动会"木"；动画和 sticky 是用户看得见的东西。**修 bug 只动真凶那几行。**

**另一处顺手修的**：点侧边空白后页面回落一个整屏（"跳一下"）——浏览器聚焦 textarea 的一个古怪行为，本来就在 v1.06 之前，非本次引入。按浩总"别弄出新毛病、优先验能验的"的指示，先验证修复本身四项全绿，这个下次一并处理。

- 原稿存入 `原始材料/日记/2026-10-02.md`（一字未改）；回信 `知识库/日记回信/2026-10-02-回信.md`
- 内容：早上**赵春林**和**赵思齐**争一瓶蒙牛饮料，怎么做工作春林都不肯给妹妹 → 我妈把饮料拿给了思齐 → 思齐喝了一口也不给姐姐 → 春林生气 → **浩总说：「因为你不肯把东西分享给妹妹，所以妹妹也不会分享给你。」** → **她好像听懂了，没哭了** → 过了一会儿妹妹给她，她也给妹妹了 → **「我觉得她是懂了」**
- **回信里我注意到的三条**：
  1. **他挑的那句话是有形状的**——没用"你是姐姐要让着妹妹"（命令）、"一瓶饮料别哭了"（敷衍）、"再哭就收走"（威胁），用的是**因果句**。**三岁半的孩子听不懂"分享"这个抽象词，但听得懂"你不给她，她也不给你"这个形状。** 他把散的几分钟（我拿着→奶奶拿走→妹妹不给→我生气）翻译成一个结构：**你做的事，会变成别人对你做的事**
  2. **他没有当场纠正结果，他解释了结果**——多数人在"孩子输了"的位置会补一句惩罚或哄一下（"活该"／"再给你拿一瓶"）；他做的是**让"输"这件事变得有意义**：她不是被抢了，是**自己刚才的选择转了一圈回到自己身上**。**这是把一次哭闹变成一次学习，而不是一次胜负**
  3. 🔴 **留了一个要看的区别**——最后是"**妹妹先给她，她才给妹妹**"，所以这次她学到的大概率是「我给 → 她也会给我」（**交换划算**），而"分享"最硬的那一层是「我给不给，跟对方给不给我，是两件事」。**三岁半做到交换已经很好了，不急教那一层**；下次她主动给时，看她是不是在预期能拿回什么
- ⚠️ 他原文写的是"她**好像**听懂了"而不是"她懂了"——**这个谨慎是对的**，已在回信里点出
- 📌 这是育儿主题在日记回信里第一次出现（此前多是读书、财经、家庭开销）；**赵春林、赵思齐两个名字第一次进日记原稿**

  4. 🔑 **他今天对春林说的那句，和这句话是同一件事**——「因为你不肯分享给妹妹，所以妹妹也不会分享给你」对春林来说也不是道理是形状。**他班主任当年对他做的，正是他今天对春林做的——这是一件正在传下去的东西**
