## 🔑 07:57 浩总反馈"写得太淡"→ 悬疑推进式重写（重大方法论沉淀）

**反馈原话**：「我觉得这篇文章写的太淡了，没有那种急迫感，紧凑感」。07:57 给了两个打法（A 悬疑推进式 / B 冲突对撞式），浩总 08:00 选 **A**。

**诊断（关键：不是素材问题，是节奏问题）**
初稿属"从容叙述体"，五个症状：
1. **开头无动作**——首句"普京提前一天到了"是背景陈述，读者不知道要看什么
2. **最强对比埋太深**——"乌克兰一次没有"落在第二节末约 500 字处，全文最狠的一句被铺垫淹没
3. **节与节并列**——每节各讲一层情况，读完一节可随时退出，没有牵引
4. **引文过长拖平节奏**——里约宣言引了整句原文 + 非洲倡议 + 和平之友 + 结尾期待，共 3 句
5. **结尾绕**——"哪个更接近真实状态。你说呢"力度虚

**改法：六个动作（已写入 v1「改稿对照」表）**
| # | 动作 | 效果 |
|---|---|---|
| ① | 开头直接上"11 国签了 45 页文件…「乌克兰」一个字没有" | 第一段就建悬念 |
| ② | 把"乌克兰一次没有"从 500 字后提到**开头第 3 段** | 一进场就撞冲突 |
| ③ | 里约引文砍到只留"回顾各国国家立场"一句，其余转述 | 证明力够、节奏不塌 |
| ④ | **每节末留一个没答完的话头**（"说完第二天文件通过了"／"到 2026 新德里，断了"／"就是没谈这一场"／"96% 已用本币结算"） | 靠"然后呢"拽着走，不靠小标题硬撑 |
| ⑤ | 结尾改成判断句"被拿掉的三个字，比写上去的 140 条都响" | 可引用、想反驳就会评论 |
| ⑥ | 节标题全部换悬念口径（"先说一句被当面说出的话"／"这不是金砖的惯例"／"那这行字为什么能消失"） | 扫一眼就带钩 |

### 🔴 08:11 浩总指出「怎么结尾没有留钩子？」→ 结尾原则补正（重要）

## 🟢 08:17 浩总要"中段软钩子"→ 钩子方法论升级为两套（重要）

**浩总原话**：「正文的中间部分也要埋一个软钩子，让读者要话可说，**就像我们人要开始说重要的话之前一样，要留 3s，让别人消化一下前面的信息，再讲重要的话一样**」。

这个比喻很准——他要的不是提问，是**节奏上的留白**。

### 核心区分：硬钩子 vs 软钩子（以前我只会硬钩子）

| | 硬钩子 | 软钩子 |
|---|---|---|
| 动作 | **抛悬念**，不给答案 | **刹节奏**，让读者自己冒出一个念头 |
| 读者反应 | "然后呢？"→ 往下读 | "这也太……"→ 想表态 |
| 形态 | 一个没答完的问题 | 一句极短的停顿句，**单独成段** |
| 功能 | 防跳出、提完读率 | 给表态空间、**提互动率** |
| 位置 | 资料段/背景段结束处 | ①信息最密处之后 ②**论点揭晓之前** |
| 像什么 | 说书人拍醒木"且听下回" | **人要说重要的话之前那 3 秒的留白** |

**为什么必须补软钩子**：全篇硬钩子 = 一直拽着读者跑，读者喘不上气，一路被拖到结尾才想起来"我好像有话要说"，但已经想不起要说什么了。**互动率的源头在软钩子，结尾钩子只是收网。**

### 本篇埋的两处
- **第四节末**（军贸信息最密处之后——苏-57/S-400/布拉莫斯/96%本币结算一口气砸完）：
  > **劝和的话说完了，单子还在桌上。**
  （不评判、不下结论，只把两件事并排放着 → 读者心里嘟囔"这……"）
- **第六节标题后、全文最重要判断出场前**：
  > **写进一句话，要11个国家点头。拿掉一句话，也是。**
  > **文件上不会写明是谁拿的。**
  （第一句把"共识制"反着说一遍，让读者自己推出"所以是有人坚持要删"；第二句补新信息 → 读者自然想问"那是谁"，答案就在下一段）

### 写法四条（可复用）
①**短**，一句话，最好 15 字内 ②**不提问**（提问是硬钩子和结尾的活）③**不评判**，把两件事摆出来就走 ④**下一段必须真的接住**，别让读者悬在半空
**密度参考**：约 400-500 字埋一处，太密会碎，超过 800 字读者会闷。

**落地**：已写进 SOP 第二节（新增「🟢 中段软钩子」小节，含对照表+样本+写法四条）+ v1 的「改稿对照」后附说明。字数 1,430 → 约 1,470。

### 10:33 浩总补正：正文里不要出现"翻转一/二/三"骨架标记
