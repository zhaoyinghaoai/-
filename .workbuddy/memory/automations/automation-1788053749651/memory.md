## 固定流程（已验证可复用）

1. 读 `知识库/项目/AI情报站.md`（拿四格模板 + 筛选口径）。
2. 扫 `原始材料/收件箱/`；再用 `find 原始材料 -newermt <本周一>` 找本周新增素材（只读，绝不改动）。
3. WebSearch 四轮并行（freshness=d7）：大模型/芯片算力、Agent 与办公产品、AI 融资创业、军事无人作战 + 写作 Skill/工具 + 政策。军事与写作方向需单独补搜，通用 AI 搜索覆盖不到。
4. 追加一节到「简报存档」区（不覆盖历史），Log.md 顶部插一条。
5. 每月第一周才附「上月情报回看提醒」；非第一周只做一句顺带提醒。

## 经验与坑

- **执行前先查重**：本自动化存在「同一周一被触发两次」的情况。开跑第一步先 `grep "^## 本周简报" 知识库/项目/AI情报站.md` + 看 `知识库/Log.md` 顶部，确认本期是否已生成；已生成则**不再新建同周小节**，改为在该期末尾追加「🔄 周一早间增量」小节（只收当天新增、仍带四要素），并在 Log 的当日条目下补一行说明。
- 搜「AI 写作 skill」时，`GitHub trending weekly` 类站点（tommyz.blog、segmentfault、shortsingh）命中率最高，能拿到仓库名+周增星数。
- 当天增量检索的高产入口：**腾讯研究院 AI 速递（搜狐）**、**今日头条「AI 全球模型排行」日报**、**创意艺术 AI 实验室（头条号，每周挑技能包）**——这三处能一次拿齐「认知/模型/写作 skill」三类，效率高于通用搜索。
- 「去AI味」方向的权威锚点：维基百科《Signs of AI writing》（23 条特征），humanizer / no-ai-slop 两个 skill 都源自它 —— 对浩总的 check_prose.py 流程有直接补充价值。
- 部分聚合帖（无标题文档类搜索结果）没有可用 URL，四要素不全的条目宁可不用，换有稳定链接的来源。
- 浩总在用 WorkBuddy，凡涉及 WorkBuddy / 腾讯混元 / 硅基流动的更新优先级拉高。
