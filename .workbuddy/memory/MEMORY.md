## 一、军事头条工作区（主战场）

**位置与归档**：旧工作区 `E:/北辰/2026-07-18-09-46-45/` 已停用。文章+配图 → `产出/军事文章/`；每日数据 → `原始材料/军事头条数据/`（只读）；主数据页 → `知识库/项目/军事文章-数据跟踪台账.md`。

**报数据约定**：浩总说「报数据：展现X 阅读X 点赞X 评论X」→ 更新台账 + 判读点击率 + 提醒下一步。按 1h/3h/12h/隔天 四个锚点报。

**点击率分档（9-10 定标 v2）**
- 文章：垫底 <1.5% ｜ 及格 2-3% ｜ 健康 4-5% ｜ 优秀 6-8% ｜ 顶尖 >9%
- 微头条：垫底 <4% ｜ 及格 6-7% ｜ 健康 8-9% ｜ 优秀 10-12% ｜ 顶尖 >13%

**完读率铁律（9-13 立案）**：报数据时必须一起报「平均阅读完成率 + 平均阅读时长」。平台低质参考线：**完读率 <40%**。主线诊断：点击率已毕业（1.4%→11.5%），下一战场是完读率。

**篇幅标准 + 分段骨架（9-13 立案）**：常规稿 **1,000 字左右 + 判断句小标题**。新骨架=4节层层推进（每节推翻读者一个想当然）。小标题必须是判断句，❌ 不许编号/施工图。改完必须 grep 复查软钩子。

**派生文件核对铁律（9-13 立案）**：从旧文件派生新文件（发文包/发布版/改写版）前，必须 `grep` 一遍已作废的词（冷池标签、被否标题、旧话术）。规则写进 SOP ≠ 自动合规。

**选题分工（9-8 浩总说明）**：不主动探测/提议选题。丢话题后负责：核实 → 军事化+不一样角度 → 成稿 → 去AI味 → 配图 → 发布参数。

**选题闸门二则（9-13 立案，9-15 升级）**：
1. 避开官媒正在铺的题——头部官媒占位时个人号难进公域池，要么换题要么等退潮。
   - **9-15 升级补充：「通稿类选题」是本条命中的最高危形态。** 凡属"某部委/发言人表态"类（如国防部 9-14 涉日表态），新华社+央视+人民网+中新网+中国网会**同日全量转载**，个人号几乎没有介入空间。识别信号：**表态本身即是新闻源**（对比：外媒首发+国内少转的题=安全，如 9-14 俄罗斯放映影片篇）。
   - **处置三步**：①换入口——不写"谁说了什么"（那是通稿的活），只写"这两个词为什么偏偏用这两个"（通稿不做的活）②错峰——等官媒流量见顶（24-48h）再发 ③标题绝不复述通稿标题。
2. 转化能力已毕业，瓶颈在展现侧。

**话题军事化约定（9-8 立约，作用域仅限军事头条对话）**：找文件级硬料/制度钩子/冷切面，判据三问：军事号读者会点吗？比主流解读多什么新东西？降敏红线内？

**降敏选题铁律（9-8 固化）**：安全输出≠民生话题，必须在军事赛道内找不敏感题材（军购/装备/民防/后勤线），手法：民生热点 + 军事制度钩子。

**标题铁律（9-9 纠偏）**：硬词前置 + 对撞/悬念，不能把结论说完。长度 15-26 字，硬实体词打头。

**爆量四件套（8-31 固化）**：硬词标题 + 4个蓝色标签 + 微头条自写转发 + 自评设锚。详见 `产出/军事文章/军事文章_爆量SOP_v1_20260831.md`。

**标签池铁律（9-13 立案）**：选标签顺序必须是「先查人数，再排槽位」。蓝标≠有流量。冷池（<5000）划掉。定型组合：`大盘国名词` + `军事观察` + `国际政治` + `角色词`。

**发布窗口**：8:32-8:40（铁律）。

**配图铁律**：① 贴题一票否决 ② 主体占画面 60% 以上 ③ 封面端出标题里的冲突/动作 ④ **图上不能有任何文字**（除原照片自带标牌；水印同判）。

**🆕 封面构图铁律（9-15 实测修正）**：判据②"主体占 60%+"要**重新理解**——本条是手段不是目的。真正起作用的是**画面里的张力**（被挤压/夹峙/对撞）。实测：9-15 国防部篇，我选的"双车并排全景"（主体大、扁平）被弃用；浩总选了"单兵站在两辆发射车中间、仰头摸打开的舱门"（人物不大，但两侧车体夹峙 = 夹缝感/压迫感，直接呼应标题"堤丰留在了日本"）。**结论：封面优先找"夹峙/夹缝/对撞"构图，其次才看主体大小。**搜索关键词方向：两车夹一人 / 装备包围 / 近距离对峙视角。

图源优先级：**DVIDS（可代下载·公版）** → 头条免费图库 → 提醒浩总自己搜。❌ 游戏CG/AI图/水印图/标题截图。

**DVIDS 代下载流程（9-15 打通，此前误记为"全不通"）**：
- 图片直链：`https://d1ldvf68ux039x.cloudfront.net/thumbs/photos/{YYMM}/{ID}/2000w_q95.jpg`（**2000w/1000w 可用，original 一律 404**）；视频帧走 `/thumbs/frames/video/{YYMM}/{ID}/DOD_xxx.0000001/2000w_q95.jpg`
- **搜索页行不通**（`/search?q=` 返回 202 空页或反爬挑战页，api 403）→ 改抓这几类页面再从 HTML 里 grep 图片 ID：`/unit/{unit-slug}`（如 USARJ）、`/feature/{exercise-slug}`（如 orientshield / valiantshield）、`/news/{id}`、`/video/{id}/{slug}`
- 抓取需 `-L --insecure` + 完整浏览器 UA
- ⚠️ 视频帧常带 **AFN PACIFIC** 水印 → 按判据④淘汰；优先找静照

**低质提醒处置铁律（9-11 立案）**：平台质量评级，不删文不扣分，只停推。处置：① 绝不删稿 ② 改一次作品信息 ③ 提交人工复审。预防：结尾低门槛钩子 + 发布后1小时内引导互动。

**钩子体系铁律（9-13 立案）**：结尾=硬判断+二选一提问；中段软钩子=15字内极短停顿句单独成段；正文钩与评论钩不许问同一问题。

**网络限制**：curl 只能访问白名单域名。**9-15 实测：`dvidshub.net` ✓ ／ `images.unsplash.com` ✓ ／ `upload.wikimedia.org` `commons.wikimedia.org` `loc.gov` ✗（返回 000）**。读懂网页内容优先用 WebFetch；**军事配图直接走 DVIDS 代下载（见上）**。

**字数核实铁律（9-15 立案）**：**报字数必须用脚本实际统计，不许凭段落感觉估。** 9-15 国防部篇首版凭估报了 1,041，实际 1,598（差 53%）。成稿后必跑一遍字数再交，公式：去 markdown 标记与空白后数字符。
