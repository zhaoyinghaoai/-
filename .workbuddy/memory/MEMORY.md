## 一、军事头条（主战场）

**路径**：文章+配图 → `产出/军事文章/`；数据 → `原始材料/军事头条数据/`（只读）；台账 → `知识库/项目/军事文章-数据跟踪台账.md`；爆量规则 → `产出/军事文章/军事文章_爆量SOP_v1_20260831.md`；配图 → `知识库/项目/DVIDS配图作业手册.md`。旧工作区 `E:/北辰/2026-07-18-09-46-45/` 停用。

**🔴🔴 交付顺序（9-17 立规 → 9-18 复现后强化）——优先级最高，压倒其他一切规矩**

**成稿/数据一到手，第一动作＝先把正文（或判读）发出去。浩总回复之前，一个字都不许归档。**

- ✅ **先发的**：文章正文（**放最前**）→ 标题 → 标签建议 → 四查结果／判读结论
- 🚫 **浩总回复前禁止**：更新台账／更新 SOP／写 memory／做发文包／配图／跑字数校验／重命名文件
- **数据同理**：先把判读写出来发出去，**再**归档
- ⚠️ **9-18 一天内复现两次**（15:32、20:16 都是先动台账再回复）→ 所以升级成硬禁止，不再用"排在后面"这类软表述
- **为什么**：浩总在快递点，时间碎片化。先看到 → 他能趁空档反馈；我先归档 → 他干等，且反馈一来全返工

**🔴🔴 判读第一铁律（9-18）：先问「这个数跑完了吗」。**
- **1h 数据只记录、不判读。** 机器是「慢启动＋长尾」，1h 只有终值的 1/3 ~ 1/30（胡塞 123→3,779／波兰 23→891／美德 618→2,202）。
- **任何两位数展现都不构成「没推」的证据。** 判「推不推」看 **3h 起**的曲线；判「推得准不准」等 **12h／隔天**。
- ⚠️ 9-17 我拿 1h 快照当终值立案「账号级限流」，让浩总白跑两次客服。**"9-13 断崖"很可能从未存在。**（专案已推翻，台账「二·五」节留作思维标本。）
- 余下有效：展现正常但点击率低＝**推错人** → 查标签池／标题／封面。口诀：**展现看推不推，点击率看推得准不准，互动看钩子有没有。**
- **🔴 9-18 晚补一半：长尾不是自动的，是被点击率触发的。** 点击率是**油门**不是仪表盘——机器推一波→看反馈→好才加推。胡塞早期 4.9% → 加推到 30.7 倍；管道 7h 0.8% → 711→910 就刹车。**分母到几百后，点击率基本能预示终局；3h 那次报数是唯一能同时看到"推不推"和"准不准"的时机。**
- **❌ 点击率难看不要改标题/封面**：改＝打断机器试探 + 重新过审。改作品信息只是 **9-11 申诉场景**的解法（9-18 我一度建议改，是错的）。让它跑完，经验用在下一篇。

**标尺**：点击率分档 文章 垫底<1.5%／及格2-3%／健康4-5%／优秀6-8%／顶尖>9%；微头条 垫底<4%／及格6-7%／健康8-9%／优秀10-12%／顶尖>13%。平台「超过 X% 同类作品」是**相对位置**，别与绝对值混谈。

**🔴 篇幅与低质（9-11 根因，仍有效）**：平台判低质＝**完读率 12% + 真实评论 0**，**篇幅是直接原因**。常规稿 **1,000-1,800 字**；报数据必须带**平均阅读完成率 + 平均阅读时长**，低质线 <40%。处置：**不删稿 → 改作品信息（贴题封面／改标题）→ 人工复审**，当晚解决。**人工客服权限高于 AI 判罚**；申诉成功只解释那一篇，与账号无关。

**派生核对（9-13／9-17／9-18 三次命中）**：派生新文件前必须 grep 已作废的词。**定稿进台账 ≠ 进稿件**——标签/标题定稿后回扫**源文件 md**，再重跑发文包。

### 选题
- **分工（9-8）**：不主动探测／提议选题。丢话题后：核实 → 军事化＋不一样角度 → 成稿 → 去AI味 → 配图 → 发布参数。
- **军事化**：找文件级硬料／制度钩子／冷切面。三问：读者会点吗？比主流多什么？在降敏红线内？手法：民生热点 + 军事制度钩子。
- **选题闸门（9-13 立案，9-15/9-17 升级）**：①**避开官媒正在铺的题**；**通稿类最高危**（信号：**表态本身即新闻源**）②**可量化信号**：查该话题讨论数——实测某国防部通稿**仅 8 条** → **官媒铺满 ≠ 民间在讨论**，个位数应避开 ③处置：换入口／错峰 24-48h／**标题绝不复述通稿标题**。

### 标题
- **铁律（9-9）**：硬词前置 + 对撞／悬念，不把结论说完。15-26 字，硬实体词打头。
- **对撞 vs 并列（9-17）**：并列＝各说一件事（散）；对撞＝同一件事上两股力气相顶（紧）。正例：`胡塞给全世界发了张通行证，只有沙特没拿到`。**检验法：两半调换顺序意思不变 → 是并列。**
- **反"平淡"（9-16）**：悬念**一秒能懂**，要画面和动作，不要谜语。
- **🔴🔴 点击率四查（9-18 立案，0.8% 换来）——不许打勾，必须写出一句话**（详见 SOP 五·五）：
  1. **入口**：写出「读者点进来是想看 ______」——**这句话里必须有军事味**，没有＝入口错（管道篇只能写出"想知道管道为什么改名"＝能源号的题）
  2. **对撞**：写出 A ⟷ B，并说明是同一件事的对立面
  3. **悬念**：读完标题还有没有想知道的东西？（`路走不通了`＝结论，说完了）
  4. **封面缩略图**：缩到 100px 还剩下什么？**必须有一个能叫出名字的主体**（管道篇缩成"一团橙色安全网"）
- ⚠️ **打勾必然失效**：9-13→9-18 六天内打勾失效四次（菲律宾小标题／管道对撞／管道结论／管道封面）。**打勾是判断题（感觉像就行），写理由是证明题（说得出才行）。**

### 标签
**池铁律**：先查人数再排槽位，蓝标≠有流量。**定型 4 槽**（多挂＝稀释匹配精度）。**🔑 找词规律（9-18）：短词 > 长词**——`军事`40万 > `军事观察`3,445；`国际`18万 > `国际政治`6,954。同义优先选更短的领域名。

| 层 | 标签 | 职责 |
|---|---|---|
| 1 品类大盘 | `军事` **40 万** | 比任何国名都大 |
| 2 领域大盘 | `国际` **18 万** | 比 `国际政治` 大 26 倍且语义包含它 → 一律用 `国际` |
| 3 大盘国名 | `美国`31万／`日本`21万／`俄罗斯`18万／`乌克兰`15万／`中国`10万 | 量级碾压，挑最大的 |
| 4 角色/实体 | `沙特`1.8万／`北约`1.5万／`胡塞武装`1.2万／`太空`1.0万／`波兰`8,000+ | 精准匹配主角 |
| 5 功能槽 | `国际政治`6,954／`军事观察`3,445 | 已被上层大盘词取代，尽量不用 |

- **🔴 只挂角色，不挂背景（9-18 浩总纠正）**：自检句——**这个词在正文里有没有独立出现、有独立动作？** 没有 → 不挂。挂背景词＝推给关心那个背景的读者 → **点击率难看**（实例：输华管道篇误挂 `乌克兰`）。
- ①定 4 个 ②语义重叠不同挂（选大的）③**别进错池子**——判据：**这个标签下的读者，是不是我想让他们看的人？**
- ⚠️ **`军事` 40 万 / `国际` 18 万不予因果宣布**。⏭ 待第二个样本（9-18 输华管道篇）。别宣布"找到钥匙"。

### 微头条转发
**🔴 它同时出现在原文评论区**——**不是"缩略版文章"，是"一条评论"**。**90 字左右**、一到两小段。**必须给文章没有的东西**；**写完回扫正文对照**——"我觉得这是新的"不算。钩子落最后一句。❌ 禁"时间地点人物"三件套开头；✅ 可用"说个容易被忽略的点：…"。
🔴 **评论区只能有一条（9-17）**：转发评论自己就是原文下那条评论，**绝不再单独发自评**；要补细节用「回复」挂在它下面。默认什么都不做。

**🔴 爆量三件套**：硬词标题 + 4 蓝标签 + 微头条自写转发。❌ **没有第四件**（"自评设锚"是 8-31 误设）。

**钩子体系**：结尾＝硬判断 + 二选一提问；中段软钩子＝15 字内极短停顿句单独成段；正文钩与评论钩不许问同一问题。**低质预防**：结尾低门槛钩子 + 发布后 1 小时内抛一个"有情绪就能答"的问题并置顶（**不是另发自评**）。

**发布窗口**：8:32-8:40。

### 配图
- **铁律**：①贴题一票否决 ②主体占 60%+ ③封面端出标题里的冲突/动作 ④**图上不能有任何文字**（原照片标牌除外）⑤**会场照一律淘汰**。
- **封面构图（9-15/9-17）**：起作用的是**画面张力**，优先"夹峙／夹缝／对撞"（被船围、被人围、被车夹都是夹）。
- 图源优先级：**DVIDS（公版·可代下载）** → 头条免费图库 → 提醒浩总搜。❌ 游戏CG／AI图／水印图／标题截图。
- **DVIDS**（可用 slug／404 清单／题材入口词全在作业手册，**别凭记忆**）：①直链 `{YYMM}` 是**发布日期**不是拍摄日期 ②**搜索页行不通** → 抓 `/unit/`、`/feature/`、`/news/`、`/video/` 页再 grep ID；需 `-L --insecure` + 完整 UA ③**先读 slug 再决定下不下**。❌ `/image/{id}` 任何 ID 都返 200，不能探测存在性。

### 文风与其他
- **🔴 腔调铁律：幽默的紧迫感（9-16）**：用玩笑的腔调讲一件不能开玩笑的事——不是让人笑，是让人笑完后背发凉。**六手法**：口语嗓／翻译体（官方话说一遍+大白话翻一遍，最好用）／列举式沉默／冷笑话收口／把严重说成日常／紧迫感三板斧（时间感、后果感、反差感）。
- **反"平淡"五查**：①全是词没东西 ②全在解释没故事 ③没有后果 ④节奏平 ⑤没有态度。解法：词换东西 → 分析换画面 → 长句砍短、单句成段。
- **🔑 选题三层诊断顺序（9-18，五轮改稿换来）**：①**入口层：军事号读者为什么点？**（反例：写天然气生意＝财经号的题；正例：写"这条管子撑着军费"）②**腔调层：有没有"东西"和"现场"？**（全是占比金额＝财政局的话）③**结构层：因果链完整吗？**
- **🔴 降敏边界（9-18）**：该降的是**评判**，不是**背景**。✅ 可说「2022 年俄乌冲突爆发」这类事实交代（**因果必需**）；❌ 不评判是非、不站队、不预测胜负、不写网络猜测。⚠️ **最容易犯的错＝把背景抽走 → 因果断了 → 后面所有数字都成孤立的。**
- **脚本健壮性（9-17 立案，9-18 第四次复现）**：正则**别锚死在章节标题精确文本**（改标题会静默返空），用「章节号 + 关键词」+ `[^\n]*`。⚠️ **写稿优先沿用脚本已认的章节命名；要改命名就先改脚本，别在赶发布时改。**
- **工具脚本**：**`.workbuddy/scripts/gen_pack.py`**（❌ 不是 `知识库/.workbuddy/scripts/`），`python gen_pack.py <稿件md> <输出txt>`（抽七节 + 逐字一致校验 + 作废标签扫描）；`count_chars.py <稿件md>` 统计正文字数／分节／破折号／禁用词。临时目录会被清理，脚本一律存项目内。
- **网络**：curl 只通白名单（`dvidshub.net`✓／`images.unsplash.com`✓；wikimedia／commons／loc.gov ✗）。读网页优先 WebFetch。

## 二、读书公众号

- **写前必读**（不许凭空写）；**省 token 读法**：只读 `产出/读书内容/读书号写作弹药卡.md`，不够按卡内指针定点读一个文件，每篇成文后追加 1-2 行
- **进度（9-18）**：第 31 天；《芙蓉镇》人物志第 5 篇（吊脚楼主→秦癫子→黎满庚→谷燕山→胡玉音），已定型"一篇一个人"；待写：黎桂桂／五爪辣／李国香／杨民高。全清单见 `产出/读书内容/运营复盘/读书号更新全清单_第1-30天.md`
- **🔴 人物志铁律**：
  1. **写前必须核对人物关系与时间线**——浩总读书极细，别凭印象写（9-17 两处被当场抓出）。
  2. **体例＝纯讲人物，作者自省段不进正文**（连砍两次）。要带自己就压成两三句挂倒数第二节尾。
  3. **标题定稿常由浩总改词**。改完 **grep 全文**，看新词与既有表达是撞上还是呼应。
  4. **压缩字数一次性规划砍哪几节，不挤牙膏**。顺序：合并同题节 → 删过渡与复述 → 合并同类对账段 → 最后才动句子。保骨头＝核心论点句 + 题眼。
  5. **考官问法④「换成你做不做」**（用具体动作逼表态）效果最好。
  6. **配图是重灾区**：渲染完必须**逐张打开看**，九张里常有三四张要返工（避让规则见 `render-social-cards` skill）。
- **固定件**：单标签 `#读书`（不堆标签）；文末标"本文风格"说明，**禁"浩总批注"这类居高临下措辞**；朋友圈互动钩子用"聊聊？"／"在底下说说"（**朋友圈不写"评论区"**，那是公域语感；多平台同发时另两平台可保留）。
