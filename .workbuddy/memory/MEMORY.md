- **选题**：唯一优先级＝**热度**（9-23 拍板，不问官媒铺没铺）；三关按序 ①热度 ②红线（唯一保留的跳过理由）③角度（官媒铺过 → **角度整个换掉，绝不复述官媒框架与标题＝判重死线**）。**热度的唯一硬证据＝热搜榜位次**（平台名＋排名＋热度值），拿不出就写"未上榜"。**先找军事落点，再核红线**；都过不了就换题，**不硬救**（判据：读者点进来能看到"枪"吗？）。
- **判读**：门槛＝24h ＋ 展现上千；**展现还在长＝不判**；口诀 **展现看推不推，点击率看推得准不准，互动看钩子有没有**；**归因顺序 ①选题 ②时机 ③账号 → 才轮到标签**；**❌ 点击率难看不要改标题/封面**。标尺：文章 垫底<1.5%／及格2-3%／健康4-5%／优秀6-8%／顶尖>9%；微头条 垫底<4%／及格6-7%／健康8-9%／优秀10-12%／顶尖>13%。

## 四、学习与教学（财经公式）

- **出题／复习** → 先读技能 **`finance-study-coach`**（课程表 / 1-3-7-21 天节奏 / 弯路库 / 复习本规矩 / 出题硬要求）。
- **讲概念与公式** → 先读技能 **`teach-haozong`**（十三条铁律 / 教学弧线 / 已知的坑 / 收工动作）。
- 🔴 **三条最容易犯的错（我都犯过）**：①**举例的数字和公式里的常数撞车**（他会当场揪出来）②**粗估只给一半**（拆成两半的题，每一半都要给区间）③**出题越界**（把没学过的知识点塞进复习题）。
- 🔴 **他的错误分两类**：**不会**（卡在某格）→ 讲"这个格子在问什么"；**手滑**（算式全对、数字串了/漏位）→ **不重讲概念**，只给动作「**念算式，数字念全**」。
- 🔑 **他的好提问三种（优先级都高于当次练习）**：划边界（"为什么不用…？"）／**验证型复述**（"……是吗？"——**必须当场纠干净**，否则错规则会跟着他走）／**深挖第二层**（问完"怎么算"接着问"算不了怎么办"）。
- 🔑 **他会主动要知识点**——他问出"这类怎么算"时就该建卡，不要等他说。
- ⚠️ **教学者的失误要当场认**：他卡住时先分清"他不会"还是"我没讲清／出题越界"。

## 五、通用

- **先交付，后归档**（通用版）：给他的东西**先发出去**，归档排在后面。
- **给浩总的回复尽量少用表格**（他连着两天说过看表格累）。
- **对外操作（发消息、公开内容）先问；对内操作（读文件、整理）大胆。**
- **不替他做重大决定**——可以分析、建议，拍板是他的事。
- **⚠️ 别替他"总结"他没说过的行为**（10-08 立案）：他日记里凡出现"**彻底不行了**""**就到这儿了**""**就直接躺下了**"这类句子，**不要替他推"他在那个点停了"**——先问一句"那之后还做了什么"，或去对痕迹（**他的发文有固定痕迹：8:32 文章、9 点左右微头条**）。10-08 踩过：推出"他撑完一件就停了"，**实际他撑了两件**，他一句话就纠出来。**宁可先问一句，也不要替他总结。**
- **🔑 他手上的事分三档，分档依据＝"这件事影响谁"**（10-08 立案，**管新想法怎么加**）：**钉死的**（8:32 文章——影响公域，得有"外部到点必须发生的事"）／**给范围的**（锻炼 5:15-5:40、微头条 9 点左右——影响自己或二次传播，只定"几点到几点之间"）／**随时的**（日记——不对外，**门槛要压低 ＋ 最好有个看的人**）。**他定得最死的和定得最松的执行都最好，中间"没定成哪一档"的（看书、知识卡、公式）反而容易掉——三条都不靠意志力。** → **他有新想法时，先问一句"这属于哪一档"，别先问"能不能坚持"。**
- **🔑 他每次说"我表达不出来"，先分清是哪一种场合**（10-10 立案）：**办事型**（打电话、跟老师、跟客户）目标＝**让对方能动手**；**倾诉型**（日记、跟媳妇）目标＝**让对方懂你**。**他常常拿第二种的尺子量第一种，怎么量都不及格** → **他抱怨"说不清楚"时，先问一句"这次你要的是对方明白你，还是对方能动手"。** 另：**他的口头卡壳＝把需要提前准备的事放到当场现做**（电话里同时组织句子＋猜对方反应＋看现场，注意力分成三份）→ **解法不是练嘴，是把"写"（他已经会的慢动作）搬到打电话之前。**
- **⚠️ 他自评用的贬义词（"囫囵吞枣""内耗""智伤""表达不出来"），先把他那句话拆开看里面有没有已经做到的部分**（跨 10-04／10-05／10-06／10-09／10-10／10-13／10-14 **七次**，**"东西已经有了，只是没记账"的变体**）——**先摆他已有的，再谈要不要加**（列清单 > 讲道理）。10-10 第五次：他说"想说成这样、却说成那样"，**两句并排一比，说出口的那句信息反而更多**。**同理：他说"以前我总是……"（自省）时，别接成"你以前做得不对"，接成"你现在自己找到了一条更省的路"**（10-13 鼠标那次）。**10-14 第七次**：他写完"释然了"紧接着缩一句"**这个思想可能也不是那么的好吧**"→ **拆法是"他把两个动作混成了一件"**：① 允许自己放下 ② 给"放下"划边界（"有的事儿可以糊涂，有的事儿不能糊涂"）——**光有①才叫糊涂，两个加在一起叫"分类"**。
- **🔑 同一把尺子会自己长出来——认它第二、第三次出现的时刻**（10-13 立案，10-14 再验）：他 10-07 自己给的判据"**这件事有没有时间窗**"，10-13 被他**自己**拿去判断"什么时候验货"，**10-14 又拿去判断"要不要较真"**（"有的人只活在我们的回忆里"那段）→ **这种"同一个判据换个对象、而且是他自己拿起来的"，说明那条道理已经长在他身上了，回信要专门指出来**（比重复讲道理有用得多）。**三次的对象一次比一次远：工具的事 → 东西的事 → 记忆和情绪的事。**
- **🔑 他因"想不起来／没做成／没记住"而失落时，先分清"是能力问题还是调用问题"——多半是调用问题**（10-14 立案）：他想不起初一的同桌（其他同桌全想起来了），自评"有点失落"。**能想起别的说明设备没坏**，那一格是**从来没被走过**（没被谁提起、没跟后面的事交接）→ **没交付物的事最难定档；没被调用过的记忆最难调出**。**处理**：**别接"你记性不错"这种安慰**，把机制讲给他听（"不是它不够重要，是它没被用过"）＋ 给一招"**写下来不是回头去查，是告诉脑子'这事存好了、不用再翻了'**"。
- **🔑🔑 「没验过的安心」——听到"我知道怎么做／应该能用／差不多行"，先问一句"这个走过一次吗"**（10-14 立案）：他答"**手机微头条我没有用，但是我知道，怎么用手机发微头条**" → **"记得"（记住步骤）和"知道"（手走过一遍、出过岔子也过了）是两件事**——**10-12 那晚他也是"知道"的，结果卡在"免费图库在哪""入口是不是文章"上**。**机制**：**因为他知道自己会，所以不着急；因为不着急，就一直没到"非用不可"的那天**（**同 10-13 那只旧鼠标**："觉得旧的能用，等到旧的彻底不能用的时候再用"，**同一形态**）。**处理三条**：**① 先把"他已经往前的那一步"认出来**（从完全不知道 → 知道步骤，这是真的进步）**② 再说差的那一步必须在"不赶时间"的时候走**（**现在试是免费的，急的时候试是付费的**——**正好是他自己 10-13 抽出的规矩**）**③ 给验法时不拿正事试手**（正事照旧走熟路，练习放在不赶时间的空档，**发出去、看见它出现在主页上就算验完，不用管数据**）。
- **🔑🔑 他评价孩子用的尺子，跟他评价自己是同一把——先指出孩子已经做到的那一步**（10-15 立案，**"东西已经有了"第一次把对象换成别人**）：快递点一个男孩想拿春林的东西，**她当场"不给"**，饭后**又主动把这事告诉了他** → **他的评价是"她没放在心上"**（**盯的是"她没说出那句反驳"**）→ **回信第一刀切在这句上：她要是真没放在心上，就不会主动说。** **处理**：**他评价孩子的"没当回事／似懂非懂／没放在心上"时，先指出孩子已经做到的那一步，再谈下一步**（**同一套手法，只是对象换了人**）。⭐ 配套：**他自己那条"把要准备的挪到'急'之前"（10-10／10-13），10-15 第一次自发用在了女儿身上**（"我又和她练习了几遍"）→ **对象第三次延伸：工具 → 东西 → 记忆情绪 → 教孩子。**
- **🔑 给他身体／精力类的建议，先过三条底线**（10-11 立案）：**① 先排除"需要出门／需要大动作"的方案**（他坐轮椅，能落地的是"见光、喝水、动上肢"这类）**② 先分清"这几天的症状"还是"持续已久的情况"**（前者调生活，后者要看医生）**③ 给一条清楚的就医红线，但别吓他**（说成"不是大病筛查，是一次排除"）。另：**他自评身体状态时用的贬义词（"懒""没自制力""没好好休息"）一律不接**——**别把身体的事当成道德问题**（10-08"今天的处理和前几天的账要分开算"、10-11"睡了两个多小时不是懒，是身体在还账"，同一条线）。
- **🔴 交付新版稿子，第一句必须写"这版改了哪几处"**（10-13 立案）：同一篇出现两版（昨天一版、今天复核一版）时，**两版都在他手上，发的时候可能拿旧的**——10-13 就发成了旧版，三个数字全是旧口径（12 人／八个国家／三天三回，实为 **13 人／九个国家和地区／五天四次**）。**同时定版必须落盘到 `产出/军事文章/`，文件头写一张"改动清单"。**
