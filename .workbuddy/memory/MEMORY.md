### 标题

**标题铁律（9-9）**：硬词前置 + 对撞/悬念，不能把结论说完。长度 15-26 字，硬实体词打头。

**🆕 「对撞 vs 并列」判据（9-17）**：两半是**并列**还是**对撞**？并列＝各说一件事（散）；对撞＝同一件事上两股力气相顶（紧）。正例：`胡塞给全世界发了张通行证，只有沙特没拿到`、`美国承认轨道上有武器了，然后什么也不肯说`。

**反"平淡"判据（9-16）**：悬念必须**一秒能懂**。"多了两个字"这类要动脑才懂的不行。口诀：**要画面和动作，不要谜语。**

### 微头条转发

**🆕 铁律（9-17 立案，9-17 二次修正——浩总指出机制）**：

🔴 **微头条转发会同时出现在原文章的评论区里。** 所以它**不是"缩略版文章"，是"一条评论"**。
- ❌ 写成 200 字＋多段小文章 = 典型错误。读者刚读完文章，滑到评论区又看到缩写版，直接划走——**这才是"没激起阅读兴趣"的真正原因**。
- ✅ **长度 90 字左右**，一到两小段（胡塞篇 92 字／波兰篇 83 字）。
- ✅ **必须给文章没有的东西**。文章展开过的不复述；评论只干一件事——补一个被忽略的点，或把几件事并排摆出来，然后下一句判断。
- ✅ **钩子落最后一句**（例："三句话里，只有一句是实话。"）。
- 🔴 **7. 评论区只能有一条（9-17 浩总第三次修正）**：**转发评论自己就是原文章下的那条评论**。**绝不再单独发自评**——两条各自独立、互不相关的评论并排出现在空评论区里，看起来就是"两个人各站一边"，很难看。
  - **默认什么都不做**：转发已经把评论区占住了，前期没人评论是正常的，不用急着填
  - **要补事实细节** → **用「回复」挂在转发评论下面**（一条评论 + 一个回复 = 对话；两条同级 = 并列）
  - **平台不允许回复自己** → **不发**，宁可只有一条
- ❌ 禁止"时间地点人物"三件套开头。✅ 可用开头："说个容易被忽略的点：…"

**🔴 爆量三件套（8-31 原为"四件套"，9-17 修正）**：硬词标题 + 4个蓝色标签 + **微头条自写转发**（这一个动作**同时**完成微头条曝光 + 文章评论区设锚）。

### 配图

**配图铁律**：① 贴题一票否决 ② 主体占 60%+ ③ 封面端出标题里的冲突/动作 ④ **图上不能有任何文字**（除原照片自带标牌；水印同判）。**会场照一律淘汰**（常带主办方 logo 大字，且"一堆后脑勺"没张力）。

**封面构图铁律（9-15 实测修正）**：判据②"主体占 60%+"是**手段不是目的**。真正起作用的是**画面张力**（被挤压/夹峙/对撞）。实测：主体大而扁平的双车并排全景被弃用，**单兵站在两辆发射车中间仰头摸舱门**（人物不大但两侧车体夹峙）胜出。**封面优先找"夹峙/夹缝/对撞"构图，其次才看主体大小。**

**夹峙形态不止一种（9-17）**：原要找"海峡两岸夹窄航道"，DVIDS 无可用曼德海峡航拍 → 换成"航母居中正面 + 两侧十余艘护航舰扇形铺开"，照样成立。**被一群船围着、被一群人围着、被两辆车夹着，都是夹。判据是张力，不是地理。**找不到理想构图时先问"这个画面的压迫感从哪来"。

图源优先级：**DVIDS（可代下载·公版）** → 头条免费图库 → 提醒浩总自己搜。❌ 游戏CG/AI图/水印图/标题截图。

**🔴 DVIDS 操作细节看手册** → `知识库/项目/DVIDS配图作业手册.md`（直链格式／slug 库／搜索入口／筛图技巧／太空坑／已下载素材索引）。留三条最硬的：

- 🔴 **直链里的 `{YYMM}` 是「发布日期」不是拍摄日期**（9-17 踩坑：ID 9799102 拍摄 06-30、发布 07-08 → 目录 `2607`）。**不确定就别猜**：抓 `/image/{id}/{slug}` 页面 HTML，grep `cloudfront.net/thumbs/photos/`。
- **搜索页行不通**（202 空页 / api 403）→ 抓 `/unit/`、`/feature/`、`/news/`、`/video/` 页再从 HTML grep ID；需 `-L --insecure` + 完整浏览器 UA。
- **先读 slug 再决定下不下**（slug 就是内容描述）；**先 WebSearch 搜 `dvidshub.net <关键词>`** 命中页面标题与简介。❌ `/image/{id}` 任何 ID 都返回 200，**不能用来探测 ID 是否存在**。

**slug 库速查**（高频用，完整版见手册）：✅ `USARJ`（陆军日本）／`feature/orientshield`、`feature/valiantshield`（演习）／`USSPACECOM`、`SSC`、`MDA`、`S4S`、`AFRL`、`feature/X37BOTV`（太空）／`CENTCOM`（中东海上）／`USAFE`、`VCorps`（北约东翼）。❌ 全 404：`USSF`、`space-force`、`Vandenberg`、`SpOC`、`NAVCENT`、`FIFTHFLT`、`CTF-55`、`CTF-153`、`feature/red-sea`、`feature/hormuz`、`US-Army-Europe`、`USAREUR-AF`、`US-Navy-Europe`。

**🔑 题材入口词**：海上 → `dvidshub.net image CENTCOM Arabian Sea warships`；铁路/补给线 → `dvidshub.net railhead operations train loading military Europe`。⚠️ 太空题材单位页多是会议照/仪式照，只找**火箭发射**（`USSF-xx`）、**装备正面特写**、`feature/` 专题。

### 其他

**网络限制**：curl 只能访问白名单域名。**实测：`dvidshub.net` ✓ ／ `images.unsplash.com` ✓ ／ `upload.wikimedia.org`、`commons.wikimedia.org`、`loc.gov` ✗（000）**。读网页优先 WebFetch；**军事配图走 DVIDS 代下载**。

**🔴 腔调铁律：幽默的紧迫感（9-16）**：**用玩笑的腔调，讲一件不能开玩笑的事**。不是让人笑，是让人笑完之后后背发凉。紧迫感来自"已经发生了"，轻松感来自"看透了"，**不是抖机灵**。

六手法：①**口语嗓**（"官方通报腔"→"跟你唠"）②**翻译体**（官方话说一遍 + 大白话翻译一遍，**最好用的装置**："措辞经过深思熟虑"→"这话是挑好时机专门说的"）③**列举式沉默**（问什么不说、问什么不说，越平静越荒诞）④**冷笑话收口**（严肃段末一句调侃收）⑤**把严重说成日常**（轻描淡写反加重分量）⑥**紧迫感三板斧**（时间感"已经/一步都没落下"；后果感：接到读者身上，卫星管着手机定位、银行转账时间戳；反差感：同一现场两副景象）

**反"平淡"五查（9-16）**：浩总说"平淡"，十有八九是——①全是词，没有东西 ②全在解释，没有故事 ③没有后果 ④节奏平（长句多、段段一样长）⑤没有态度（通稿腔）。**解法**：词换成东西 → 分析换成画面 → 长句砍成短句（单句成段）。

**🔧 脚本健壮性教训（9-17，同坑三度复现）**：写抽取脚本时**正则不要锚死在章节标题的精确文本上**——改标题（`（微头条）`→`（微头条 · 评论形态）`、`**主推**：`→`**主推（9-17 定稿）**：`）会**静默返回空值**。**规则：锚点用「章节号 + 关键词」，后面接 `[^\n]*` 放开。**

**工具脚本**：`知识库/.workbuddy/scripts/gen_pack.py`，用法 `python gen_pack.py <稿件md> <输出txt>`，抽七节（标题/标签/配图/正文/微头条/评论引导/检查清单）+ 正文逐字一致校验 + 全局作废标签扫描。**临时目录会被环境清理，脚本一律存项目内 `.workbuddy/scripts/`。**

**🔴 人物志铁律（9-17 立案）**：
1. **写人物前必须核对人物关系与时间线**——谁是谁的前任/现任、哪件事发生在新楼盖起前还是后。**9-17 我两处搞错被浩总当场抓出**（把胡玉音写成"寡妇家的女儿"、把"卖碎米时"写成"已是寡妇+新楼被收"）。浩总读书极细，别凭印象写。
2. **体例＝纯讲人物，作者自省段不进正文**（浩总 9-16、9-17 连砍两次）。自省段一进，读者注意力就从人物转到作者，收口判断句被稀释。要带自己就压成两三句挂倒数第二节尾。
3. **标题定稿常由浩总改词**，他的改法通常更准（9-17 "干的好事"→"干的事"：把好坏都收进来，坏的账他也认）。改完要**grep 全文**，看新词是否与既有表达撞上——撞上可能是打架，也可能是呼应。
4. **压缩字数一次性规划砍哪几节，不挤牙膏**（9-16 曾 5 轮才到位）。顺序：①两节讲同一件事就合并 ②删过渡句与情节复述 ③合并同类对账段 ④最后才动句子。保骨头＝核心论点句 + 题眼。
5. **考官三问可用问法④「换成你做不做」**（给一个具体动作逼他表态）——9-17 效果最好，他答出「小孩子是国家的希望，不能因为他父母是坏分子，就给他也扣上一顶帽子」，比原著立意高一寸。
6. **配图是重灾区**：渲染完必须**逐张打开看**，不能只看尺寸和四角像素。九张里常有三四张要返工。避让规则见 `render-social-cards` skill「排版避让铁律」。
