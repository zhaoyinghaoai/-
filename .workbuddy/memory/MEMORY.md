## 一、军事头条（主战场）

**路径**：文章+配图 → `产出/军事文章/`；数据 → `原始材料/军事头条数据/`（只读）；主数据页 → `知识库/项目/军事文章-数据跟踪台账.md`；爆量规则 → `产出/军事文章/军事文章_爆量SOP_v1_20260831.md`；配图细节 → `知识库/项目/DVIDS配图作业手册.md`。旧工作区 `E:/北辰/2026-07-18-09-46-45/` 停用。

**🔴 交付顺序（9-17）**：成稿/数据一到手，**第一动作＝先发浩总看**（正文放最前），配图、发文包、台账、字数校验排后面。先归档＝返工。**报数据**：展现/阅读/点赞/评论 → 更新台账 + 判读 + 下一步。锚点 1h/3h/12h/隔天；**过了的锚点不再追**（后台只有累计数，9-15 连问五轮永远拿不到）。

**🔴🔴 判读第一铁律（9-18 重写）：先问「这个数跑完了吗」。**
- **1h 数据只记录、不判读。** 机器是「慢启动＋长尾」模式，1h 只有终值的 **1/3 ~ 1/30**。实测：胡塞 123→**3,779**（30.7×）／波兰 23→**891**（38.7×）／美德 618→2,202（3.6×）。
- **任何两位数展现都不构成「没推」的证据。** 判「推不推」看 **3h 起**的曲线形状；判「推得准不准」等 **12h／隔天**。
- ⚠️ 9-17 我拿 1h 快照当终值立案「账号级限流」，还让浩总白跑两次客服（客服两次都说账号正常，是我没信）。**"9-13 断崖"很可能从未存在。**
- 余下仍有效：展现正常但点击率低＝**推错人** → 查**匹配**（标签池／标题／封面）。口诀：**展现看推不推，点击率看推得准不准，互动看钩子有没有。**

**点击率分档 v2（9-10）**：文章 垫底<1.5%／及格2-3%／健康4-5%／优秀6-8%／顶尖>9%；微头条 垫底<4%／及格6-7%／健康8-9%／优秀10-12%／顶尖>13%。

**平台横评标尺（9-17）**：后台「超过 X% 同类作品」是平台官方标尺。已知 4.9%→42%（胡塞）／11.5%→82%（印度）／16.8%→98%（胡塞终值）→ **4.9% 只在同类中位数**。我们分档是绝对值、平台是相对位置，不能混。每次报数据一并记。

**🚫 账号限流专案（9-17 立案 → 9-18 已推翻）**：账号全程正常。台账「二·五」节保留全案，作「用错误的时间尺度下结论」的思维标本。
**🔴 9-11 低质判定的根因（仍有效）**：平台原话「不适宜持续推荐，存在低质创作内容」＝**完读率 12% + 真实评论 0**。**篇幅是直接原因**——菲律宾篇实发 **2,185 字**（v1 只 1,007，因浩总反馈"主角太干瘪"加线后翻倍）。**常规稿必须压回 1,000-1,800 字；报数据必须带「平均阅读完成率 + 平均阅读时长」，低质线 <40%。**
- 处置（有效）：**不删稿 → 改作品信息（贴题封面 + 标题去"却"字）→ 人工复审**，当晚解决。**人工客服权限高于 AI 判罚。**
- **申诉成功 ≠ 内容判定被撤销**，但它**只解释那一篇自己的命运，与账号无关**——别再挂钩。

**篇幅 + 骨架（9-13）**：常规稿 **1,000 字左右 + 判断句小标题**（4 节层层推进，每节推翻读者一个想当然）。不许编号／施工图。**字数必须脚本实测**（去 markdown 标记与空白后数字符），不许凭感觉估，且**用发布版 txt 实测算数**（稿件 md 会混入核查表）。

**派生核对（9-13，9-17/9-18 三次命中）**：派生新文件前必须 grep 已作废的词。**定稿进台账 ≠ 进稿件**——标签/标题定稿后回扫**源文件 md**，再重跑发文包。

### 选题
- **分工（9-8）**：不主动探测／提议选题。丢话题后：核实 → 军事化＋不一样角度 → 成稿 → 去AI味 → 配图 → 发布参数。
- **军事化（9-8）**：找文件级硬料／制度钩子／冷切面。三问：读者会点吗？比主流多什么？在降敏红线内？手法：民生热点 + 军事制度钩子（军购／装备／民防／后勤线）。
- **选题闸门（9-13 立案，9-15/9-17 升级）**：①**避开官媒正在铺的题**；**通稿类最高危**（"某部委／发言人表态"；信号：**表态本身即新闻源**）②**可量化信号**：查该通稿话题讨论数——实测 `#国防部：助长日本军事野心将祸及自身#` **仅 8 条** → **官媒铺满 ≠ 民间在讨论，个位数应避开** ③处置：换入口（写"为什么偏偏用这两个词"，不写"谁说了什么"）／错峰 24-48h／标题绝不复述通稿标题。

### 标题
- **铁律（9-9）**：硬词前置 + 对撞／悬念，不把结论说完。15-26 字，硬实体词打头。
- **对撞 vs 并列（9-17）**：并列＝各说一件事（散）；对撞＝同一件事上两股力气相顶（紧）。正例：`胡塞给全世界发了张通行证，只有沙特没拿到`。
- **反"平淡"（9-16）**：悬念**一秒能懂**。要画面和动作，不要谜语。

### 标签
**池铁律（9-13）**：先查人数再排槽位。蓝标≠有流量。**定型 4 槽**（多挂＝稀释匹配精度）。

| 层 | 标签（讨论数） | 职责 |
|---|---|---|
| 1 品类大盘 | `军事` **40 万** 🏆 | 比任何国名都大。9-17 才发现，此前 10+ 篇从未挂过（一直用 `军事观察` 3,445，**差 116 倍**） |
| 2 领域大盘 | **`国际` 18 万** 🆕 | **9-18 新发现**。比 `国际政治`（6,954）**大 26 倍**且语义完全包含它 → **一律用 `国际`，不再挂 `国际政治`** |
| 3 大盘国名 | `美国`31万／`日本`21万／`俄罗斯`18万／`乌克兰`15万／**`中国`10万** 🆕 | 量级碾压，优先挑最大的国名 |
| 4 角色/实体 | `沙特`1.8万／`北约`1.5万／`胡塞武装`1.2万／`太空`1.0万／`波兰`8,000+ | 精准匹配故事主角 |
| 5 功能槽 | `国际政治`6,954／`军事观察`3,445 | 只归类不带量，**已被上层大盘词取代，尽量不用** |

- **🔑 找词的规律（9-18 提炼）**：**短词 > 长词**。`军事`(40万) > `军事观察`(3,445)；`国际`(18万) > `国际政治`(6,954)。**同一个意思，字数越少的往往池子越大**（因为它是领域名，不是细分类目）。查词时可顺手试试更短的同义写法。
- **三条补充**：①定 4 个 ②语义重叠不同挂（`太空`+`航天` 二选一，选大的；`国际`+`国际政治` 同理）③**别进错池子**——军事内容挂民用标签会推给科技读者。判据：**这个标签下的读者，是不是我想让他们看的人？**
- **🔴 9-18 补强：挂标签前先问「这个词在文章里是角色，还是背景？」——只挂角色，不挂背景。**
  - **实例**：9-18 输华管道篇我挂 `乌克兰`（理由"俄乌冲突是文章的因果起点"），**浩总当场纠正**——文章里乌克兰根本没出场，三方是俄罗斯（卖方／主角）／中国（买方）／欧洲（配角），`乌克兰` 只是"2022年"这个时间背景。
  - **附带损伤**：挂背景词＝**推给关心那个背景的读者**，他们点进来发现是能源财政 → **点击率难看**，正是"推错人"。**自检句：这个词在正文里有没有独立出现、有独立动作？** 没有 → 不挂。
- **9-17 修正**：`冷池<5000 划掉` 只适用**带量词**，不适用**功能槽**（池子小恰因垂直）。`国际政治` 多一倍 ≠ 流量多一倍。
- ⚠️ **`军事` 40 万 / `国际` 18 万均不予因果宣布**。⏭ 待验证：大池词是否真拉动展现（9-17 胡塞篇首挂 `军事`，终值 3,779 属正常档、未见量级跃升；9-18 输华管道篇挂 `军事`+`国际`，第二个样本）。别宣布"找到钥匙"。

### 微头条转发
**🔴 它同时出现在原文评论区**——**不是"缩略版文章"，是"一条评论"**。
- ❌ 200 字＋多段＝典型错误（读者刚读完文章，评论区又见缩写版，直接划走）。✅ **90 字左右**、一到两小段（胡塞 92／波兰 83／管道 79）。**必须给文章没有的东西**（补一个被忽略的点，或几件事并排摆出，再下一句判断）；**写完要回扫正文对照**——"我觉得这是新的"不算。钩子落最后一句。
- ❌ 禁"时间地点人物"三件套开头；✅ 可用"说个容易被忽略的点：…"。
- 🔴 **评论区只能有一条（9-17 第三次修正）**：转发评论自己就是原文下那条评论，**绝不再单独发自评**。要补细节 → **用「回复」挂在转发评论下**；不许回复自己就不发。默认什么都不做。

**🔴 爆量三件套（9-17 修正，原"四件套"）**：硬词标题 + 4 蓝标签 + **微头条自写转发**。❌ **没有第四件**——"自评设锚"是 8-31 的误设（9-10 已说明、9-12 已进 SOP、9-17 又误执行一次）；发文包默认不排"自评"节。

**钩子体系（9-13）**：结尾＝硬判断 + 二选一提问；中段软钩子＝15 字内极短停顿句单独成段；正文钩与评论钩不许问同一问题。

**低质提醒处置（9-11）**：不删稿 → 改一次作品信息 → 人工复审。预防：结尾低门槛钩子 + 发布后 1 小时内作者抛一个"有情绪就能答"的问题并置顶（**不是另发自评**）。

**发布窗口**：8:32-8:40。

### 配图
- **配图铁律**：①贴题一票否决 ②主体占 60%+ ③封面端出标题里的冲突/动作 ④**图上不能有任何文字**（原照片标牌除外）⑤**会场照一律淘汰**。
- **封面构图（9-15/9-17 修正）**："主体 60%+"是手段不是目的，起作用的是**画面张力**。**优先"夹峙／夹缝／对撞"**——被判据是张力不是地理：被船围、被人围、被车夹都是夹；没"海峡夹航道"就用"航母居中 + 两侧护航舰扇形铺开"。（正例：单兵站两辆发射车中间仰头摸舱门；反例：双车并排全景）
- 图源优先级：**DVIDS（可代下载·公版）** → 头条免费图库 → 提醒浩总搜。❌ 游戏CG／AI图／水印图／标题截图。
- **DVIDS**（可用 slug／404 清单／入口词全在 `知识库/项目/DVIDS配图作业手册.md`，**别凭记忆**）：① 直链 `{YYMM}` 是**发布日期**不是拍摄日期 ② **搜索页行不通** → 抓 `/unit/`、`/feature/`、`/news/`、`/video/` 页再 grep ID；需 `-L --insecure` + 完整 UA ③ **先读 slug 再决定下不下**。❌ `/image/{id}` 任何 ID 都返 200，不能探测存在性。
- **题材入口词**：海上 → `dvidshub.net image CENTCOM Arabian Sea warships`；铁路/补给 → `dvidshub.net railhead operations train loading military Europe`。⚠️ 太空题材单位页多是会议照，只找**火箭发射／装备正面特写／`feature/`**。

### 文风与其他
- **🔴 腔调铁律：幽默的紧迫感（9-16）**：用玩笑的腔调讲一件不能开玩笑的事——不是让人笑，是让人笑完后背发凉。**六手法**：口语嗓／翻译体（官方话说一遍+大白话翻一遍，最好用）／列举式沉默／冷笑话收口／把严重说成日常／紧迫感三板斧（时间感、后果感、反差感）。
- **反"平淡"五查（9-16）**：①全是词没东西 ②全在解释没故事 ③没有后果 ④节奏平 ⑤没有态度。解法：词换东西 → 分析换画面 → 长句砍短、单句成段。
- **网络**：curl 只通白名单（`dvidshub.net`✓／`images.unsplash.com`✓；`upload.wikimedia.org`、`commons.wikimedia.org`、`loc.gov`✗）。读网页优先 WebFetch。
- **脚本健壮性（9-17 立案，9-18 第四次复现）**：正则**别锚死在章节标题精确文本**（改标题会静默返空）。锚点用「章节号 + 关键词」+ `[^\n]*`。⚠️ **9-18 教训升级**：v5 换章节命名 → `gen_pack.py` **整包抽空**，当时只剩 15 分钟。**规则：写稿优先沿用脚本已认的章节命名；要改命名就先改脚本，别在赶发布时改。**
- **工具脚本**：**`.workbuddy/scripts/gen_pack.py`**（❌ 不是 `知识库/.workbuddy/scripts/`），`python gen_pack.py <稿件md> <输出txt>`（抽七节 + 逐字一致校验 + 作废标签扫描）。临时目录会被清理，脚本一律存项目内。

**🔑 军事化选题三层诊断顺序（9-18 立案，五轮改稿换来的）——出问题按顺序查，别跳步**：① **入口层：军事号读者为什么点？** 不是"能不能跟军事沾边"，是"读者点进来的理由是什么"（反例：写天然气生意＝财经号的题；正例：写"这条管子撑着军费"＝军事号的语言）② **腔调层：有没有"东西"和"现场"？** 全是占比金额＝**财政局的话**，读者没身体感受（换成"每花100卢布，38卢布进了军队"）③ **结构层：因果链完整吗？**

**🔴 降敏的正确边界（9-18 修正误区）：降敏该降的是"评判"，不是"背景"。**
- ✅ 可说「2022 年俄乌冲突爆发」「冲突四年多」「前线」——**事实交代，因果必需**；✅ 客观引用双方公开数据
- ❌ 不评判是非、不站队、不预测胜负；不写「谁撑不住了」这类结论；不写「留后手/制衡」这类网络猜测
- ⚠️ **最容易犯的错＝把背景抽走 → 因果断了 → 后面所有数字都成孤立的**（9-18 实例：抽掉 2022 背景后，读者不知道"军费为什么涨""路为什么断"）

## 二、读书公众号
- **触发词「记录上了瘾」** → 调出 `产出/读书内容/成品文章/2026-09-07_读书成了任务记录成了瘾_重发版.md`
- **读者画像**：为"和我同频的人、想要读书改变命运的人"发声（＝昨天的自己）
- **写前必读**（不许凭空写）；**省 token 读法**：只读 `产出/读书内容/读书号写作弹药卡.md`（约 2.5KB），不够按卡内指针定点读一个文件，每篇成文后追加 1-2 行
- **进度（9-17）**：第 30 天；《芙蓉镇》人物志第 4 篇（吊脚楼主→秦癫子→黎满庚→谷燕山），已定型"一篇一个人"写法；第 30 天做 10 天小复盘（最想写 vs 读者最认）
- **🔴 人物志铁律（9-17 立案）**：
  1. **写前必须核对人物关系与时间线**——9-17 两处搞错被当场抓出。**浩总读书极细，别凭印象写。**
  2. **体例＝纯讲人物，作者自省段不进正文**（9-16、9-17 连砍两次）。要带自己就压成两三句挂倒数第二节尾。
  3. **标题定稿常由浩总改词**（9-17"干的好事"→"干的事"）。改完 **grep 全文**，看新词与既有表达是撞上还是呼应。
  4. **压缩字数一次性规划砍哪几节，不挤牙膏**。顺序：合并同题节 → 删过渡与复述 → 合并同类对账段 → 最后才动句子。保骨头＝核心论点句 + 题眼。
  5. **考官问法④「换成你做不做」**（用具体动作逼表态）效果最好。
  6. **配图是重灾区**：渲染完必须**逐张打开看**，九张里常有三四张要返工。避让规则见 `render-social-cards` skill「排版避让铁律」。
