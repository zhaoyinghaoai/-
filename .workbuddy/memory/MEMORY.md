**🔴 完读率铁律（9-13 德国篇+菲律宾篇立案，当前第一战场）**：报后台数据时**必须一起报「平均阅读完成率 + 平均阅读时长」**——这两个是完读率的直接指标，比点赞评论更早暴露"内容留不留得住人"。**平台低质参考线：完读率 <40%**。**三篇实测把这条线画出来了**：菲律宾篇 **12.0%**（被"低质"提醒）／德国篇 **29.3%**（给量慢）／再往上才安全。⚠️ **残酷规律：展现量越大完读率越低**（11.5% 点击率的印度篇只推 26 人；94,158 展现的菲律宾篇完读率只有 12%——扩池必然推向路人，但平台不看分母）。**菲律宾篇的真相：完读率 12% + 真实评论 0 = 低质提醒的根；但读者侧投了相反票（点赞 118 / 收藏 27 / 涨粉+4 / 收益 3.44 元），960 个读完的人里出 118 赞 = 转化率 12%** → **机器和读者在打架，不是写得不好。**
> **📌 主线诊断（合并版）**：**我们一直在优化"让人点进来"（点击率 1.4%→11.5%，已毕业）；从没优化过"让人读完"（完读率 12%→29.3%，还在红线附近挣扎）。下一个战场是完读率。**
> **治完读率的三味药**：①**开头给回报承诺**（铺场景同时用一句话告诉读者"读下去能拿到什么"；自检"读完前3段知不知道再花2分钟能拿到什么"）②**中段软钩子**（在信息最密处之后/论点揭晓之前埋极短停顿句）③**篇幅控制**——**常规稿压到 1,000 字，骨架改为「三次翻转」**。

**🔴 篇幅标准 + 分段骨架（9-13 立案，浩总两次定调）**：**1,000 字左右 + 判断句小标题**，核心认知是"**不是压缩字数，是换骨架**"——旧骨架=7 节叙述体（每节补一层背景，读者看不到终点、随时可退）；新骨架=4 节层层推进（每节推翻读者一个想当然）。**分布**：开头 130 字（抛反常事实 + 给回报承诺）→ 一节 270 → 二节 250 → 三节 220 → 四节 190（含收尾：最强对照 + 硬判断 + 二选一）。**每节 200-270 字**，4 个短节比 7 个长节视觉上更"读得完"。**⚠️ 小标题铁律（浩总 9-13 定调「你用小标题吧」）**：小标题**必须是判断句**（「不是漏了，是有人拿掉的」），**❌ 不能写编号或施工图**（「翻转一」「第一节」「背景介绍」）。判据：**把四个小标题单独拎出来连读，能不能看懂这篇文章在讲什么？能 → 合格。** **砍字三原则**：①砍"解释"留"信息"（制度解释压成一句话）②砍"重复节"（把前文再说一遍的整节删——重复是完读率最大杀手）③砍"离题细节"（第三方评论/背景知识/非主线武器型号）。**⚠️ 改稿高危**：删段落易连带删掉软钩子（印度篇实测误删「文件上不会写明是谁拿的」），**改完必须 grep 复查钩子**；**别用整块删除做压缩**（old_string 拉太长会连删别的段），一段一段删、删完即验。样本：`产出/军事文章/印度莫迪普京篇_1000字紧凑版_20260913.md`（原 1,430 → 新 1,027，砍 28%）。

**钩子体系铁律（9-13 印度篇立案，一天内两次补正）**
- **结尾** = 硬判断 + 二选一提问，**两者都要**。判断句给"值得截图"的力度，二选一给"有话可说"的入口（选边站不用动脑 > 开放提问）。⚠️ **改稿最易丢钩子**——给文章"提力度"时顺手删掉结尾提问，改完必查"提问还在不在"。
- **中段软钩子（浩总 08:17 提出）**：在正文中间埋"要说重要的话之前那 3 秒的留白"——**不是提问，是一句极短停顿句单独成段**（15 字内、不评判、把两件事并排放着），让读者自己冒出一个念头产生表态冲动。位置：①信息最密处之后 ②论点揭晓之前。密度约 400-500 字一处。
- **硬钩子 vs 软钩子**：硬钩子抛悬念（"然后呢"→ 往下读，管完读率）；软钩子刹节奏（"这也太……"→ 想表态，管互动率）。**互动率的源头在软钩子，结尾钩子只是收网。**
- ⚠️ 正文钩子与评论钩子**不许问同一问题**（正文问"调解人还是买家"→ 评论改问"两头吃还是务实"）。
