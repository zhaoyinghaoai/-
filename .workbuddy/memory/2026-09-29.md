### 14:08~14:55 追加：他自己要"为什么"（本次含金量最高的追问）

他问：**"ln2 ÷ ln(1+r) 的本来公式是什么？r 是什么意思？"**

### 走法：四步推导 + 对数复习 + 换底公式

1. **四步推导**：`100×(1.08)^n = 200` → `1.08^n = 2` → 两边取 ln 用"指数搬下来" → `n = ln2÷ln1.08 = 9.006`
2. 🔴 **他自己问出了最关键的白话读法**：**"100 乘以多少个 1.08 才能等于 200 是吗？"**
   → 这正是 `n` 的含义，也**正是对数的定义**（"1.08 乘自己几次等于 2"）。**他一句话就把 `log₁.₀₈2` 读懂了。**
3. 他说"**对数是我高中学的，你帮我复习一下吧**" → 出了八道题（定义 3 道 / 特殊值 2 道 / 三条法则 3 道）→ **八道全对**
4. **换底公式** `log_a b = ln b ÷ ln a`：口诀"上面 b、下面 a"；一行证明（又是"指数搬下来"那条法则）；用 `log₂8`/`log₃27`/`log₅125`/`log₄64` 四个已知结果反查验证；并说明换成 log₁₀ 也一样
5. **72 的来历讲透**：`ln2 = 0.6931` → 百分号搬到分子 `69.31` → `100×ln1.08 = 7.696`（比 8 略小，心算易少算）→ **把分子调到 72**（`72÷8 = 9` 正好对上）

### 一个值得记的教学现象

**他算对数题时，连续两次只写结果、不写"它等于 log 几"。** 我要的那个"倒着走"的动作（给你答案，认出是哪个数的对数），他一开始没做。

**为什么重要**：`n = ln2÷ln(1+r)` 就是"倒着走"的产物——从 `(1+r)^n = 2` 反解出 n。**正着套法则容易，倒着解才是推导的肌肉。** 提醒后又补做了三道，都对了。
