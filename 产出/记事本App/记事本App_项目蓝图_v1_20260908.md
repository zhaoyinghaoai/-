# 随手库 · 手机记事本App 项目蓝图 v1

> 立项日期：2026-09-08　|　状态：需求✅ 原型✅（浩总验收"可以"），开发未启动
> 定位：浩总的个人"统一素材口子"，服务军事文章 + 读书公众号两条写作主线

---

## 一、一句话定位

**一个装在手机上的"统一素材口子"**——随手记（打字 / 语音 / 贴图都能进），能长期存也能快速转走，一键复制出去就能用；将来能发给别人、能做成收费产品。

## 二、为什么做（痛点）

浩总每天接触的信息散在微信收藏、截图、备忘录、文件传输助手……好几个地方，写作时要找素材得翻好几个 App。
真正的需求不是"多一个记事本"，而是：**所有随手东西以后都往这一个口子丢，用的时候一键取**。

## 三、用户画像

| 阶段 | 用户 | 含义 |
|---|---|---|
| 现在 | 浩总自己 | 先当个人提效工具，用顺了 |
| 将来 | 朋友 / 小团队 | 觉得好 → 发出去给别人一起用 |
| 更远 | 付费用户 | 为"付费运用"打基础（浩总原话） |

## 四、需求清单

### 4.1 功能需求（浩总亲口确认 9 条）

| # | 需求 | 细节 |
|---|------|------|
| 1 | 记文字为主 | 灵感/素材/金句，图片是辅助 |
| 2 | 一键复制 | 复制到**剪贴板（通用）**，自己再贴到别处 |
| 3 | 能长存也能快转 | 长期翻看 + 快速转走，两个都要 |
| 4 | 手机为主 | 单手拇指操作，按钮大、好按 |
| 5 | 打字 + 语音 | 两种输入都要，随场景切换 |
| 6 | 搜索窗口 | 记完能快速找回来 |
| 7 | 卡片式编辑页 | 界面像 YouMind，好看好用 |
| 8 | 留升级空间 | 架构别锁死，日后能升级 |
| 9 | 能发给别人 | 以后多人一起用 |
| 10 | 思维导图（9-8追加） | 双用途：①素材拉成导图→变文章大纲（写作向）②心里一团想法时铺开联想、看清自己真正要什么（梳理向） |

### 4.2 隐形需求（浩总验收：5 条全中）

| # | 隐形需求 | 含义 |
|---|---------|------|
| ① | 统一入口 | "别再让我到处找"——它是收集口，不是存储仓库 |
| ② | 语音是坚持用的钩子 | 快递点忙、常单手，说话随时能记 → 语音是习惯钩子不是锦上添花 |
| ③ | 写作素材中转库 | 复制的目的地 = 军事文章 + 公众号写作（他是写作者） |
| ④ | UI 好看 = 能见人 | 以后要发产品，质感从第一天做起 |
| ⑤ | 数据不丢 + 找得着 | 备份出口 + 快速搜索，是地基 |

### 4.3 付费地基（浩总补充，最关键的一条）

**为以后付费运用打好基础** → 数据结构从第一天按以下原则设计：
- 每条内容有独立 ID、时间戳
- 数据模型与"用户"解耦，将来加账号体系时不用推倒重来
- 功能分层预留（免费层 / 增值层），先不实现但别锁死

## 五、设计决策（原型已验证）

### 5.1 视觉
- 暖纸底 `#F5F0E6` + 深墨字 `#2B2620` + 赤陶橙 `#C05621`（行动点）
- 与公众号社卡同一套审美（暖纸 + 深墨），浩总熟悉、舒服

### 5.2 交互（对映需求）

| 需求 | 设计 |
|---|---|
| 单手用 | 底部三块：笔记 / **中间大 ＋**（拇指最舒服位）/ 搜索 |
| 复制是主目的 | 每张卡片右下角 **"⧉ 复制"** 常驻，不进详情就能复制 |
| 语音是钩子 | "按住说话"做成**大按钮**，占输入工具条主要位置 |
| 文字为主+贴图 | 正文输入框最大，贴图是辅助小按钮 |
| 长存+快转 | 首页时间分组流（今天/昨天）= 长存；卡片复制 = 快转 |
| 搜索 | 独立 tab + 首页顶部搜索条双入口；未来加"语音搜""搜图片里的字" |
| 卡片质感 | 白卡圆角 + 轻阴影，像 YouMind / 笔记软件 |

### 5.3 信息架构

```
首页(笔记流) ──点卡片──▶ 详情/编辑页(可改可复制)
   │ 顶部搜索条
   ├──▶ 搜索页(真过滤+高亮)
   └── 中间大＋ ──▶ 记一条(打字/按住说话/贴图 → 存为卡片)
```

## 七、版本规划（升级路线）

| 版本 | 内容 | 阶段 |
|---|---|---|
| **v0.5 自己能用** | 本地存储 + 打字/语音 + 复制 + 搜索 + 贴图 | 最小可用，先真用起来 |
| v1 质感完整 | 标签/分组、图片真存储、编辑体验打磨、**基础思维导图**（素材→大纲） | 当"拿得出手"的版本 |
| v2 发给别人 | 账号、数据上云、多设备同步、共享、导图自由梳理板 | 多人一起用 |
| v3 付费 | 免费/增值分层，打赏或订阅 | 商业验证 |

> 💡 **产品亮点（浩总 9-8 提出）**："帮用户发现隐形需求"——用户自己梳理不清时，工具引导他一层层看清真正要什么。这是随手库区别于普通记事本的差异化灵魂，v2/v3 可加 AI 引导提问强化它。

> ⚠️ v0.5→v1 阶段：数据模型就按 4.3 的"付费地基"设计，不返工。
