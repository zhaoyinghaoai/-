> 用途：写卷二卷三前的"世界底稿"。对齐 `大纲 v1` + 卷一 1-10 章正文。

## 一、轻奇幻定位与虚实边界【锁】

- **风格**：轻奇幻。巨鱼/海神托辞作叙事层保留，方术作神秘氛围，**仙药可真**，但**不写实鲛人神山实体**。
- **史实底座**（详 `大纲 v1·史料锚点`）：徐福齐地琅琊方士、两度出海、《史记》"得平原广泽，止王不来"；《汉书》韩终与徐福并列"入海求神采药，因逃不还"。
- **虚实分层**：
  - 实：始皇求仙潮、坑儒阴影、琅琊东巡、楼船出海、韩终史书真名。
  - 虚：始皇梦魇预见千年因果、平海东扶桑真实使命、韩终=徐福心腹副将（史实只证二人皆入海不归，同船为合理虚构）、扶桑少女、千年隐忍回响、韩终误服不死。

## 二、术语与红线【锁】

1. **制图术语**（浩总13:55订）：
   - **堪舆图** = 陆上舆地图（军国地理），始皇正式/口头语境用，如"从堪舆图上抹干净""踏平过堪舆图上每一寸土地"。
   - **海图** = 航海图（船队出行用），徐福/韩终绘、案上摊的均用海图。
   - **地图** = 现代词，全书禁用；仅"一整张图"类泛称可留。
2. **韩终近臣红线**（浩总13:47订）：韩终是**天子近臣、始皇唯一托底方士**。皇帝下令时纵有疑虑也必须**立刻领旨（"臣，遵旨"）、坚决拥护**，质疑只留私下对徐福（同乡）说，绝不当朝推辞/抗命。卷三"一念之仁放少女"须建立在"已领旨、内心仁觉醒"，而非"抗命"。
3. **同乡边界**：韩终同乡 = **徐福**（皆齐地琅琊方士）；**绝非始皇**（始皇秦人）。
4. **禁止章节自指（破框红线）**（浩总09-01 15:19订）：书中任何叙事文字（含当事人内心独白、叙述者旁白）**不得出现"第X章""卷X"等对本书包结构的指代**。当事人活在故事里，不知自己是第几章；叙述者亦不得用"第X章"标签事件。指代前事时用事件本身描述（如"始皇梦魇那夜""他在咸阳一笔笔绘的"），而非章节号。各章首行 `# 卷X·第Y章 标题` 是给读者导航的结构标记，不在禁止范围（本次已据此修正卷一第4/9章、卷二第1/2/3章共8处"第X章/卷X里"破框表述）。
5. **梦的归属红线**（浩总09-01 17:42订）：始皇帝做的梦，书中人物（徐福/韩终等）**不得说成"我/我们/梦中那面旗"归属自己**。徐福握"令"那一半、韩终握"梦"那一半（知梦内容），但梦本身不归二人；提及时须用"**陛下梦中 / 始皇帝梦中**"。注意信息分割：徐福通过卷一第4章始皇交底（"朕梦中见过的旗，插的就是那片海岸"）知"梦中有旗、插海东"，可比对"这支与梦中旗可像"，但不可把梦说成自己的。卷二第3章已据此把"与我们梦中那面旗"→"与陛下梦中那面旗"（两处）。
6. **发布合规红线**（2026-09-01 收尾新增，2026-09-02 补强+拍板）：对外发布版全文禁用"倭 / 红圆旗 / 甲午 / 侵华 / 倭寇 / 金陵惨案 / 冶城惨案（及一切真实惨案、真实战争名，含其古称、别称）"等指向现实民族与战争、或坐实真实历史事件字眼；始皇之梦以"跨越千年的因果劫"意象承载，不坐实为任一真实历史事件。卷三徐福"亮底牌"台词亦须用此抽象体系（铁船异旗 + 史无前例的黑暗），不点名真实惨案。
   - **09-02 浩总拍板（发布版路线）**：亮底牌"童谣/谶语"采用**脱敏版**——保留"梦中童谣 + 四句意象"结构，藏头改写为抽象预言 **铁/异/四/劫**（铁船异旗、四十余年后之劫），不坐实任一真实惨案名；并在发布版文首/文末附**合规提示（免责声明）**（见 `卷三/卷三_徐福亮底牌_台词demo.md` 文末）。
   - **本体稿/manuscript**：仍可写"金陵惨案"藏头童谣作创作存档（09-02 浩总最终定：本体稿用金陵惨案藏头、发布版脱敏），但**发布前必须脱敏**为抽象版（铁异四劫），违红线6不上发布版。参见 `产出/小说/徐福东渡_平台发布大纲_合规.md`。
   - **09-02 卷四第6章 历史背景锚定（仅作者私藏·不写正文）**：使馆段写"普国大使馆 + 逃难人 + 冤魂声由隐到显"，保持抽象。其历史原型为南京大屠杀 / 拉贝安全区（普国=普鲁士=德意志、拉贝、日军屠戮）——**此背景仅作作者理解，绝不写进正文**。发布版维持"普国"馆舍 / 赤丸旗 / 故国国都 抽象层即可，红线6安全。"赤丸样式的旗帜"为脱敏表述（红日旗抽象），可上发布版。

7. **用字规矩·犬与狗**（浩总 09-26 订）：通篇一律用"**犬**"（"狗"听着像骂人）；**唯卷四第 7 章韩终悔恨交加处，由"犬"降格为"狗"**，借其贬义衬其自轻自贱。徐福那句"狼未大时，也是犬样"（卷二第 3/4/8 章、卷四第 7 章回扣）均循此例。

## 三、地理与诸方

- **秦土**【锁】：书同文、车同轨，六国疆界化一（第1章始皇独白）。
- **琅琊**【锁】：东海之滨、齐地尽头，始皇东巡停留最久、立石刻颂秦德（第3章）；徐福择此上书非偶然——临海敢言、始皇近海显松弛。
- **东海**【锁】：航海通道，多雾、风涛、巨鱼（叙事层）。
- **扶桑（海东）**【锁+展开】：东海以东大片空白；韩终海图"扶桑"字样旁画矮丘怪树（第6章，海东异族之地的标记）；卷三登陆地。
- **三神山（蓬莱/方丈/瀛洲）**【锁·轻留白】：明面求仙话术，船头刻纹、寻仙旌旗；不实写神山实体。
- **扶桑诸部**【展开】：诸部落构成、少女所属部族、韩终所平与所赦之分野——卷二卷三细化（此处预留接口）。

## 四、轻奇幻规则

### 4.1 仙药体系【锁·触发点=扶桑部族守护灵药（7.1）】
- 韩终私藏丹方：三十余味（朱砂、云母、玉屑、松脂…"轻身延年"常用物），**末味"东海神山所出，无名"**（第6章原文）。师门传东海极处神山产草，服之"弗志弗死"。
- 始皇要出海求药，韩终私心借船寻自己那味药（为己身不死，母逝十二岁发誓）。
- **长生机制**【锁】：误服而非主动求成——韩终本为己身求药，却因卷三放过少女阴差阳错得药，讽刺感强；服之"弗志弗死"。

### 4.2 巨鱼 / 海神托辞【锁】
- 《史记》"射巨鱼"作叙事层保留。
- "海神托辞"：方术书术语，指舟人临险前的海上幻象（第9章韩终自疑"眼花了"）。

### 4.3 少女梦兆【锁（卷一已写）·展开（卷三）】
- 第9章韩终甲板雾中见少女：赤足浮浪、清眸、似"隔着千年的雾认出他"、伸手非求救非威胁是"辨认"。
- 韩终求药半生梦里"似有过站在海上的清眸女子"——托辞或真实预视，**轻奇幻留白**。
- 卷三被赦后，此梦兆与"隐忍血脉"接通【展开】。

### 4.4 长生者亲历因果【锁（结局）】
- 始皇只**梦见**因果；韩终**活见**因果（双层预见闭环）。不老不是金手指，是罚——让他独吞自己那点仁慈的利息。卷四以死谢罪。

## 五、秦代海洋技术【锁（卷一已写）】

- **楼船**：龙骨粗如村中古槐，帆索比人臂粗；船头刻三神山纹，挂"寻仙"旌旗（第6章）。
- **底舱甲兵**：弩机、戈矛、甲片裹油布锁入底舱；始皇调三千锐卒扮船工护卫，平时锁、到海东为锋刃（第6章）。
- **司南**：徐福交韩终掌首船方术（第9章）。
- **海图**：韩终绘，东海以内熟、以东空白（第6章）；徐福从海图推扶桑（第4章）。
- **观星辨风**：韩终齐地方士本事，定航向、避风涛、护船（第6/9章）。
- **童男女数千、百工、五谷**：按求药排场，明面遮天下耳目（第6章）。

## 六、年代与纪年【锁（史实）】

- 始皇二十八年（前219）：东巡郡县、琅琊立石刻、徐福首上书入海求仙。
- 始皇三十二年（前215）：《史记》"使韩终、侯公、石生求仙人不死之药"（韩终史骨）。
- 始皇三十七年（前210）：徐福再出海，增弓弩手射巨鱼、带童男女三千百工五谷；终"得平原广泽，止王不来"。
- 小说将史骨压缩入"梦见→交底→出海"叙事链，具体纪年以卷一"始皇二十八年东巡"为锚（第3章）。

## 七、待拍板项（浩总定）

> 2026-09-01 浩总确认：两项均采纳推荐方案，现已锁死。

### 7.1 仙药触发点【锁·选定 B·扶桑部族守护灵药】
- **机制**：韩终卷三放过少女时，少女/其族以神山所出之药相授、或韩终误触此草 → 因仁得药、因药得长生、因长生得亲历因果、因亲历而谢罪，**因果闭环最狠**，且与第6章丹方"末味东海神山所出"严丝合缝。
- 备选 A·徐福所得"平原广泽之药"：韩终替徐福保管时误服（贴《史记》"得平原广泽"史骨）——**未采纳**，因 B 方案的"因仁得药"更贴合道德心脏设定。
- 落笔卷三时按 B 执行：放过少女的"一念之仁"直接成为误服不死的触发点。

### 7.2 卷四"亲历千年因果"落点【锁·选定 抽象·铁船异旗的梦魇成真】
- **理由**：以海始、以海终对称——韩终以海征出、以海亲历自己仁慈的因果，宿命感最强；不点名具体战争，留白更强、亦避影射。
- 落笔卷四时：韩终长生亲历一场由当年那点仁慈长成的、跨越千年的海战梦境成真（铁船、异族旗），与第1章首尾咬合。

### 7.3 其余已锁，无需再议
- 心腹副将=韩终（史书真名）；轻奇幻；网文向；被放过者=扶桑少女；四卷骨架 2.5/2.5/3/2 万字；护栏（隐忍=创伤生存术 / 韩终之仁=道德心脏 / 结局直给因果不反讽）。
