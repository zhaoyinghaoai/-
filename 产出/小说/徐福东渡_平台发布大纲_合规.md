## 一、发布版 · 一句话故事（Logline）

方士韩终随徐福跨海寻仙，却因一念之仁放过一名海东扶桑少女；他更阴差阳错误服不老药，长生不老。千年里，他亲见自己当年那点仁慈在时光中长成的因果——那支被放过的血脉将"隐忍"刻入骨血，长成了他再也挽回不了的模样。长生不是恩赐，是罚：让他独自吞下这份额外的债，最终以死谢罪。

## 二、发布版 · 主题

**仁慈的代价，与长生者的债。** 一个人的一念之仁，在千年尺度上发酵成他始料未及的因果；而不死，让行善者独自吞下这份额外的刑罚——直到以死谢罪，才把债还清。

## 三、合规护栏（发布版铁律）

| 禁用字眼 | 替代口径 |
|---|---|
| 倭 / 倭寇 / 倭患 | 那字 / 海东之民 / 后患（"那字"作始皇梦中不可名状之恐惧的留白） |
| 红圆旗 / 红底白圆 | 异族旗 / 形制陌生的旗 / 一面陌生的旗 |
| 甲午 / 侵华 / 具体战争名 | 删除；卷四落点统一为"铁船异旗的梦魇成真"抽象意象 |
| 中原 / 反噬中原 | 故土 / 秦土（若需，避免"反噬"对抗叙事） |
| 灭扶桑 / 灭国（实写种族根除） | 平海东 / 平服一族（弱化灭绝语气，保留帝王令与仁的冲突） |

原则：始皇之梦只作"跨越千年的因果劫"意象，绝不坐实为任一真实历史事件或民族。故事的内核是**一个人的仁与悔**，不是族群对抗。
