# 读书公众号产出

> 读书公众号的所有产出物归这里。按类型分文件夹存放，别再散着放了。

## 文件夹说明

| 子文件夹 | 放什么 |
|--------|--------|
| 成品文章/ | 读书感悟、书评类成品文章 |
| 古诗词解读/ | 古诗词治愈解读类文章（独立一条线） |
| 配图/ | 文章配图（封面图、内文配图，按文章名分子文件夹） |
| 选题库/ | 还没动笔的选题想法、灵感记录 |
| 运营复盘/ | 阅读量、涨粉、选题效果等运营复盘 |

## 文件命名规范

- 成品文章：`YYYY-MM-DD_标题.md`（或带版本 `_v1_日期`）
- 例：`2026-08-20_勇敢开口你至少赢了90%.md`

## 相关位置（别搞混）

| 内容 | 放哪 |
|------|------|
| 读书原始素材（摘抄、划线） | `原始材料/书摘/` |
| 读书方法/运营方法提炼 | `知识库/知识主题/读书笔记/` |
| 公众号成品文章 | 本文件夹 → `成品文章/` |
