## 二、人物表（核心九人）

| 人物 | 身份 | 关键事实 |
|---|---|---|
| **万心（姑姑）** | 乡村妇产科医生，任职六十年 | 父亲万六府是八路军军医、烈士，跟白求恩学过西医。前半生推行新法接生，跟老接生婆抢孩子；1960 年代起执行计划生育，**带过队、给村里男人做过手术**。丈夫郝大手。晚年精神时清时昏，把终止妊娠的孩子一个一个捏成泥娃娃。✅ **已写（第39天）** |
| **万足（蝌蚪）** | 叙述者，"我"，姑姑的侄子 | 军人、剧作家。前妻王仁美、后妻小狮子。**为前程默许王仁美引产，妻子死在手术台上。**四个信的"我"就是他 |
| **王仁美** | 蝌蚪原配 | 父母王金山、吴秀枝。怀第二胎被迫引产，**大出血身亡** |
| **小狮子** | 曾是姑姑的助手，后为蝌蚪之妻 | 🔴 **在陈眉这条线上她做足了三个动作**：①陈眉即将在木筏上出生时，**不会游泳的她跳进水里**，为这个孩子争取了出生时间；②王胆死后，**和姑姑一起喂养了陈眉半年**，"抱着陈眉，亲不够，看不够"；③陈鼻把陈眉带走那天，**她哭得浑身乱颤**，姑姑训她"哭什么哭，自己生一个"——而她生不出来。多年后，**她瞒着蝌蚪取了他的精子，选中陈眉为她代孕**，孩子出生后抱走。温顺、隐忍，一辈子活在姑姑的光环下，晚年被生育执念驱动 |
| **陈鼻** | 蝌蚪小学同学 | **姑姑接生的第一个孩子**（父亲陈额是旧社会地主，母亲艾莲是俄裔 → 混血面孔）。曾是东北乡首富"万元户"，**因王胆二胎又生女儿而拒绝养育陈眉**，交了姑姑开的 5800 元罚款才把孩子领回。妻死女残，晚年负债、疯疯癫癫，在"堂吉诃德"餐馆扮成堂吉诃德招徕客人 |
| **王胆** | 陈鼻之妻 | **身高仅 70 厘米的侏儒**。为生男孩怀二胎、东躲西藏，被姑姑带人在水上堵住，**在竹筏上早产生下陈眉，自己难产身亡**。陈眉这个名字是姑姑起的（姐姐叫陈耳，因为她"眉清目秀"） |
| **郝大手** | 民间泥塑艺人，姑姑的丈夫 | 姑姑退休宴上被假酒放倒（饭店老板解小雀用假酒）→ 头晕 → 撞上郝大手，两人结缘 |
| **袁腮** | 蝌蚪小学同学 | 曾替妇女**私拆节育环**；后开牛蛙养殖公司，**暗中经营代孕**。⚠️ **说好给陈眉五万，公司骗她说生了死胎，只给了一万**。妻麻花儿 |

## 六、浩总的第一手判读（成文必带）

- 关于姑姑（浩总原话）：**"他是坚定的共产主义战士……毫不动摇地执行国家的国策，这是很令人钦佩的。"** ⚠️ 我当时的处理：**"令人钦佩""坚定的战士"这类评价性的话一句不用**，把落点改成 **"她的恍惚不是动摇，是重量"**——用他自己的那句"有点难过"作骨头。这条已成惯例，写后面几篇同样适用。
- 浩总补充：**"她是乡村医生，是带队的，给男人做手术的。"**／**"姑姑晚年把那些她终止妊娠的孩子都做了泥娃娃。"**
- ⚠️ 待确认：王仁美引产的具体过程（是不是在手术台上出事、蝌蚪当时在哪、谁签的字）——**成文前问浩总**。
- ✅ 已核清（2026-09-27）：陈眉产子后被抱走，孩子（**小名金娃**）最终**归小狮子**（话剧里由高梦九"断"给她）。陈眉是**以黑纱遮面**（不是头盔），原因是怕吓哭小孩。
