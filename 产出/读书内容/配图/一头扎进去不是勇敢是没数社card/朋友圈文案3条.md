# 第22天朋友圈文案（一头扎进去不是勇敢，是没数）

标签：#读书 #学会提问 #创业思维

---

**① 金句型**
一头扎进去不是勇敢，是没数。想事情不能光靠脑子里的想象，得拿点真东西垫底。数据是真的、样本有代表性，才配谈自主思考。不然想得再起劲，也是空中楼阁，风一吹就散。
#读书 #学会提问 #创业思维

**② 接地气型**
今天读《学会提问》被扎了一下：自主思考是有前提的，信息得够、还得真，凭一丁点东西下判断，那叫自己哄自己。想起军事号 82 粉涨不动那阵，我一口咬定"水平不行"。后来美伊那篇水平一点没变，就改了方法，12 小时 4503 展现，是之前的 5.4 倍。我才回过味：看见一个数、给它编个原因，那叫联想；改一个动作、等系统给个回响，那才叫验证。
#读书 #学会提问 #创业思维

**③ 互动型**
书里有句话：做决定的基础如果只有极为有限的一点信息，那就很难真正思考。刷视频那些"躺赚"项目，我以前一听就上头，"我觉得行"。现在会先问自己两句：我有数吗？这数是真的吗？你有没有哪件事，是"我觉得行"就一头扎进去，后来才发现自己根本没数的？聊聊。
