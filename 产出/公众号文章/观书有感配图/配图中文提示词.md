# 观书有感·其二 — AI配图中文提示词

> 以下提示词可复制到 **可灵 / 即梦 / 通义万相** 等国产AI生图平台使用。
> 风格统一选：**水墨 / 国风 / 治愈**

---

## 图1：封面图（江面大景）

**提示词：**

```
中国传统水墨画风格。清晨的宽阔江面，春水初涨，水位高涨且平静。画面中央一艘古代巨型木船轻盈地漂浮在江面上，仿佛轻如鸿毛。远处是若隐若现的水墨远山，轮廓柔和。柔和的金色晨光映在水面上，江面升起淡淡薄雾。色调以淡青、柔金、灰蓝为主。构图留白，上方留出大片天空，意境空灵。整体氛围宁静、治愈、诗意，有禅意。
```

**用途：** 公众号封面图，上方留白处可叠加标题文字

## 图2：正文配图（江边近景）

**提示词：**

```
中国传统水墨画风格。春天的江岸边特写。春水轻轻上涨，水波拍打着石岸。水边隐约可见一艘古船的船舷，船身轻盈地浮在水面上。岸边有柔软的青草和细小的野花。温暖的晨光透过薄雾洒下来，笔触细腻轻盈。色调以淡绿、浅蓝、暖白为主。整体氛围治愈、安静、温柔。
```

**用途：** 正文配图，放在原诗引用块上方或段落间做视觉分隔

## 使用建议

| 平台 | 免费？ | 特点 |
|------|--------|------|
| **即梦**（jimeng.jianying.com） | 免费 | 字节系，国风水墨效果不错 |
| **可灵**（klingai.com） | 有免费额度 | 快手系，画面质感好 |
| **通义万相**（tongyi.aliyun.com） | 免费 | 阿里系，水墨风格拿手 |

**操作步骤（三个平台通用）：**
1. 打开对应网站，登录账号
2. 找到「图片生成」入口
3. 把上面的提示词粘贴进去
4. 风格如果有选项，选「水墨」「国风」或「中国风」
5. 生成后挑一张最满意的，下载即可
6. 生成的图没有"AI生成"水印，可直接用于公众号

**小贴士：** 如果第一次生成的不太满意，微调提示词里的颜色或氛围词再试一次，通常2-3次就能出满意的。
