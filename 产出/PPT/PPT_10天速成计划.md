## Day 1 · 快捷键 + 基础复习

**学习内容：**
6个必记快捷键（来自旁门左道笔记）：

| 快捷键 | 功能 | 使用场景 |
|--------|------|----------|
| Ctrl+G | 组合对象 | 把多个元素绑成一组移动 |
| Ctrl+Shift+G | 取消组合 | 拆开重新编辑 |
| Ctrl+鼠标拖动 | 快速复制 | 不用Ctrl+C/V，直接拖 |
| Ctrl+Shift+鼠标拖动 | 水平/垂直复制 | 排一排同样的卡片 |
| F4 | 重复上一步 | 连续设置同样格式，效率神器 |
| 按住Shift | 等比例缩放 | 调图片不变形 |

**练习任务：**
打开WPS，新建空白PPT，做以下操作各5遍：
1. 画3个矩形 → Ctrl+G组合 → Ctrl+Shift+G取消
2. 画1个矩形 → Ctrl+拖动复制3个 → 排成一行
3. 画1个矩形设蓝色填充 → 再画1个 → 按F4（自动变蓝）
4. 插入1张图片 → 按住Shift缩放

**当天产出：** 1页"快捷键练习记录"截图

**WPS注意：** WPS的快捷键和PowerPoint基本一致，但部分功能位置不同。如果找不到"组合"按钮，右键菜单里一定有。

## Day 3 · 排版4步法（最核心的一天）

**学习内容：**
这是旁门左道PPT最核心的方法论，学会这个你就能把任何一段文字变成PPT页面。

**排版4步法：**

**第1步：梳理信息**
- 找出主干（通常是第一句话或最后一句话）
- 把论据拆成关键词（不要整句放上去）
- 判断信息结构：
  - 论证型（后面论证前面）
  - 包含型（包含、聚焦、涉及）
  - 流程型（首先、其次、第一、第二）

**第2步：确定布局**
- 并列展示型：横向排列、田字格
- 环绕对称型：多点内容，奇数半圆，偶数整圆
- 拦腰布局型：1段介绍 + N段内容

**第3步：改变层级**
- 颜色：重点用强调色
- 粗细：关键词加粗
- 字号：标题与正文1.5倍关系（如标题36/正文24）
- 深浅：次要信息用浅灰

**第4步：可视呈现**
- 图片：找与主题相关的高清图
- 图标：用图标替代文字标签
- 图形：用色块/形状表达逻辑关系

**练习任务：**
拿这段文字练习：

> "2024年公司销售额同比增长25%，新客户开发52家，覆盖3个新区域。团队扩编至28人，培训覆盖率100%。客户满意度达96%，复购率提升18%。"

按4步法做：
1. 梳理：主干="业绩增长"，4个论据（销售/客户/团队/满意度）
2. 布局：并列展示型，4个卡片横向排列
3. 层级：关键数字（25%/52家/28人/96%）用强调色加粗
4. 可视：每个卡片加1个对应图标

**当天产出：** 1页排版练习（4卡片并列型）

## Day 4 · 排版实战（3种布局）

**学习内容：**
练习3种最常用的布局，覆盖80%接单场景。

**布局1：并列型（最常用）**
- 3-4个要点横向排列
- 每个要点：图标 + 关键词 + 1句话
- 适用：工作汇报、产品介绍

**布局2：拦腰型**
- 左侧1段介绍 + 右侧3-4个要点
- 或上1下3的布局
- 适用：毕业答辩（研究背景+研究成果）

**布局3：对比型**
- 左右两栏对比
- 左边"问题" + 右边"方案"
- 适用：商业路演、方案对比

**练习任务：**
用同一段文字，做3种不同的布局：
- 布局1：4卡片并列
- 布局2：左介绍右要点
- 布局3：左问题右方案

**当天产出：** 3页不同布局的PPT（同一段内容）

**关键原则：**
- 内容相同，布局不同，效果完全不同
- 接单时先问客户"你想要什么感觉"，再选布局
- 不要一页塞太多信息，超过5个要点就拆页

## Day 5 · 封面页3种版式

**学习内容：**
旁门左道封面页公式：划分层级 → 匹配图片 → 确定布局

**3种接单必会封面版式：**

**版式A：全图+文字叠加（最常用）**
1. 找一张高清大图（城市/山峰/海洋/天空）
2. 插入全屏渐变透明色块（色块凸显法）
3. 文字放在色块上方
4. 主标题36-44pt + 副标题20-24pt

**版式B：半图半文**
1. 上半部分放图片（占60%）
2. 下半部分纯色底放文字
3. 标题居中或左对齐

**版式C：纯色+大字（最简单）**
1. 纯色背景（你的主色）
2. 超大标题居中
3. 副标题在下方
4. 底部加logo或日期

**色块凸显法（Day5核心技能）：**
1. 插入形状 → 矩形 → 覆盖整页
2. 右键 → 设置形状格式 → 渐变填充
3. 方向：线性向右（如果主体在右侧）
4. 左侧光圈透明度100%，右侧透明度0%
5. 颜色用你的主色

**练习任务：**
做3个封面页，分别用3种版式：
- A：全图+渐变色块+文字叠加
- B：半图半文
- C：纯色+大字

**当天产出：** 3个封面页（以后接单直接套版）

**WPS注意：** WPS免费版的图片处理功能够用。如果找不到高清图，用Unsplash（免费免版权）。

## Day 6 · 内容页排版实战

**学习内容：**
把Day3的排版4步法用在5种常见内容页上。

**5种必会内容页类型：**

| 类型 | 布局选择 | 要点 |
|------|---------|------|
| 要点页 | 并列型 | 3-4个要点，每个1句话 |
| 数据页 | 大数字+说明 | 关键数字放大，用强调色 |
| 图表页 | 图表+文字说明 | 图表占60%，说明占40% |
| 引用页 | 大引号+引文 | 引文居中，字号大 |
| 过渡页 | 纯色+章节名 | 1页只放1个词，大字居中 |

**内容页排版铁律：**
- 标题与正文字号1.5倍关系（标题36/正文24，或标题32/正文20）
- 正文行距设为1.3（段落 → 行距 → 多倍行距 → 1.3）
- 正文用深灰色#333333（不用纯黑，太刺眼）
- 每页文字不超过6行
- 图标风格统一：线条型全部线条型，填充型全部填充型

**练习任务：**
做5页内容页，分别用5种类型：
1. 要点页（并列4卡片）
2. 数据页（3个大数字+说明）
3. 图表页（插入柱状图+文字）
4. 引用页（客户评价/领导讲话）
5. 过渡页（章节分隔）

**当天产出：** 5页内容页 + 封面 = 1份6页迷你PPT

## Day 7 · 色块凸显法进阶 + 高级封面

**学习内容：**
把Day5的色块法深化，做出"看起来很贵"的封面。

**3种高级色块用法：**

**用法1：单侧渐变（基础）**
- 图片主体在右 → 渐变向右
- 左侧透明度0%（完全显示图片）→ 右侧透明度100%（纯色覆盖）
- 文字放在纯色覆盖的一侧

**用法2：双侧夹击（进阶）**
- 上下各一个渐变色块
- 中间留出图片带
- 文字放在上方色块上

**用法3：圆形遮罩（高级）**
- 插入圆形 → 覆盖在图片上
- 设置半透明填充
- 文字放在圆形内

**高级封面额外技巧：**
- 图片虚化：设置图片格式 → 艺术效果 → 虚化（半径越大越模糊）
- 暗色叠加：在图片上覆盖一层半透明黑色（透明度40-60%）
- 字体选择：封面标题用思源黑体或微软雅黑粗体

**练习任务：**
用3种色块法各做1个封面：
1. 单侧渐变（图片在右，文字在左）
2. 双侧夹击（上下色块，中间图片带）
3. 圆形遮罩（圆形+文字叠加）

**当天产出：** 3个高级封面

## Day 8 · 表格美化 + 母版基础

**学习内容：**

**表格美化6步法：**

1. 清除格式：全选表格 → 表设计 → 选第一个（无格式）
2. 去掉所有框线：表设计 → 边框 → 无框线
3. 表头处理：表头行加主色底+白字，上下加线（2.25磅）
4. 数据行：文字左对齐，数字右对齐
5. 隔行色：奇数行白色，偶数行浅灰（#F5F5F5）
6. 重点数据：用强调色标注

**母版基础：**
1. 视图 → 幻灯片母版
2. 在母版中插入logo（固定在右上角或左下角）
3. 在母版底部插入页码（插入 → 幻灯片编号）
4. 设置占位符：文字占位符、图片占位符
5. 关闭母版视图 → 所有页面自动统一

**练习任务：**
1. 插入一个4列5行的表格 → 用6步法美化
2. 进入母版 → 加logo和页码 → 关闭母版
3. 新建5页 → 检查是否都自动有logo和页码

**当天产出：** 1页美化表格 + 5页带母版的页面

**WPS注意：** WPS的母版功能在"视图 → 母版"里。如果找不到，用"设计 → 编辑母版"。

## WPS vs PowerPoint 注意事项

| 功能 | PowerPoint | WPS免费版 |
|------|-----------|-----------|
| 快捷键 | 完全一致 | 完全一致 |
| 布尔运算 | 合并形状菜单 | 插入→形状→合并形状 |
| 母版 | 视图→幻灯片母版 | 视图→母版 |
| 图表改色 | 丰富的配色方案 | 免费版配色少，需手动改RGB |
| 虚化效果 | 图片格式→艺术效果 | 图片格式→艺术效果（位置可能不同） |
| 渐变色块 | 形状格式→渐变填充 | 完全一致 |

**WPS踩坑提醒（你已经踩过的）：**
- "更改颜色"不只改图表，背景文字全跟着改
- "应用到全部"只有当前页有效
- 免费版没有蓝色系图表配色 → 手动双击逐块改RGB
