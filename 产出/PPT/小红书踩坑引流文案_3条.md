我学PPT第6天，做"上图下文"版式

教程说"标题用深蓝#1F4E79"

我照着打了，然后……

字呢？字去哪了？🤔

深蓝底 + 深蓝字 = 字和背景融为一体，完全看不见

这个坑太经典了，我做的时候真的愣了3秒

**深蓝底文字颜色铁律：**
- 大标题 → 白色 #FFFFFF
- 副标题 → 浅蓝 #B5D4F4
- 要点正文 → 白色或浅蓝

绝对不能用深蓝！

后来发现不止我踩这个坑
卡片用蓝色、信息糊进背景，也是一个道理
深蓝底就必须用白色卡片 + 深蓝文字

1️⃣ WPS模板页4个按钮，3个要会员，新手一不留神就点付费功能
→ 每次只点"空白演示文稿"

2️⃣ 手打圆点•在Arial字体下渲染成方块
→ 改用WPS自带"项目符号"功能

3️⃣ 图表"更改颜色"把背景文字全改了，字直接消失
→ 改色后必查3项：色块/背景/文字

4️⃣ "应用到全部"结果只有1页有效果
→ 全选所有页一起设置

5️⃣ 饼图小扇形数字挤一起看不清
→ 双击标签→标签位置→数据标签外

6️⃣ 卡片用蓝色，信息糊进背景
→ 深蓝底必须用白色卡片
