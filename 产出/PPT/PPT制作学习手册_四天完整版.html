全部操作技能（分步骤详解）

一、基础操作

1
打开WPS演示 + 新建空白文稿
基础
  • 打开WPS → 点"WPS演示"图标
  • 模板选择页有4个按钮 → 点"空白演示文稿"（免费的那个）
  • 注意：不要点"AI生成PPT""上传文档生成""稻壳大师"——这3个都要会员
坑：每次打开PPT必须选"空白演示文稿"，别被付费按钮引导走
2
设置16:9宽屏比例
基础
  • 顶部菜单点"设计"标签
  • 工具栏找"幻灯片大小"按钮
  • 选"宽屏(16:9)"
虽然WPS默认就是16:9，但走一遍流程确认一下更稳
3
打字 + 改字号
基础
  • 点击标题占位符中间（出现光标）
  • 打字输入标题内容
  • Ctrl+A 全选文字
  • 在顶部字号框里输入数字（标题用40，副标题用18，正文用18-24）
4
保存文件
基础
  • Ctrl+S 快捷保存（第一次会弹出"另存为"窗口）
  • 选保存位置 → 输入文件名 → 点保存
  • 以后每次按 Ctrl+S 就直接保存，不弹窗
养成习惯：每做完一步就按 Ctrl+S，防止白做

二、页面设置

5
设置参考线（安全区）
进阶
  • 顶部菜单点"视图"标签
  • 勾选"参考线"（按钮变蓝=已开启）
  • 默认出现1条竖线+1条横线（在页面中心）
  • 从顶部标尺往下拖，可以新增横线；从左侧标尺往右拖，可以新增竖线
  • 拖动参考线到合适位置，4条线围成一个"安全区"矩形
参考线的作用：让每页的标题、正文都在同一位置，看起来整齐。参考线不会打印/导出，只给你看的
6
设置背景色（深蓝底）
进阶
  • 右键点击页面空白处 → 选"设置背景格式"
  • 右侧弹出面板 → 选"纯色填充"
  • 点"颜色"下拉 → "其他颜色" → "自定义"标签
  • 输入RGB值：R:31 G:78 B:121（深蓝#1F4E79）→ 确定
  • 点底部"全部应用"→ 所有页面都变成深蓝底
关键：一定要点"全部应用"，不然只有当前1页变色。Ctrl+M新建的页面不会自动继承背景色

三、文字操作

7
改文字颜色（右键字体法）
进阶
  • 选中要改色的文字（Ctrl+A全选 或 拖选）
  • 右键 → 点"字体"
  • 弹出对话框 → 找"字体颜色" → 点下拉 → "其他颜色" → "自定义"标签
  • 输入RGB值 → 确定 → 确定
推荐用"右键→字体"法，不用找工具栏小按钮，最稳。工具栏那个"A字加下三角"的按钮容易跟"填充颜色"搞混
8
批量替换字体（Arial → 微软雅黑）
高级
  • 顶部菜单点"开始"标签
  • 工具栏找"替换"按钮 → 点旁边的小三角
  • 下拉菜单选"替换字体"
  • 弹窗："替换"选 Arial → "替换为"选 微软雅黑 → 点"替换"
  • 10页PPT的字体1秒全部改完
坑："替换"按钮右边有个很小的下三角，容易忽略。不是点"替换"本身，是点它右边的小箭头
9
项目符号（圆点列表）
进阶
  • 选中要加圆点的多行文字
  • 顶部"开始"工具栏找"项目符号"按钮（三个圆点图标）
  • 点击即可添加圆点
坑：不要手打圆点符号"•"——在Arial字体下会渲染成方块。用WPS自带的项目符号功能才靠谱
10
文本框拉宽（解决文字换行）
进阶
  • 点击文本框（出现橙色边框+8个调整点）
  • 鼠标移到右边中间的小圆点上
  • 光标变成左右箭头时，按住左键往右拖
  • 文字就不再换行了

四、页面操作

11
新建页面
基础
  • Ctrl+M 快捷键新建一页空白幻灯片
  • 或者：左侧缩略图区域最下方，点"+新建幻灯片"按钮
注意：Ctrl+M新建的页面是白底，不会自动继承深蓝背景。需要在背景设置时点"全部应用"才统一
12
复制页面（Ctrl+D）
高级
  • 左侧缩略图点中要复制的页面
  • 按 Ctrl+D → 自动复制一页到后面
  • 复制出来的页面保留所有格式（背景色/装饰条/字体/参考线）
  • 只需改文字内容即可
这是做10页PPT的核心技能！做好1页模板，Ctrl+D复制9次，改文字就完事
13
拖动调整页面顺序
进阶
  • 鼠标点住左侧缩略图（不要松手）
  • 往上或往下拖动
  • 拖动时会看到一条横线，表示插入位置
  • 横线到想要的位置后松手，页面就移过去了

五、排版技巧

14
插入装饰条（矩形）
进阶
  • 顶部菜单点"插入" → "形状" → 选"矩形"
  • 在页面上拖出一个长条矩形（标题下方）
  • 右键矩形 → "设置对象格式" → 填充颜色 → #85B7EB → 透明度60-70%
  • 再拖一条更短的细矩形在下方，颜色更浅
两条装饰条一长一短，一深一浅，是科技风PPT的标准排版手法
15
副标题制作（含竖线分隔符）
进阶
  • 在标题下方、装饰条下面插入文本框
  • 输入内容格式："演示人：浩浩 | 2026.07.31"
  • 竖线 | 的打法：Shift + \ （退格键左边那个键）
  • 字号18，颜色浅蓝#B5D4F4（RGB: 181/212/244）
16
章节过渡页制作
高级
  • 用Ctrl+D复制封面页 → 改成过渡页
  • 左侧放大号编号"01"（字号60-80，颜色浅蓝#85B7EB）
  • 中间放中文标题（如"项目概述"，字号40，白色）
  • 标题下方放英文副标题（如"Project Overview"，字号18，浅蓝）
  • 右下角放页码（如"03/10"，字号12，浅蓝）

六、图标操作

17
插入SVG图标到PPT
进阶
  • 顶部菜单点"插入"标签
  • 工具栏点"图片"按钮
  • 选"本地图片"（不要选"在线图片"）
  • 在文件窗口找到 PPT素材库\图标\科技风_图表.svg\ 文件夹
  • 选中SVG文件 → 点"打开"
  • 图标出现在幻灯片上
18
调整图标大小和位置
基础
  • 调大小：鼠标拖角点（四角的小圆点），按住 Shift 键等比缩放
  • 移位置：鼠标拖图标中间，移到目标位置松手
  • 取消选中：点页面空白处
一定要按住Shift拖角点！不按Shift拖动会变形（拉长/压扁）
19
图标改色
进阶
  • 点击图标选中（出现橙色虚线框）
  • 顶部自动出现"图片格式"（或"图形格式"）标签
  • 找"颜色"按钮 → 选白色
  • 如果没有"颜色"，找"填充"功能 → 改白色
科技风PPT的图标统一用白色，跟白色标题字+浅蓝装饰条呼应

七、导出与交付

20
导出PDF
高级
  • 点左上角"文件"按钮（WPS演示按钮右边紫色按钮）
  • 下拉菜单找"输出为PDF"（蓝色高亮项，也叫"另存为PDF"或"导出PDF"）
  • 弹窗选保存位置 → PPT素材库\pdf\文件夹
  • 文件命名规范：客户名_主题_v1_日期.pdf（如：张总_项目汇报_v1_20260801.pdf）
  • 点"保存"
交付规范：PPTX可编辑版 + PDF预览版 双交付。PDF不会乱版，客户不用装WPS也能看

八、母版（了解，暂搁置）

21
进入母版 + 加自动页码
高级
  • 顶部菜单点"视图" → "幻灯片母版" → 进入母版编辑界面
  • 左侧第一个缩略图是"主母版"（最大的那个）
  • 顶部菜单点"插入" → "页眉页脚"按钮
  • 弹窗勾选"幻灯片编号" → 点"全部应用"
  • 顶部最右端点红色叉号 ✕ → 退出母版
  • 普通视图查看所有页面右下角是否有自动页码
注意：浩总的WPS版本母版自动页码不生效（无论点"应用"还是"全部应用"），暂时用手动页码替代。母版概念已理解，进入方法已掌握，等以后换WPS版本或用PowerPoint时再用
九、表格插入与美化（接单高频）
22
插入表格
基础
  • 顶部菜单点"插入"标签
  • 点"表格"按钮
  • 弹出小格子网格，鼠标拖选 5列×5行
  • 松开鼠标，表格插入到页面
23
科技风表格美化（4步成型）
高级
  • 表头改深蓝底：选中第一行 → 右键"设置对象格式" → 填充色 #1F4E79
  • 表头改白字加粗：选中第一行文字 → 字体白色 → Ctrl+B 加粗
  • 隔行变色：第3、5行（奇数数据行）填充浅蓝灰 #F0F6FB
  • 全表微软雅黑：选中整个表格 → 开始标签 → 字体选微软雅黑
  • 居中对齐：选中所有数据单元格 → 开始标签 → 居中按钮
口诀：深蓝表头 + 白/灰隔行 + 微软雅黑 + 无粗边框 = 专业商务表格
24
表格加标题 + 居中
进阶
  • 点表格上方空白区域，或插入→文本框→横向文本框
  • 输入标题（如"季度业绩对比"）
  • 字体微软雅黑、字号28、加粗、颜色深蓝#1F4E79
  • 选中整个表格 → 拖动到页面居中位置
  • 微调用键盘方向键 ←→↑↓ 一格一格挪
十、图片技能链（接单必备）
25
截图插入图片（3种方法）
基础
  • 方法1（最快）：桌面选中图片 → 按住左键拖到PPT页面 → 松手
  • 方法2（最准）：插入 → 图片 → 本地图片 → 双击图片文件
  • 方法3（截图）：Win+Shift+S 截屏 → 切到PPT → Ctrl+V 粘贴
Win+Shift+S 是Windows自带截屏快捷键，截图自动存剪贴板，Ctrl+V直接粘贴
26
图片缩放与移动
基础
  • 缩放：点图片选中 → 拖右下角白圆点 → 按住Shift等比缩放
  • 移动：鼠标放图片中间（不是圆点）→ 光标变十字 → 按住左键拖
  • 看不到白圆点：先点一下图片（图片被选中才出现8个圆点）
一定要按住Shift拖角点！不按Shift会变形拉长。拖中间是移动，拖圆点是缩放
27
裁剪图片（核心技能）
高级
  • 方法A（基础裁剪）：双击图片 → 黑色裁剪框出现 → 拖黑点裁掉多余 → Enter确认
  • 方法B（裁剪为形状）：选中图片 → 图片工具标签 → 裁剪按钮▾ → 裁剪为形状
  • 选"圆角矩形" → 图片立刻变圆角（高级感拉满）
  • 选"椭圆" → 图片变圆形头像（适合Logo/人像）
方法B是接单神器：方图变圆角矩形，立刻从"贴上去"变"嵌进去"
28
图片边框 + 阴影
进阶
  • 加边框：选中图片 → 图片工具 → 图片边框 → 颜色白色 → 粗细1磅
  • 加阴影：选中图片 → 图片工具 → 阴影效果/图片效果 → 外部 → 右下
  • 默认阴影参数就行，不用调
边框让轮廓清晰，阴影让图片有立体感。两步做完从"贴上去"变"浮起来"
29
图文排版（左图右文）
高级
  • 图片缩到合适大小，拖到页面左侧居中
  • 插入 → 文本框 → 横向文本框 → 在右半边画框

样式1：竖线标题装饰（最常用）
基础

踩坑记录 & 解决方案

1. WPS模板选择页的付费陷阱

打开WPS演示后，模板页有4个按钮，其中3个（AI生成/上传文档/稻壳大师）要会员，新手容易被引导点付费功能。

解决：每次只点"空白演示文稿"（免费），忽略其他3个按钮

2. "字体颜色"和"填充颜色"搞混

工具栏上"A字加下三角"是字体颜色，旁边还有一个"填充颜色"按钮（像油漆桶），新手容易点错。浩总曾误打开"填充颜色"面板。

解决：改文字颜色优先用"右键 → 字体 → 字体颜色"对话框法，绕过工具栏混淆

3. #1F4E79 不在标准颜色下拉里

科技风深蓝色 #1F4E79 不在WPS默认颜色面板里，直接选不到。

解决：颜色下拉 → "其他颜色" → "自定义"标签 → 手动输入 RGB 值 31/78/121

4. 手打圆点"•"渲染成方块

在Arial字体18pt下，手打的圆点符号"•"会渲染成方块，位置还偏高。

解决：删掉手打圆点，改用WPS自带的"项目符号"功能（开始工具栏里的三个圆点图标）

5. Ctrl+M 新建页面不继承背景色

用 Ctrl+M 新建的页面是白底，不会自动继承深蓝背景。

解决：方法1——设置背景色时点"全部应用"；方法2——用 Ctrl+D 复制已有页面代替 Ctrl+M 新建

6. "替换字体"按钮找不到

"替换字体"功能藏在"替换"按钮旁边的小三角里，容易忽略。

解决：开始菜单 → 找到"替换"按钮 → 点它右边的小三角（不是点按钮本身）→ 选"替换字体"

7. 母版自动页码不生效

浩总的WPS版本，在母版里用"页眉页脚"加自动页码，无论点"应用"还是"全部应用"都不生效。

解决：接受现状，使用手动页码。母版的概念和进入方法已学会，等以后用PowerPoint时再用自动页码功能

8. 图标颜色和PPT风格不搭

从iconfont下载的图标可能是彩色/灰色的，跟科技风（深蓝+白+浅蓝）冷色调不搭。浩总最初插入的闪电是黄色的。

解决：选中图标 → 图片格式 → 颜色/填充 → 改成白色。或者在iconfont下载时就选线性白色版本

9. 图表Ctrl+A选不上文字

图表里用Ctrl+A想全选文字改字体，发现选不上图表内的文字。

解决：先单击选中整个图表对象（图表边框变亮），再点开始标签 → 字体选微软雅黑，一次改全部文字

10. 折线图X轴类别不够

Excel里填了6行数据（1月-6月），但图表X轴只显示4个类别（1月-4月）。

解决：①还在Excel里没退出 → 点表格外空白处退出，图表会刷新 ②数据范围未扩展 → 图表工具→设计→选择数据→改范围为 A1:B7

11. 图例显示多余的"系列2/系列3"

折线图图例里除了"用户数"还显示"系列2"和"系列3"，因为Excel里C列D列还有默认数据。

解决：方法①Excel里选中C/D列数据 → Delete清空。方法②图表工具→设计→选择数据→左侧选系列2/3→删除→确定

12. "横向分布"让圆点挤在一起

做时间轴时，5个圆点全选 → 开始→排列→对齐→横向分布，结果圆点全挤在右边或中间一小段。

解决：横向分布是"从选中第一个到最后一个之间分布"，不是页面全宽分布。新手建议撤销(Ctrl+Z)后手动拖到5个等距位置更稳

13. 数据点旁边出现多余数字"1"

折线图数据点"120"旁边出现一个小"1"，不知道哪里来的。

真相：这是"系列名称"标签的显示残留。WPS默认不勾选系列名称，重进数据编辑后那个"1"会自动消失。如果还在：右键数据标签→设置数据标签格式→取消勾选"系列名称"

14. 图表改色找不到按钮

选中图表后找不到改色按钮，右键也没有"更改颜色"选项。

解决：选中图表 → 顶部自动出现"图表工具"标签 → 点"设计"子标签 → 找"更改颜色"按钮（图标像彩色小方块）→ 选蓝色色调

15. 装饰条文字意外旋转90度

做装饰条时，不小心碰到形状顶部的绿色旋转手柄，整个形状+文字旋转了90度，变成竖排文字。

解决：删掉多余文字，装饰条本身不写文字。不要碰绿色旋转手柄（只在画箭头需要旋转角度时才用）。标题单独用横向文本框

坑1：WPS"更改颜色"按钮免费版无蓝色系方案（重大更正）

之前手册说"图表工具→更改颜色→选蓝色色调"——这是错的。WPS免费版的"更改颜色"里，没有一套是纯蓝色系，全是有橙/绿/黄/紫的彩色方案。

正确方法：手动改色——双击单块扇形（双击两次：第一次选中整图，第二次选中单块）→ 右键 → 设置数据系列格式 → 纯色填充 → 颜色点开 → 自定义颜色 → 填RGB值

坑2：图表"更改颜色"会把整个图表配色按方案色改

不只改柱子，背景/文字/网格线全改。出现"背景变深蓝+文字也深蓝=字消失"就是这个问题。

改色后必查3项：色块颜色 / 背景颜色（改回白色）/ 文字颜色（保留深蓝）

坑3：饼图小扇形数据标签挤一起

200/350这种小扇形数据标签默认"数据标签内"位置，数字叠在一起看不清。

修复：双击数字标签 → 对象属性 → 标签位置 → 数据标签外（带引导线）。进阶：双击小扇形拖出来"分离扇形"突出重点。

坑4：目录与内页标题要一致

改了目录章节名（如"核心数据"→"全年概览"），内页标题也要同步改，否则目录和内页对不上。

原则：目录章节名 = 过渡页副标题 = 内容页标题，三者必须一致。改一个，其他两个也要同步。

1
卡片式版式（团队介绍/服务亮点）
  • 插入 → 形状 → 圆角矩形 → 画卡片（宽5-6cm，高7cm）
  • 卡片填充白色，无线条（或浅蓝#85B7EB细线1磅）
  • 卡片内放3层内容：深蓝图标（顶部）+ 深蓝姓名18pt加粗（中部）+ 浅灰职务12pt（底部）
  • Ctrl+D复制出3-4个卡片 → 手动拖动横排对齐（间距1cm）
  • ⚠️ 卡片配色铁律：深蓝底 + 白卡片 + 深蓝文字（蓝卡片信息糊背景）
  • ⚠️ 圆角别太大，拖左上角黄菱形调小（像信息卡不像APP按钮）
  • ⚠️ 所有内容必须放卡片内，不能飘外面
2
上图下文版式（案例展示/活动回顾）
  • 插入大图 → 宽度占页面60-70% → 居中
  • 右键图片 → 设置对象格式 → 边框：浅蓝#85B7EB实线1磅
  • 阴影：外部向下偏移，模糊100%，颜色深蓝半透明 → 图片"浮"在页面上
  • 图片下方3层文字：白色标题22pt加粗 / 浅蓝副标题16pt / 白色要点带项目符号
  • ⚠️ 深蓝底文字颜色铁律：白字最清晰，浅蓝#B5D4F4做层次，不能用深蓝
  • ⚠️ 不写"案例标题""项目简介"等标签词，直接写内容
3
多图排版（活动照片墙/成果展示）
  • 插入图片 → Ctrl+C/V复制出4张 → 统一大小（右键→大小和位置→输入相同宽高）
  • 排成2×2网格：上排2张 + 下排2张，间距1cm
  • 手动拖动对齐 + 参考线辅助（别用"横向分布"，会全挤一边）
  • 每张图下方配白色小字说明（4-6字），微软雅黑12pt，居中
  • 页面顶部加大标题（白色32pt加粗）+ 浅蓝装饰条
  • ⚠️ 4张图必须完全一样大，不然网格不整齐
4
页面切换动画（淡入）
  • 左侧缩略图点第1页 → 按住Shift点最后一页 → 全选所有页
  • 顶部「切换」标签（不是"动画"标签）→ 选「淡入」
  • 全选所有页一起设置，避免逐页操作
  • ⚠️ 商务PPT动画铁律：少用、克制、统一，一个PPT最多2种动画效果
  • ⚠️ 只用淡入/推入，不用弹跳/旋转/飞入（太花哨）
  • ⚠️ "应用到全部"有时只给同版式页加效果，全选页面一起设置更靠谱
!
第6天踩坑记录
  • 卡片用蓝色 → 信息糊背景：深蓝底必须用白色卡片，蓝色卡片和背景融为一体
  • 文字飘在卡片外面：所有内容（图标+姓名+职务）必须放卡片内部
  • 图标颜色太亮：#4A90C2不够商务，必须改成#1F4E79深蓝
  • 圆角太大像APP按钮：拖左上角黄色菱形点调小圆角
  • 深蓝底用深蓝文字 → 看不见：深蓝底文字必须用白色或浅蓝#B5D4F4
  • 页面切换在"动画"标签找不到：WPS页面切换在独立的「切换」标签，不是「动画」标签
  • "应用到全部"只给一页加效果：WPS版本bug，全选所有页一起设置更靠谱
