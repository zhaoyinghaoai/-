## 第一次跑通 ppt-master（Quick Generate 工作流）

浩总说"现在试" → 用快递服务站工作总结跑通 Quick Generate，10 页 SVG → 原生 PPTX。

### 工作流（5 步可复用）
1. **准备源材料**：把文字稿导入到 `projects/<name>_<format>_<date>/sources/source.md`
2. **项目初始化**：`project_manager.py init` 创建项目目录
3. **跑完整性门控**：`attribution_guard.py`（必须通过，否则后续步骤被拦截）
4. **手写 SVG 页面**到 `svg_output/`：
   - viewBox=`0 0 1280 720`（ppt169 16:9）
   - 必读规范：`shared-standards-core.md`（SVG 基础）+ `svg-effects.md` §6.1（效果诊断）
   - 关键约束：无 mask/style/class/foreignObject/animate，颜色 #RRGGBB，无单位小数，几何属性 inline 风格需 px 后缀
   - 每个 top-level `<g>` 必带 `id` 和 `data-pptx-bounds="x y w h"`
   - 背景 `<rect>` 加 `id` + `data-pptx-role="background"`
   - 根 `<svg>` 加 `data-pptx-page-role`（cover/content/section/ending/toc）
   - 文字用 `<text>` + positioned `<tspan>` 多行（dx=0, dy=正数）
5. **质量检查 + 导出**：
   - `svg_quality_checker.py <项目目录> --quick-generate --stage final --json`（生成 validation/svg_quality_report.json）
   - `svg_to_pptx.py <项目目录> --quick-generate --format ppt169 -o <输出.pptx>`

### 踩过的坑（下次避开）
1. **polygon 箭头方向要画对**：顶点顺序决定朝向。右向箭头：`points="x1,y1 x2,y1 x2,y0 x3,ymid x2,y2 x2,y3 x1,y3"`（x3 是箭头尖）
2. **data-pptx-role 必须配 id**：单独的 role 属性会触发 ERROR
3. **root viewBox 是画布权威**：不在 root svg 上加 `width`/`height`，会被 checker 警告
4. **data-pptx-page-role 必填**：flat 页面必须在 root svg 上加这个属性（值: cover/content/ending/section/toc）
5. **tspan 多行**：用 positioned `<tspan x=... dy=正数>` 配合 text-anchor 才能精确控制
6. **导出前必须生成 JSON 质量报告**：`--quick-generate` 模式会校验 final report 是否存在

### PDF 预览生成（无 LibreOffice 环境下的方案）
WPS COM 被安全策略拦截。改用 pymupdf 自带的 SVG 解析 + JPEG 压缩合成：
```python
import pymupdf, glob
doc = pymupdf.open()
for svg in sorted(glob.glob('svg_output/*.svg')):
    src = pymupdf.open(svg)
    pix = src[0].get_pixmap(matrix=pymupdf.Matrix(1.0, 1.0))
    img_bytes = pix.tobytes('jpeg', jpg_quality=85)
    src.close()
    page = doc.new_page(width=960, height=540)  # 16:9
    page.insert_image(page.rect, stream=img_bytes)
doc.save('预览.pdf', garbage=4, deflate=True, deflate_images=True)
```
10 页压到 ~0.5 MB。
