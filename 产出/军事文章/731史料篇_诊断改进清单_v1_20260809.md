## 二、三个核心原因

### 原因1：话题触碰平台"限流区"

| 高敏感元素 | 平台处理 |
|------------|----------|
| 731部队 | 严格限流 |
| 日本侵华细菌战 | 谨慎推荐 |
| "精日"标签 | 降权 |
| 反日情绪渲染 | 限流 |

平台给了2.7万"测试展现"，看用户反应。结果几乎没人点，直接判定"不适合放大"。

### 原因2：标题太煽动，读者不信

| 标题元素 | 问题 |
|----------|------|
| "花560亿买遗忘" | 数字猎奇，像营销号 |
| "14岁孩子掏出一张纸" | 情绪消费未成年人 |
| "日本百年套路崩了" | 夸张结论，读者本能不信 |
| 问句+感叹句混合 | 标题党感强，平台降权 |

用户看到标题第一反应是"又一个煽动的"，手就划走了。

### 原因3：账号权重可能被降

前几篇连续出现事实合规问题（台海篇被判"事实不符"、伊朗篇有虚构风险），账号权重大概率被下调。权重低 → 只给测试展现，不放量。

## 三、内容本身的四个问题

| # | 问题 | 说明 |
|---|------|------|
| 1 | 开头太慢 | "三个月前，三个初中生凑压岁钱买了几张泛黄的纸"——叙事开头，没有钩子 |
| 2 | "560亿日元"无来源 | 这个数字如果是真的需要注明来源，否则被判定"编造数据" |
| 3 | 情绪过载，事实密度不够 | 大量篇幅渲染情绪，可验证的事实和独特信息差偏少 |
| 4 | 结尾互动门槛高 | "下一个站出来捅破认知战泡泡的，会是哪个国家的什么人"——太抽象，读者不知道怎么答 |

## 四、改进方向

### 1. 标题：从"煽动型"改"悬念型"

| 改前 | 改后 |
|------|------|
| 花560亿买遗忘？14岁孩子掏出一张纸，日本百年套路崩了 | 三张旧纸捐给731陈列馆，为什么有人坐不住了 |

**原则**：少用"日本""套路""崩了"这种煽动词，多用"档案""真相""为什么"这种悬念词。

### 2. 开头：从"叙事式"改"钩子式"

| 改前 | 改后 |
|------|------|
| 三个月前，三个初中生凑压岁钱买了几张泛黄的纸… | 一张标着"秘"字的1936年文件，被三个初中生送到了哈尔滨 |

**原则**：用具体物件做钩子，信息差前置。

### 3. 数据：从"无来源"改"模糊化"

| 改前 | 改后 |
|------|------|
| 日本外务省累计投了超过560亿日元——专门对华舆论抹黑 | 据公开报道，日本外务省曾拨出专项资金用于海外信息传播 |

**原则**：无法核实的数据要么删掉，要么加"据公开报道"限定。

### 4. 情绪词：从"煽动"改"分析"

| 改前 | 改后 |
|------|------|
| 精日病得狠狠治 | 删除 |
| 日本百年套路崩了 | 用新技术洗旧历史的打法 |
| 花560亿批量生产遗忘的流水线 | 历史叙事，是要抢的 |

**原则**：去情绪化，保留分析框架。

### 5. 结尾：从"抽象提问"改"具体思考"

| 改前 | 改后 |
|------|------|
| 评论区猜个数——下一个站出来捅破认知战泡泡的，会是哪个国家的什么人？ | 你觉得，在AI时代，档案和记忆，哪一个更靠得住？ |

**原则**：降低门槛，引发思考而非站队。
