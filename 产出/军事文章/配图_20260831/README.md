## 使用流程

1. 在头条创作者后台「文章管理」→ 找到本篇 → 「编辑」
2. 正文光标移到对应段落末尾
3. 点编辑器「图片」按钮 → 上传本地文件
4. 上传后系统会生成图片ID（自动插入正文）
5. 选完后保存（数据不清零）
