## 配图位置四原则（可复用）

1. **兑现原则**：图的内容 = 刚读完那一段的核心名词。别让读者还得猜图和文章什么关系。
2. **呼吸口原则**：手机阅读每 4-6 段纯文字后需要一张图，否则眼睛滑走。但别连续两张挨太近，会打断句子流。
3. **对位原则**：图和文字的关系可以是「印证」（最稳）或「反讽」（更高级，能制造张力）。反讽用好了，评论区会有人专门提。
4. **留白原则**：结尾互动钩子前**不放图**。钩子要独占最后一段空间，把注意力全留给"点赞过 200 我来安排"那句话。

> 另注：封面图会在正文顶部自动显示一次，所以第一张文中图不必抢在开头，放第一部分之后正好。

## ⚠️ 使用须知

1. **图注统一写「资料图」或「示意图」**，例如：
   - 01 → 「特朗普访问以色列（资料图）」
   - 02 → 「以色列境内的一套防空系统（资料图）」
   - 03 → 「美以双边会晤（资料图）」
   ❌ 禁止写成「9月8日制裁现场」「英国宣布制裁」等，是事实错误。

2. **封面最终由浩总肉眼拍板**（我看不了图）。判定标准就是昨天定的那条：
   **把图缩到拇指大小，一眼能认出主体是什么吗？认不出就换。**
   - 01 的风险：机场抵达类照片常是远景，若特朗普的脸在缩略图里看不清 → 换 02
   - 02 的优势：导弹发射车体积大、轮廓硬，缩略图里一眼就是军事装备

3. 三张全是美方/以方官方开放版权图，**不含任何巴方画面、无冲突伤亡画面**，降敏安全。

4. 本轮仍未突破「读图」限制——画面描述全部来自 DVIDS 官方 caption，未亲验。
