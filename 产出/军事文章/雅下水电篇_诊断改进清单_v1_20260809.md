## 三、三大核心问题

### 问题1：标题门槛太高（最致命）

原标题：
> 印度急着打听雅下水电细节，怕的不是水

| 问题 | 说明 |
|------|------|
| "雅下水电"是缩写 | 普通读者不知道这是"雅鲁藏布江下游水电站"，信息流里刷到直接划走 |
| 25字偏长 | 清单要求15字内冲突型 |
| 悬念在后半句 | "怕的不是水"有悬念，但前半句"打听细节"太干，读者还没读到悬念就划走了 |

**改写方向：用最直白的冲突，去掉缩写，数字前置。**

### 问题2：选题没有时效热点

| 维度 | 说明 |
|------|------|
| 事件时间 | 2025年7月19日开工，现在是2026年8月9日，已过一年多 |
| 新闻钩子 | 没有"今天刚发生"的事件做由头 |
| 话题热度 | 中印边境是持续话题，但"水电站打听细节"不是大众热点 |

**这篇不是跟热点，是"冷题热写"**——话题本身有分析价值，但没有时效杠杆撬动初始池。拉夫罗夫篇能冲72.7万，是因为采访事件正在发酵；这篇没有这个杠杆。

### 问题3：数据需要合规处理

| 文中表述 | 合规判断 | 改法 |
|----------|----------|------|
| "50公里河段落差两千米" | 🟡 工程数据，需来源 | 加"据公开资料" |
| "一吨水发5度电" | 🟡 技术换算，需来源 | 模糊化为"发电效率极高" |
| "三个三峡那么大" | 🟡 各方估算 | 改"据多方估算，规模堪比多个三峡" |
| "离印度边境20公里" | 🔴 需核实 | 改"靠近边境" |
| "2020年加勒万冲突" | ✅ 真实历史事件 | 保留 |
| "2025年7月19日开工" | 🟡 需确认 | 加"据公开报道" |

## 四、内容层面的优点（要保留）

| 优点 | 例子 |
|------|------|
| 核心洞察清晰 | "打听的不是水，是议价权"——这个判断很有力 |
| 金句在线 | "这不是水龙头，拧不紧""那不是水电站，那是定海神针""上游在你手里，下游在我手里" |
| 结构层次分明 | 水→数→地 三层递进，有分析骨架 |
| 有信息差 | "径流式不蓄水"这个技术细节，多数人不知道 |
| 结尾互动 | "怕的是水还是怕手里没牌"——投票式，方向对 |

**底子不差，问题全在"拉人进来"这一关。**

## 五、改进清单（按优先级）

| # | 改什么 | 怎么改 | 影响等级 |
|---|--------|--------|----------|
| ① | **标题** | 25字缩写型→16字冲突型，数字前置，去掉"雅下"缩写 | ⭐⭐⭐⭐⭐ |

## 七、一句话总结

**内容底子过关，金句在线，问题全在标题门槛。** 这篇跟普京旧话篇是同一类病——标题把人挡在外面，内容再好也没人看。标题改对，从3500冲到几万没问题。

**但要注意**：这篇是"冷题热写"，没有时效热点撬动，天花板比拉夫罗夫篇那种"正在发酵的事件"低。改对标题能冲一级池，但冲到几十万爆款池需要蹭上中印相关新闻。
