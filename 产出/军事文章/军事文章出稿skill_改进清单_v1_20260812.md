# 今日头条军事文章出稿 Skill — 改进清单

> 浩总自建skill的审阅意见，按优先级排列。骨架不动（6步流程清晰），原则和自查扎实，以下是缺的部分。

---

## P0：两个最致命的缺失（必须补）

### 缺失1：选题时效判断 — 应加为"第0步"

**现状**：6步流程从"第1步扒原文"开始，没有前置的选题判断。

**问题**：选题类型决定了流量天花板，这是比标题、比内容都更上游的变量。

**验证数据**：

| 文章 | 选题类型 | 展现量 |
|------|----------|--------|
| 拉夫罗夫篇 | 正在发酵的热点 | 72.7万 |
| 南海篇 | 热点周年节点 | 12万 |
| 基辅无人机展篇 | 热点但过了时效 | 低 |
| 雅下水电原版 | 我误判"冷题"（实为621万热点） | 3518 |

**建议**：在"第1步扒原文"之前加 **第0步：选题诊断**

| 检查项 | 判断 |
|--------|------|
| 这件事今天/昨天刚发生吗？ | 是→热点，可写 |
| 头条话题量多少？ | 几百万以上→大热点；几万以下→冷点 |
| 大媒体还在报吗？ | 是→热度在发酵；否→热度过了 |
| 军事/地缘领域有相关热点吗？ | 有→蹭；没有→换选题 |

**一句话**：宁可少写，也要写正在发酵的。冷题再好的内容也冲不出初始池。

---

### 缺失2：话题标签选择 — 应补进"第5步"

**现状**：skill的第5步是"标题+结尾"，完全没有话题标签这一步。

**问题**：不带话题标签，621万热点流量一分吃不到，只走账号基础推荐。台湾国格篇带了 #台湾# #一个中国# 直接跳到6.8万展现。

**验证数据**：

| 文章 | 带话题标签 | 展现量 |
|------|-----------|--------|
| 雅下水电原版 | ❌ 没带 | 3518 |
| 台湾国格篇 | ✅ 带了2个 | 6.8万 |

**建议**：第5步改为 "标题+结尾+**话题标签**"

**标签规则**：

| 规则 | 具体操作 |
|------|----------|
| 数量 | 2-3个，不要多（系统最多有效识别3个） |
| 组合公式 | 1个热点话题 + 1-2个领域常规话题 |
| 位置 | 统一放正文最末尾，不要放开头/中间 |
| 操作 | 手机端逐个搜索选中变蓝，不要一次性粘贴 |
| 相关性 | 必须和内容强相关，不能乱蹭（乱蹭会乱账号标签+降权） |

**军事领域常规标签储备**：

```
#台海局势#  #俄乌冲突#  #中印边境#  #中美关系#
#军事观察#  #地缘政治#  #南海问题#  #中东局势#
```

**每次发文**：1个当天热点 + 从上面挑1-2个相关的。

**怎么确认成功**：发布后点进文章，标签是蓝色可点击 = 成功接上话题流量池。

## P1：四个重要缺失（建议补）

### 缺失3：发完后自己发第一条评论 — 应加为"第7步"

**现状**：skill的第6步是"存Obsidian"，到这就结束了。

**问题**：发完文章后的动作没覆盖。其中最关键的是自己先发第一条评论——读者跟评门槛骤降。

**建议**：加 **第7步：发布后动作**

| 动作 | 怎么做 | 为什么有效 |
|------|--------|-----------|
| 自己发第一条评论 | 发完1小时内，评论区发一条，给读者一个回复模板 | 第一条评论是锚，有锚跟评多，没锚冷场 |
| 监测初始数据 | 发完1-2小时看展现/点击率 | 卡在初始池（展现<5000）立刻判断要不要改标题重发 |
| 回复前几条评论 | 有人评论及时回 | 回复会触发平台二次推荐 |

**第一条评论的写法**：给一个具体的、可跟的模板，比如"我选D，那根定海神针最扎心。你们呢？"

---

### 缺失4：选题类型轮换 — 应补进"第2步"

**现状**：第2步是"角度+叠加"，没有考虑这篇是什么类型。

**问题**：我们验证过三种内容类型各有所长：

| 类型 | 擅长拉什么 | 例子 |
|------|-----------|------|
| 观点驱动 | 点赞 | 内塔尼亚胡篇（日本侵华类比，代入感拉满） |
| 信息差驱动 | 转发 | 拉夫罗夫篇（拆解套路，有教学感） |
| 争议驱动 | 评论 | 留一个让两派能吵的点 |

**建议**：第2步角度选择时，先问一句"这篇打什么类型？"，连续两篇同类型就换一个。

---

### 缺失5：涉台表述具体规则 — 合规关第5项要展开

**现状**：合规关第5项只写了"涉台"，没有具体规则。

**建议**：展开为具体规则：

| 规则 | 对 | 错 |
|------|-----|-----|
| 称谓 | 台湾地区、台湾当局 | 中华民国、总统 |
| 法律依据 | 引1971年联大2758号决议 | 自创"法理"表述 |
| 角色定位 | 中国的一个省 | 主权实体 |
| 当局称呼 | 台湾地区领导人 | 台湾总统 |

---

### 缺失6：人名处理原则 — 应加为第9条写作原则

**现状**：8条写作原则没有"人名处理"。

**问题**：731史料篇我们学到，涉敏感人物写全名会增加核查风险。

**建议**：加第9条：

| 原则 | 核心 |
|------|------|
| 人名瘦身 | 涉敏感人物去掉全名，保留职务描述（"安全局上校"而非全名），降核查风险 |

## P2：四个可优化的点

### 优化1：定义"humanize"

**现状**：第4步提到"humanize"但没有定义。

**建议**：写明——去AI腔，把书面词换成口语：

| AI腔 | 改成 |
|------|------|
| 此外 | 删掉，或换"再说一件事" |
| 综上所述 | "说到底" |
| 值得注意的是 | 删掉 |
| 不可否认 | "说白了" |

感叹号控制在3个以内。

---

### 优化2：互动结尾补具体公式

**现状**：第5步提到"2-3互动结尾"但没有公式。

**建议**：补公式：

| 结尾类型 | 公式 | 门槛 |
|----------|------|------|
| 投票式二选一 | "A还是B？评论区选一个" | 低（不用想，选一下） |
| ABCD四选一排序 | "ABCD排个序" | 中（选一下就行） |
| 开放提问 | "你怎么看？" | 高（要组织语言，慎用） |
| 晒具体例子 | "你见过最X的Y？晒一个" | 中（要回忆） |

**优先用投票式，慎用开放提问。**

---

### 优化3：数字规范表述更清楚

**现状**：写了"中国模糊/外国具体"，这个表述反直觉。

**建议**：改成：

| 规则 | 具体含义 |
|------|----------|
| 中国军事数据模糊化 | 涉机密（部署位置、备弹量、拦截率）→ 用"大量""数十枚" |
| 外国公开数据可具体 | 有公开来源的（武器存在性、公开射程）→ 可写，但加"据公开资料" |

---

### 优化4：确认"存Obsidian"

**现状**：第6步写"存Obsidian"。

**问题**：浩总实际用的是普通文件（.md存在工作目录），不确定是否真用Obsidian。

**建议**：确认浩总是不是真用Obsidian。如果不是，改成"存工作目录"。

## 总结：改进后的7步流程（建议版）

```
第0步：选题诊断          ← 新增（判断热点/温点/冷点，决定要不要写）
第1步：扒原文            → 搜索原始新闻/官方声明/原话，展示给浩总确认
第2步：角度+叠加+类型选择 → 2-3个角度+2-3个叠加维度+判断观点/信息差/争议型，等浩总确认
第3步：写初稿            → 内置9条写作原则（原8条+人名瘦身）
第4步：定稿              → humanize（去AI腔）+自查（五层18项），推全文等浩总OK
第5步：标题+结尾+话题标签 → 3-5标题候选（15-22字，给冲突不给结论）+2-3互动结尾（优先投票式）+3个话题标签（1热点+2常规，放文末）
第6步：发布后动作        ← 新增（自己发第一条评论设锚+监测初始数据+回复前几条评论）
```
