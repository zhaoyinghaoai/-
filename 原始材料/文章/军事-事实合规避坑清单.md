# 军事文章事实合规避坑清单 v1

> 用途：写完军事/地缘类文章后，发布前对照检查，避免被头条判定"关键信息与事实不符"导致限流或处罚。
> 日期：2026-07-27

---

## 一、什么样的内容会被判"关键信息与事实不符"

头条审核不是随便判的，它抓的是**具体的事实性硬伤**。军事类内容是重点审核领域，以下几类表述最容易踩雷：

| 雷区类型 | 为什么会被判 | 例子 |
|----------|-------------|------|
| **军事机密数据** | 官方不公布，你写具体数字=编造 | "天弓三备弹三位数""东部战区备几倍于这个数" |
| **具体部署位置** | 部署信息属军事机密，无法证实 | "福建浙江江西三道线铺着" |
| **具体武器性能参数** | 详细参数多为推测或涉密 | "东风-17从点火到命中八分钟不到" |
| **具体拦截率/战果数字** | 无权威来源，无法证实 | "乌军拦截率从80%掉到50%" |
| **夸大/绝对化表述** | 非官方定论却写成定论 | "号称全球第二""防空密度全球第一" |
| **推测当事实写** | 把分析推测写成已发生的事实 | "2026年答案浮上来了"（如果是推测） |

---

## 二、高危数据三类处理法

写军事内容难免要用数据，但不是所有数据都能随便写。发布前把文章里的数据分成三类处理：

### ✅ 可以保留的（有公开权威来源）

- 武器型号存在性："东风-17是高超音速导弹"（公开信息）
- 公开射程范围："PHL-191远火射程三百多公里"（公开资料有）
- 已发生的公开事件："俄军2022年开战"（新闻事实）
- 地理常识："海峡最窄一百三十公里"（地理数据）

**判断标准：能在官方通报、权威媒体（新华社/央视/国防部发言人）、公开军刊里找到的，可以写。**

### 🟡 要模糊化的（方向对但具体数字无法证实）

| 原文（高危） | 改后（安全） |
|-------------|-------------|
| "宙斯盾一次能拦60枚" | "宙斯盾拦截能力有限" |
| "天弓三备弹三位数" | "天弓三备弹量不小" |
| "八分钟不到命中" | "极短时间内命中" |
| "拦截率从80%掉到50%" | "拦截率明显下滑" |
| "几倍于这个数" | "规模远超俄军" |
| "福建浙江江西三道线" | "沿海多方向" |

**模糊化原则：保留判断方向，去掉无法证实的具体数字。**

### ❌ 必须删掉的（纯属推测或涉及机密）

- 具体部队番号、驻地
- 具体弹药库存数量
- 具体作战计划时间表
- "某型导弹具体击毁了多少目标"（无权威战报）
- 把未发生的事当已发生写

## 三、军事类内容的三个特殊红线

军事/涉军/涉台内容审核比普通内容严得多，额外注意：

### 1. 涉台表述要规范

| ❌ 不要写 | ✅ 要写 |
|----------|---------|
| "台湾的防空" | "台湾地区的防空" |
| "台军"当独立军事力量表述 | "台湾地区军事力量" |
| 暗示台湾是独立实体 | 坚持"台湾是中国的一部分" |

**原则：涉台内容里，任何可能被解读为"台湾是独立主体"的表述都要避免。这是政治红线，不是事实核查问题。**

### 2. 武器数据用"公开资料"限定

写武器性能时，加一句来源限定，规避"编造数据"判定：

- ❌ "东风-17飞行轨迹你跟踪试试"
- ✅ "据公开资料，东风-17是高超音速导弹，现有反导系统难以拦截"

**加了"据公开资料"，就把责任从"你编造数据"变成"你引用公开信息"，审核判定完全不同。**

### 3. 区分"分析观点"和"事实陈述"

文章里你的分析和推测，要明确标成观点，不要写成事实：

- ❌ "2026年，答案浮上来了"（像陈述已发生事实）
- ✅ "从2024年底的战场变化看，俄军似乎找对了打法"（明确是分析）

**凡是推测、分析、判断的内容，用"从…看""似乎""可能""分析认为"等限定词，不要用肯定句当事实写。**

## 四、发布前自查清单（每篇都过一遍）

写完文章，发布前逐项检查：

### 数据核查

- [ ] 文章里所有具体数字，能不能找到公开来源？
- [ ] 找不到来源的数字，有没有模糊化处理？
- [ ] 武器性能参数，有没有加"据公开资料"限定？
- [ ] 有没有把推测当事实写？（检查"了""是""有"等肯定表述）

### 涉台表述

- [ ] 涉台内容有没有用"台湾地区"？
- [ ] 有没有把台湾当独立军事力量表述？
- [ ] 有没有暗示台湾是独立实体的措辞？

### 军事机密

- [ ] 有没有写具体部队番号、驻地？
- [ ] 有没有写具体弹药库存、部署数量？
- [ ] 有没有写具体作战计划？

### 表述规范

- [ ] "全球第一""全球第二"这类绝对化表述，有没有加"号称""被认为"？
- [ ] 战果数字有没有权威来源？没有就别写具体数
- [ ] 未发生的事，有没有误用过去时态当已发生写？

## 五、被处罚了怎么办

如果已经被判"关键信息与事实不符"，按这个顺序处理：

### 第一步：定位是哪句话触发的

| 判定原因 | 表现 |
|----------|------|
| 具体数字无法证实 | 审核提示指向某个数据 |
| 涉密信息 | 审核提示指向部署/数量 |
| 涉台表述不规范 | 审核提示指向涉台段落 |
| 推测当事实 | 审核提示指向某个判断句 |

### 第二步：判断能不能申诉

| 情况 | 能否申诉 | 怎么办 |
|------|----------|--------|
| 数据都有公开权威来源 | ✅ 申诉 | 提供来源链接 |
| 数据是推测/AI生成/道听途说 | ❌ 大概率失败 | 改完重发 |
| 部分有据部分没据 | 🟡 改掉没据的再申诉 | 先改再申诉 |

### 第三步：改写重发（比硬申诉成功率高）

**申诉不如改写重发。** 把无法证实的部分按本清单改掉，重新发布，比硬撑着申诉成功率高得多，也省时间。

改写三步：
1. 删掉所有无法证实的数据和部署信息
2. 模糊化具体数字（"60枚"→"数十枚"）
3. 加来源限定词（"据公开资料""从…看"）

---

## 六、一句话原则

**军事类内容，宁可写"方向"不写"数字"，宁可写"趋势"不写"细节"。**

你的文章强项是**逻辑分析和金句冲击**，不是情报数据。把具体数字换成趋势判断，把部署细节换成战略分析——文章的力量不会减弱，反而更安全、更经得起审核。
