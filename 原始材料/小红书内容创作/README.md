# 小红书内容创作

小红书内容创作工作区，从素材收集到发布复盘的完整流程管理。

## 文件夹结构

| 文件夹 | 用途 | 在流程中的角色 |
|--------|------|----------------|
| 📥 素材库 | 存放收集到的创作素材（截图、灵感、竞品参考） | 进料口 |
| 🎯 选题库 | 选题清单、选题分析、热点追踪 | 加工车间 |
| ✍️ 文案库 | 完整文案、标题库、开头结尾模板 | 成品仓库 |
| 📅 发布计划 | 发布排期、发布记录、数据复盘 | 执行仪表盘 |

## 创作流程

```
素材收集 → 选题判断 → 文案撰写 → 发布排期 → 发布 → 数据复盘
  素材库      选题库      文案库       发布计划      发布计划     发布计划
```

## 使用建议

1. **日常**：刷到好内容/灵感，随手丢进「素材库」，标注能用在哪
2. **每周**：从素材里提炼选题，写进「选题库」，过一遍选题判断标准
3. **写稿**：选定一个选题，在「文案库」里写完整文案
4. **排期**：把成稿排进「发布计划」的排期表
5. **复盘**：发布后记录数据，每周复盘一次，找出爆款规律
