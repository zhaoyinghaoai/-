# 发布计划

这个文件夹用来存放**发布排期和发布记录**——管好什么时间发、发什么、发了之后效果如何。

## 适合放什么

- **发布排期表**：未来一段时间的发布计划（日期+内容+平台）
- **发布记录**：已发布内容的归档（含数据复盘）
- **数据复盘**：每周/每月的内容数据总结
- **发布规则**：最佳发布时间、发布频率、账号运营节奏

## 文件命名建议

- 排期表：`发布排期_2026年8月.md`
- 周复盘：`周复盘_W33_0804-0810.md`

## 数据复盘要点

每篇内容发布后记录：

- **浏览量**（曝光是否够）
- **点赞/收藏/评论比**（内容质量是否好）
- **涨粉数**（转化效果）

每周复盘一次，找出数据好的内容的共性，复制成功模式。

## 原则

发布计划是"执行仪表盘"，是整个创作流程的最后一环。计划要落地、记录要真实、复盘要诚实。
