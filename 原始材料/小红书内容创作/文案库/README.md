# 文案库

这个文件夹用来存放**写好的文案**——从选题到成稿的完整内容。

## 适合放什么

- **完整文案**：可以直接发布的图文/视频文案
- **标题库**：收集和测试过的标题，记录哪些数据好
- **开头模板**：各种风格的爆款开头（痛点型、故事型、数据型等）
- **结尾模板**：引导互动的结尾（提问、投票、关注引导）
- **标签库**：按主题整理的常用话题标签

## 文件命名建议

- 成稿：`日期_主题_v1.md`，修改版加版本号
- 模板类：`标题库.md`、`开头模板.md`

## 文案结构参考

一篇完整的小红书文案通常包含：

1. **标题**（20字以内，带情绪/数字/痛点）
2. **开头**（前3行决定点击率，要有钩子）
3. **正文**（分点清晰，每点一两句话）
4. **结尾**（引导互动：提问/投票/关注）
5. **标签**（5-10个相关话题标签）

## 原则

文案库是"成品仓库"，放进来的是接近可发布状态的稿子。草稿和半成品可以先留在选题库里。
