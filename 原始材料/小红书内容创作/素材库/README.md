# 素材库

这个文件夹用来存放**创作素材**——你刷到的、想到的、收集到的各种可以用来做小红书内容的原始材料。

## 适合放什么

- **截图/图片**：刷到的爆款笔记截图、好看的排版参考、视觉灵感
- **链接**：刷到的优质内容链接（可以存个截图+一句话备注）
- **灵感碎片**：突然冒出来的想法、标题灵感、开头金句
- **竞品参考**：同领域博主做得好的内容，存下来学习拆解
- **数据素材**：行业数据、统计数据、可以引用的数字

## 文件命名建议

- 截图类：`日期_主题.png`，比如 `20260815_爆款标题拆解.png`
- 文字类：直接写在一个 `.md` 文件里，按日期或主题归档

## 原则

素材库是"进料口"，不用整理得太细，但要标注清楚**这条素材能用在哪**，方便后面选题的时候翻。
