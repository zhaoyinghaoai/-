# 选题库

这个文件夹用来存放**选题清单和选题分析**——把素材转化成可以拍/写的内容主题。

## 适合放什么

- **选题清单**：一段时间内想做的内容主题列表
- **选题分析**：某个选题值不值得做、怎么做、对标谁
- **热点追踪**：当前平台热点、节日节点、热门话题
- **内容规划表**：按周/按月的内容排期草稿

## 文件命名建议

- `选题清单_2026年8月.md`
- `热点追踪_本周.md`

## 选题判断标准

每个选题过一遍这几个问题：

1. **我的目标用户关心这个吗？**
2. **我能提供什么独特价值？（别人为什么看我的而不是别人的）**
3. **这个选题有延展性吗？能不能做成系列？**
4. **跟我的账号定位一致吗？**

## 原则

选题库是"加工车间"，素材进来、选题出去。定期清理做过和放弃的选题，保持清单清爽。
